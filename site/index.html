核心场景

终端和画布在一起，工作流就不用来回跳了

AI 写完，画布上直接看

终端里让 Claude Code 生成一个页面，产出的 HTML 会被开成画布上的预览节点，就摆在终端旁边。改一版看一版，不用在编辑器、浏览器、终端三个窗口之间找来找去。

  • 网页预览节点用内嵌 Chromium 渲染，CLI 里打开的链接不跳出应用
  • 代码、图片、Markdown、设计稿都是同一块画布上的模块
  • 画布可缩放平移，模块按项目分组成 Frame

一个项目一组标签，终端想怎么切就怎么切

像编辑器那样横竖分屏，几个终端并排跑。每个项目有自己的一组标签，切项目就是切一整套上下文，不用重新 cd 一遍。

  • 任意横竖切分，布局跟着项目走
  • 运行监视：哪个终端还有进程在跑，一眼看到
  • 关面板、退应用前会拦一道，不误杀正在跑的命令

每个终端一个 AI 会话，不会串台

任意终端节点一键起 Claude Code 或 Codex，模型和思考档位记得住。会话和终端是绑定的——回溯历史只会回溯这一个终端的，不会翻到别的终端的对话里去。

  • Claude Code / Codex 一键启动，配置记忆
  • 会话与终端绑定，多个 Agent 同时开也互不干扰
  • 离线语音输入：说话转文字进终端，本地跑，不上传

看文档、改文案、翻提交记录，都不用离开画布

.md 文件默认渲染成排版好的样子，右下角一键切源码；所有文本预览都能就地编辑保存。Git 的提交历史、diff、回退，也都是画布上的模块。

  • Markdown 排版预览，源码 / 排版随时切
  • 文本预览就地编辑，改完直接存回文件
  • Git 提交历史、diff、回退在画布模块里完成

Agent 角色

侦查、施工、验收、写作……每个新会话绑一个角色，各自带自己的约定、模型和工具权限。角色可以排序、改分类、自己建。

AI 接入

让 AI 自己去摆画布

Eas-Term 自带一个 MCP 服务，装上应用就已经接好。终端里跑的 Claude Code 或 Codex 不只是给你回一段文本——它能直接把产出摆到你眼前。

AI 能做的事

  • 把生成的 HTML / 图片 / 代码开成预览节点，摆在你眼前
  • 打开网址、最大化某个节点让你细看
  • 整理 Frame 布局，把散乱的模块排整齐
  • 新开终端节点、重命名、关掉不用的节点
  • 贴便签写说明，任务跑完发系统通知

共 13 个工具，随应用内置，不用手写配置文件。

和 CLI 的配合

  • 任意终端节点一键启动 Claude Code 或 Codex
  • 模型、思考档位选一次就记住，下次直接起
  • 会话与终端一一绑定，多开 Agent 也不会串到别的终端
  • Agent 打开的链接落进画布的内嵌浏览器，视线不离开工作台
