每个版本改了什么

只记你能感觉到的变化。想知道当前装的是哪一版，看应用标题栏右侧的设置里。

0.4.13

2026-08-07

新增

  • 甘特图。第四个视图：横轴是时间，一行一个项目，每根条是一次「你发出去的话 → agent 干完」。条上显示前十个字，鼠标停上去看全文和耗时，点一下跳回那个终端。同一个项目同时跑几件事时，条会上下堆叠而不是叠在一起
  • 底部有一条导航带，画完整一周的活动疏密，拖上面那个框选看哪一段；主区跨度可以在 24 小时和 3 天之间切。有异常中断的位置在导航带上是红的，一眼能找到
  • 图上直接拖也能平移，底部那个框实时跟着走；反过来拖框上面也跟着动
  • 四个视图收进了一个「模式切换」按钮，点开下拉四选一 —— 原来的三段控件放不下第四项

修复

  • 看板里点开终端一片空白。而且是间歇性的：切到看板后第一次通常正常，之后就全打不开，直到切走再切回看板。所以看着像「只有某几个终端有问题」，其实跟是哪个终端无关，取决于你是第几次点开

0.4.12

2026-08-06

新增

  • 装了「笔纵画板」就能在终端里直接出图。跟 agent 说「画张封面」，它会自己开项目、建节点、挑模型、发起生成、等结果，画完把图摆到画布上给你看，不用再切过去手动点一遍。画板放在「应用程序」里就会被自动认出来，不用填任何配置 —— 但生成的时候画板得开着（工具是连到运行中的画板上的）
  • 视频、抠图、放大、扩图这些画板的能力，同样可以直接在终端里说

修复

  • 模块放大铺满时，右下角的画布工具条和缩放条不再透出来。它们本来就被盖在下面，但模块背景是半透明玻璃，于是那排图标和「100%」浮在终端输入框那一行上，跟发送、语音挤成一团。铺满的时候画布整个被盖住了，缩放画布本来也没有意义

0.4.11

2026-08-06

修复

  • 从灵动岛跳回软件后，第一次点击不再被吃掉。以前跳过来伸手点模块，那一下被系统当成「激活窗口」用掉了，看着像点不动 —— 现在看见什么就能点什么
  • 模块放大铺满后直接就能滚，不用再点一次选中它。画布已经被整个盖住了，那会儿滚轮本来就该归模块内容
  • 看板里点开终端后，上方那条控制条（角色 / 模型 / 思考档位）显示的和画布上同一个终端一致了 —— 之前它读不到配置，一律显示默认值，改了也存不住
  • 看板全屏时，上方那条可以拖动窗口了
  • 「启动」弹出的回溯确认框不再越出窗口右边缘
  • 看板左上角「进行中」那个浮标不再跟着横向滚动滑走

0.4.10

2026-08-06

改进

  • 每个终端的内存占用大幅下降。终端保留的历史行数从 2 万调到 5 千 —— 一个终端刷满长日志时，占用从 +68MB 降到 +2MB。开十几二十个终端长时间工作时差别很明显。往回翻仍有约 60 屏，agent 的审批解析不受影响

0.4.9

2026-08-06

改进

  • 画布只渲染你看得见的那部分。以前视口外几千像素的终端也一直在画，三十个终端摊开时内存会随着平移一路爬（实测 536 → 668 MB）；现在稳定在 378 MB 不动
  • 网页节点离屏两分钟就连进程一起回收，滚回来自动重建并回到你上次停留的页面。以前一个网页节点只要被看过一次，它那个进程就活到关软件为止
  • 看板里能关终端了：卡片上的终端行鼠标移上去出一个 ×，全屏时顶部条也有。以前得切回终端或画布才能关

修复

  • 看板里点开的终端翻不动历史。滚轮被画布那套「在模块上滚 = 平移画板」的逻辑截走了 —— 而且它还在偷偷平移画布，所以你在看板滚几下、切回画布会发现画面整个跑掉了
  • 画面偶尔整个往上跳、顶部被切掉。浏览器为了让某个元素可见会去滚它认为能滚的容器，而那几层容器设计上根本不该滚。改用 overflow: clip 从根上堵住，不再靠事后复位

0.4.8

2026-08-06

新增

  • 看板模式。第三种视图，跟「终端」「画布」并排。按状态分列，一个项目一张卡片：开了几个终端、每个正在忙什么、哪个在等你处理，一屏看全。点卡片铺满干活，Esc 或点「看板」回来
  • 看板的列由你自己定：新建、双击改名、删都行。删一个看板不会删掉里面的项目，它们回到「未分类」。一屏正好四列，多的往右滑
  • 拖着卡片就能改状态，而且三个视图是同一份数据 —— 画布上那个项目的框会跟着变色，分屏里右键项目也能打同一个标
  • 分屏里也能给项目打状态标了。以前状态记在画布的框上，没进过画布的项目根本无处可打

改进

  • 看板里滚轮永远滚列表，除非你真的点进了某个终端 —— 指针只是路过时不会误翻某个终端的历史
  • 往上滚出去的卡片会折叠成一摞收在顶部，滚回来自动展开

0.4.7

2026-08-05

新增

  • 卡片和按钮跟着鼠标发光。鼠标靠近画布节点的边框，那条边会渗出一圈光；主按钮划过去有一道白光斜扫而过
  • 主按钮有了立体感，按下去是真的凹进去——受光面会翻过来，不是整个往下滑
  • 终端上的 Claude / Codex 切换收成了左边一枚星星按钮。当前用哪个看图标就认得出，不再占两个文字按钮的位置；角色钉死了 CLI 时按钮会锁住并告诉你原因，以前那种情况点了没有任何反应
  • 角色选择改成翻页式：顶上一排点、中间一页角色、底下左右翻，也可以点任意一个点直接跳过去。打开时停在你正在用的那个角色上
  • 角色的「禁用工具」不用再手打名字了。按「改文件 / 跑命令 / 读代码 / 联网 / 协作 / MCP」分好组摆出来，点一下就禁，每项鼠标停上去有一句说明它是干什么的。通配符这类还是能手写，收在「手写补充」里

改进

  • 密钥柜排版松开了，标题和正文拉开距离，变量名改成两列
  • 角色列表里每项前面的彩色圆点改成了灰点，只有当前选中的那个亮——原来那些颜色看着像有分类含义，其实没有

修复

  • 灵动岛上点「知道了」不再把整个软件拽到前台。你在别的应用里干活时顺手点一下，Eas-Term 会安安静静待着——那条通知你本来就只是想让它别再响，没打算切过来
  • 角色编辑面板里的字不再叠成一团。窗口不够高时「职责契约」那一栏会被挤成零高度，里面的内容原地溢出，压在下面两栏上
  • 手快连着点两个要禁用的工具时，不会再丢掉其中一个

0.4.6

2026-08-04

修复

  • 你在软件里干活时，灵动岛不再自己冒出来。它是个层级很高的窗口，macOS 为了显示它会把你从当前桌面拽走——全屏用的时候就是「被强制切了窗口」。任务完成照旧有提示音和标题栏的待处理计数，切走之后灵动岛才登场；想主动看一眼可以右键 Dock 图标
  • 终端里的链接不再拉起 Safari。用来把链接留在软件内的那层拦截其实一直没生效（被系统的 PATH 重排挤掉了），所以 agent 一打开网页，整个应用就被顶到后台
  • 标签栏不再跟着 agent 的转圈动画一直跳字——那个字每 100 毫秒换一个，紧挨着标题栏，看着就是顶上一条在闪
  • 在终端输入框里点发送（或 ⌘↵），内容有时会停在 agent 自己的输入框里不发出去，还得再按一次回车——带图片时尤其明显。现在文本和回车分开发，中间留一点时间给 agent 反应
  • 多行内容不再被拆成好几条发出去，整段算一条

0.4.5

2026-08-04

新增

  • 画布上框选一片模块后，按删除键可以一次性删掉。Mac 键盘那个 delete 键现在也认了（原来只认 Fn+delete，按下去没反应）
  • 选中里含终端时会问一次「其中几个正在运行命令，删除会终止它们」，确认后一起删——不会逐个弹窗

改进

  • 任务完成时灵动岛只折叠着播报，不再摊开卡片挡住屏幕顶部；等待审批才自动展开（那种要你做决定，卡片上就有能直接点的选项）
  • 点折叠条只做「展开」这一件事：看清哪些完成了、哪些还在跑，不会顺手把待处理清掉
  • 展开后点灵动岛以外的地方，它会自己收起来

0.4.4

2026-08-04

新增

  • Dock 图标右键可以直接看「谁完成了、谁还在跑」，点一条直达那个终端——不用打开软件，也不用等灵动岛冒出来

改进

  • 在软件里干活时，灵动岛不再弹卡片压住屏幕顶部：只留一条折叠胶囊，上面写明是「任务完成」还是「需要审批」，想看详情自己点一下展开
  • 展开后是一份列表：完成了哪些、还在跑哪些，点任意一条跳到那个终端
  • 「知道了」不再把任务当成处理完了——它只是不再提醒你，待处理标记留着，等你真去那个终端才消掉
  • 语音输入插在光标处，不再总是接到最后面

修复

  • Windows 上用鼠标滚轮缩放画布，一格就直接掉到 20%（缩放步长是照着 macOS 触控板写的，而 Windows 滚轮一格的跨度是它的十倍）

0.4.3

2026-08-03

新增

  • 有新版本时标题栏会提示，点开能看到这一版改了什么，一键下载对应你芯片的包并打开
  • 官网多了一页更新日志，每个版本改了什么都记在那里
  • 新增匿名使用统计，默认开启，可以关：只有使用时长、启动次数、版本与系统大类、各功能的使用次数。 终端内容、命令、文件路径、项目名、与 AI 的对话、密钥，一个字节都不会离开你的电脑， 也不生成任何能跨天认出你的标识。不想要就去设置 → 隐私关掉，关掉后一条请求都不会发。 详情见隐私说明第四节——这一条是对此前「不做使用统计」那句话的改动，所以单独写出来。

改进

  • 设置里能看到当前版本号，并可手动检查更新

0.4.2

2026-08-03

新增

  • 终端多了一个文字输入框：长提示词先写好再发，中文输入法不再错位，粘贴多行也不会被逐行当成命令执行
  • 输入框支持粘贴 / 拖入图片，⌘↵ 时把图片路径连同文字一起发给 agent
  • 语音输入的结果现在落进输入框，说错了能改完再发（原先是直接写进终端）

改进

  • 设置移到标题栏最右，两种视图下位置一致；主题和提示音都收在里面
  • 画布右侧抽屉的项目高亮和文件树，会跟着你正在操作的项目走（选中 Frame 或点进终端节点）

修复

  • 语音按钮和输入框在右下角叠成一团
  • 你正盯着某个终端、它跑完了却一声不响——现在无论是否聚焦都会提醒
  • 主窗口在前台时灵动岛不再完全沉默：有新通知会露面几秒，等待审批的会一直留着
  • 贴着窗口右缘的悬浮提示被挤成一列竖排字

0.4.1

2026-08-03

新增

  • 灵动岛：把软件收起来后，屏幕顶部出现一条状态胶囊，显示有几个项目在跑； 任务完成或需要审批时弹出通知，写明项目、耗时、模型和这一轮的问答梗概，点一下直接跳回那个会话
  • 需要审批的打断可以在灵动岛上直接处理，不用切回来
  • 待处理提示音（木琴音色），任务完成和等待审批是两个不同的音，可在设置里关闭或调音量
  • 画布 Frame 支持颜色状态标签：蓝色进行中、黄色待执行、红色已完结

改进

  • Windows 包恢复跟随发布（此前需要手动补传）
