每个版本改了什么

只记你能感觉到的变化。想知道当前装的是哪一版，看应用标题栏右侧的设置里。

0.4.4

2026-08-04

新增

  • Dock 图标右键可以直接看「谁完成了、谁还在跑」，点一条直达那个终端——不用打开软件，也不用等灵动岛冒出来

改进

  • 在软件里干活时，灵动岛不再弹卡片压住屏幕顶部：只留一条折叠胶囊，上面写明是「任务完成」还是「需要审批」，想看详情自己点一下展开
  • 展开后是一份列表：完成了哪些、还在跑哪些，点任意一条跳到那个终端
  • 「知道了」不再把任务当成处理完了——它只是不再提醒你，待处理标记留着，等你真去那个终端才消掉
  • 语音输入插在光标处，不再总是接到最后面

修复

  • Windows 上用鼠标滚轮缩放画布，一格就直接掉到 20%（缩放步长是照着 macOS 触控板写的，而 Windows 滚轮一格的跨度是它的十倍）

0.4.3

2026-08-03

新增

  • 有新版本时标题栏会提示，点开能看到这一版改了什么，一键下载对应你芯片的包并打开
  • 官网多了一页更新日志，每个版本改了什么都记在那里
  • 新增匿名使用统计，默认开启，可以关：只有使用时长、启动次数、版本与系统大类、各功能的使用次数。 终端内容、命令、文件路径、项目名、与 AI 的对话、密钥，一个字节都不会离开你的电脑， 也不生成任何能跨天认出你的标识。不想要就去设置 → 隐私关掉，关掉后一条请求都不会发。 详情见隐私说明第四节——这一条是对此前「不做使用统计」那句话的改动，所以单独写出来。

改进

  • 设置里能看到当前版本号，并可手动检查更新

0.4.2

2026-08-03

新增

  • 终端多了一个文字输入框：长提示词先写好再发，中文输入法不再错位，粘贴多行也不会被逐行当成命令执行
  • 输入框支持粘贴 / 拖入图片，⌘↵ 时把图片路径连同文字一起发给 agent
  • 语音输入的结果现在落进输入框，说错了能改完再发（原先是直接写进终端）

改进

  • 设置移到标题栏最右，两种视图下位置一致；主题和提示音都收在里面
  • 画布右侧抽屉的项目高亮和文件树，会跟着你正在操作的项目走（选中 Frame 或点进终端节点）

修复

  • 语音按钮和输入框在右下角叠成一团
  • 你正盯着某个终端、它跑完了却一声不响——现在无论是否聚焦都会提醒
  • 主窗口在前台时灵动岛不再完全沉默：有新通知会露面几秒，等待审批的会一直留着
  • 贴着窗口右缘的悬浮提示被挤成一列竖排字

0.4.1

2026-08-03

新增

  • 灵动岛：把软件收起来后，屏幕顶部出现一条状态胶囊，显示有几个项目在跑； 任务完成或需要审批时弹出通知，写明项目、耗时、模型和这一轮的问答梗概，点一下直接跳回那个会话
  • 需要审批的打断可以在灵动岛上直接处理，不用切回来
  • 待处理提示音（木琴音色），任务完成和等待审批是两个不同的音，可在设置里关闭或调音量
  • 画布 Frame 支持颜色状态标签：蓝色进行中、黄色待执行、红色已完结

改进

  • Windows 包恢复跟随发布（此前需要手动补传）
