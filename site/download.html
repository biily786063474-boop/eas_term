怎么装

macOS

  1. 下载 .dmg 并打开。
  2. 把 Eas-Term 拖进「应用程序」文件夹。
  3. 双击打开。安装包已公证，不会弹「无法验证开发者」。
  4. 首次使用会请求终端所需的权限，按提示允许即可。

Windows

  1. 下载 .exe 安装包并运行。
  2. Windows 弹「已保护你的电脑」是因为这个包还没做代码签名——点「更多信息 → 仍要运行」。
  3. 按向导完成安装。
  4. 从开始菜单启动 Eas-Term。

常见问题

要单独装 MCP 服务吗？

不用。画板控制的 13 个工具随应用内置，装完就能被 Claude Code / Codex 调用，不用写配置文件。

Claude Code 和 Codex 需要自己装吗？

需要。Eas-Term 负责起会话、记住模型和思考档位，CLI 本身按各自官方方式安装即可。

语音输入会把音频传到云端吗？

不会。语音识别在本地跑，音频不上传。

Intel Mac 能用吗？

能。macOS 版分成两个包，Intel 机器下「Intel 芯片」那个即可。 不确定自己是哪种就点屏幕左上角 →「关于本机」，看「芯片」那一行； 页面在能认出你的机器时也会直接标出来。

为什么不做成一个通用包？

做过，199 MB。拆成两个之后每个约 110 MB，下载少等一半时间 —— 代价是要你选一次，所以我们尽量把这一步做得不用想。
