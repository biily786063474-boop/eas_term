How to install

macOS

  1. Download the .dmg and open it.
  2. Drag Eas-Term into your Applications folder.
  3. Double-click to launch. The build is notarized, so you won't see "unidentified developer".
  4. On first use it asks for the permissions a terminal needs. Just allow them when prompted.

Windows

  1. Download the .exe installer and run it.
  2. If Windows says "Windows protected your PC", that's because this build isn't code-signed yet. Click "More info → Run anyway".
  3. Follow the wizard to finish installing.
  4. Launch Eas-Term from the Start menu.

FAQ

Do I need to install an MCP server separately?

No. The 13 canvas-control tools are bundled with the app, and Claude Code / Codex can call them as soon as it's installed. No config files to write.

Do I need to install Claude Code and Codex myself?

Yes. Eas-Term starts the sessions and remembers your model and reasoning level. Install the CLIs themselves the official way.

Does voice input send my audio to the cloud?

No. Speech recognition runs locally, and audio is never uploaded.

Does it work on Intel Macs?

Yes. The macOS version comes as two builds; on an Intel machine, grab the "Intel" one. If you're not sure which you have, click in the top-left corner → "About This Mac" and check the "Chip" line. When this page can recognize your machine, it'll point you to the right one too.

Why not ship a single universal build?

We did: 199 MB. Split in two, each is about 110 MB, so the download takes half as long. The trade-off is that you have to pick once, so we've tried to make that choice a no-brainer.
