Workflows

Put the terminal and the canvas together, and your workflow stops jumping around

The AI finishes, you see it on the canvas

Ask Claude Code in the terminal to build a page, and the HTML it produces opens as a preview node on the canvas, right next to the terminal. Change it, look at it, repeat, without hunting between an editor, a browser and a terminal.

  • Web preview nodes render with embedded Chromium, and links opened from the CLI stay inside the app
  • Code, images, Markdown and design files are all modules on the same canvas
  • Zoom and pan the canvas, with modules grouped into Frames by project

One set of tabs per project, terminals split however you like

Split horizontally or vertically like in your editor and run several terminals side by side. Each project gets its own set of tabs, so switching projects switches the whole context. No more cd-ing back in.

  • Split any way you want, and the layout stays with the project
  • Activity monitor: see at a glance which terminals still have processes running
  • Closing a pane or quitting the app asks first, so you never kill a running command by accident

One AI session per terminal, no crossed wires

Launch Claude Code or Codex from any terminal node in one click, and it remembers your model and reasoning level. Sessions are tied to their terminal, so going back through history only shows that terminal's conversation, never someone else's.

  • One-click Claude Code / Codex launch, with your settings remembered
  • Sessions are tied to terminals, so multiple agents run side by side without interfering
  • Offline voice input: speak and the text goes into the terminal, processed locally, never uploaded

Read docs, edit copy, browse commits, all without leaving the canvas

.md files render as formatted documents by default, with a one-click toggle to source in the bottom-right corner. Every text preview can be edited and saved in place. Git history, diffs and reverts are canvas modules too.

  • Formatted Markdown preview, switch between source and rendered any time
  • Edit text previews in place and save straight back to the file
  • Git history, diffs and reverts, all inside canvas modules

Features

What you get out of the box

Multiple terminals, any split

Split horizontally or vertically like in your editor, with one set of tabs per project.

Infinite canvas

Terminals, web previews, code, images and design files are all modules on the canvas, grouped into Frames by project. Zoom and pan freely.

AI agent console

Launch Claude Code / Codex from any terminal node in one click, with your model and reasoning level remembered. Sessions are tied to their terminal, so history never gets mixed up.

MCP canvas control

The AI can drive the canvas directly: open its HTML output as a preview, tidy the layout, send a notification when it's done. 13 tools, ready to go with zero configuration.

Embedded Chromium browser

Links opened by CLI tools in the terminal open right on the canvas instead of kicking you out.

Offline voice input

Speak and the text goes into the terminal. Runs locally, never uploaded.

Design module

Design and animate right on the canvas, then export to your project's demo/ folder.

Formatted Markdown preview

.md files render formatted by default, with a source toggle in the bottom-right. Every text preview can be edited and saved in place.

Git version control

Commit history, diffs and reverts, all in canvas modules.

Personal knowledge base

Just a folder of Markdown, with a file tree and knowledge graph in the left drawer. Drop material into the inbox and the AI files it, writes notes and keeps the log by your rules. Works with both Claude Code and Codex.

Agent roles

Scout, builder, reviewer, writer… Bind a role to each new session, each with its own conventions, model and tool permissions. Reorder roles, recategorize them, or create your own.

Design glossary

242 interaction, motion and UI terms, each with an illustration and implementation notes. One click drops the description into your terminal prompt. For when you can't quite put the effect you want into words.

AI Integration

Let the AI lay out the canvas itself

Eas-Term ships with its own MCP server, wired up the moment you install the app. Claude Code or Codex running in the terminal doesn't just hand you back a wall of text. It can put its output right in front of you.

What the AI can do

  • Open generated HTML / images / code as preview nodes, right in front of you
  • Open URLs, or maximize a node so you can take a closer look
  • Tidy up Frame layouts and line up scattered modules
  • Open new terminal nodes, rename nodes, close the ones you don't need
  • Pin sticky notes with explanations, and send a system notification when a task finishes

13 tools in total, bundled with the app. No config files to write by hand.

Working with the CLI

  • Launch Claude Code or Codex from any terminal node in one click
  • Pick your model and reasoning level once, and it's remembered for next time
  • Sessions and terminals are paired one to one, so even with several agents open nothing leaks into the wrong terminal
  • Links the agent opens land in the canvas's embedded browser, so your eyes never leave the workbench
