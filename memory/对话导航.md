# Claude Code 对话导航（读 transcript 回看）

> 立项 2026-07-09。用户想要：点击导航直接跳到某条对话。因 Claude Code 是备用屏、终端拿不到实时滚动，
> 改为读 Claude Code 自己保存的 transcript 做「只读回看」的对话目录。用户拍板：主区域「对话导航」大视图。

## 数据来源（已用真实 transcript 验证）
- 文件：`~/.claude/projects/<编码cwd>/<sessionId>.jsonl`，编码 = `cwd.replace(/[^a-zA-Z0-9]/g,'-')`。
- 同一 cwd 多份会话时取**最近修改**那份（当前活跃会话）。
- 每行一个 JSON：`type: user/assistant`、`message.content`(str 或 block 列表)、`uuid`、`timestamp`、`isSidechain`、`sessionId`。
- 用户真实消息过滤：type=user 且非 sidechain，content 有文本，排除 `Base directory for this skill` / `<...>` / `[Request interrupted` / `Caveat:`；连续相同文本去重（中断重发）。
- 回答 = 该用户消息之后、下一条用户消息之前的所有 assistant 文本块（tool_use 标注为「〔调用工具：X〕」）。
- 验证：对本会话 jsonl 跑通，抽出 10 条用户消息 + 正确配对回答。

## 实现
- 后端 `src/main/session.ts`：`session:index(cwd)`→{found, sessionId, turns[]}；`session:exchange(cwd,uuid)`→{userText, assistantText, at}。按文件 mtime 缓存解析结果（活跃会话 mtime 常变会重解析，可接受）。`index.ts` 注册。
- 类型 `SessionTurn/SessionExchange/SessionIndex`；preload `api.session.*`。
- 前端：PaneKind 加 `'chat'`(PaneState {kind:'chat',cwd})、`store.openChat`、`ChatNavView.tsx`(左消息目录+右回看)、PaneView(KIND_LABEL + 渲染 + **终端头部 MessageIcon 按钮**触发 openChat)、Icons.MessageIcon、styles `.chat-*`。
- 入口：终端面板头部的对话气泡图标 → 主区域开「对话导航」。

## 诚实边界 / 待验
- **点击=在 Eas-Term 里只读回看**，不是滚动实时 Claude Code 画面（终端控制不了备用屏内部滚动）——已跟用户讲清并认可。
- 局限：同一 cwd 多个 claude 会话时只认最近那份；claude 若在子目录启动则 cwd 对不上（用了 tab.cwd）。
- **UI 渲染未能亲手截图验证**（用户打包版多个活跃 Claude 会话一直抢焦点，调试实例驱动不稳）；数据层已实锤，UI 套用已验证过的历史大视图结构。待用户在 dev 里眼验。
