使用规则

Supabase 界面以暖中性三层构建深度，而非纯黑或纯灰。卡片与输入框用 #ffffff 浮于 bg-100 之上；代码块与嵌套区域用 bg-200。页面级可叠加极淡的品牌色 radial 光晕。

Motion Rules (Supabase from source kit):
- Hover: 120ms, easing ease-out
- Medium: 150ms (composer box-shadow, swatch hover)
- Exit: ease-out
- Linear: linear
- Focus: .input:focus → border #171717 + 1px ring
- Button active: scale(0.98) (kit .btn:active)
- Avoid bounce, spin, exaggerated scale
规范 · Do's & Don'ts整套设计系统的正确与错误用法
色彩
沿用既定调色板
只用 Supabase Dashboard token（--sb-green / --sb-ink / --sb-bg）。
Aa
字体
保持 Circular / Source Code Pro
UI 用 Circular（Helvetica Neue / system fallback）；SQL / token / meta 用 Source Code Pro。Circular 为专有字体，需本机或授权加载。

使用 token 档位圆角
从 sm 4px … md 6px … lg 8px … xl 12px · full 中取值，统一弧度。
按钮
组件
复用原生组件与状态
直接调用 kit 内组件，沿用其内边距与层级。
标志
保持比例并按底色反色
等比缩放、留足安全间距，深底用浅色标志。
色彩
擅自引入新颜色
不要使用调色板之外的高饱和或随机色值。
Aa
字体

圆角

按钮
组件

Marketplace Skill

用于生成 Supabase 首页、目的地页、搜索结果页。

  • Dashboard：侧栏 sb-navitem + table/cards + composer。
  • 引用 #i-* sprite；焦点环 Brand Green soft glow。
  • Brand Green #3ecf8e 用于 sb-btn--primary。

Search & Booking Skill

用于生成搜索、筛选、预订流程界面。

  • Composer 字段：地点 / 入住 / 退房 / 入住人（来自 kit）。
  • Filter chips：.active / .brand 状态来自 kit §8。
  • Listing card 280×280 + 价格 + 评分结构保持一致。

Host / Account Skill

用于生成房东中心、账户设置（沿用 kit 表单组件）。

  • 表单：.field-stack + .input h44 r8。
  • Secondary 按钮 #222 底；Danger #ea4f3d。
  • Elevation el-1…el-3 建立层级，不用玻璃拟态。
生成防跑偏规则给 Coding Agent 的正负约束

Do

  • 使用 #ffffff / #fbfcfd 作为基础背景（kit Background swatches），保持柔和与可信赖。
  • 优先使用细边框、轻阴影和明确留白建立层次。
  • 复用 kit 内 .sb-btn / .sb-composer / .sb-navitem / .sb-chip / .sb-card 规则。
  • 标题可以更有编辑感，但正文必须保持清晰易读。
  • 新增页面前先读取 DESIGN.md，再决定布局与组件。

Don’t

  • 不要使用默认 Tailwind / shadcn 的蓝紫色 SaaS 风格。
  • 不要加入玻璃拟态、霓虹光、复杂渐变或赛博质感。
  • 不要随意新增字体、圆角、阴影和 container 宽度。
  • 不要把 Brand Green #3ecf8e 作为大面积背景或过度强调色。
  • 不要为了丰富而添加无意义插画、3D 或复杂动效。
