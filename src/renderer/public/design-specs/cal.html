# Cal.com Design Kit Design Kit

## Source
Event Types · app.cal.com · 148 CSS tokens · 159 icons · 9 component categories · Inter 400–700
Source file: Cal-kit.html

## Visual Language
- Canvas #f8f9fb; surface #ffffff; muted #f6f7f9
- Brand Ink CTA #111827 (hover #0f0f0f) — not green
- Success #19a974 for confirmed / positive states only
- Inter · Event Types dashboard · sidebar + event list + booking empty

## Guardrails
- Light surfaces · strong grid · minimal shadow
- 8px button / input radius · 12px cards / panels · ink focus ring
- Do not use green as primary CTA
语义化映射
anti-drift layer
Primary
Cal.com Accent，只用于 CTA、品牌标记、关键状态，不大面积铺满。
Surface
#ffffff / #f8f9fb 作为主体背景，强调温和、可信赖、低噪音。
Text
#070a0d 用于主文字，灰阶文字用于说明、meta、caption。
Structure
Strong Grid，源 kit 页面 1100px 居中、14px bento gap、4px spacing base。
Expression
Event Types Dashboard，Inter · Brand Ink CTA，但整体保持 UI 的清晰和克制。

Marketplace Skill

用于生成 Cal.com 首页、目的地页、搜索结果页。

  • Event Types：侧栏 + list/cards + ink primary CTA。
  • 引用 #cal-icon-* sprite；主按钮近黑 ink。
  • Brand Ink #111827 用于 cal-btn-primary。

Search & Booking Skill

用于生成搜索、筛选、预订流程界面。

  • Composer 字段：地点 / 入住 / 退房 / 入住人（来自 kit）。
  • Filter chips：.active / .brand 状态来自 kit §8。
  • Listing card 280×280 + 价格 + 评分结构保持一致。

Host / Account Skill

用于生成房东中心、账户设置（沿用 kit 表单组件）。

  • 表单：.field-stack + .input h44 r8。
  • Secondary 按钮 #222 底；Danger #641717。
  • Elevation el-1…el-3 建立层级，不用玻璃拟态。
生成防跑偏规则给 Coding Agent 的正负约束

Do

  • 使用 #ffffff / #f8f9fb 作为基础背景（kit Background swatches），保持柔和与可信赖。
  • 优先使用细边框、轻阴影和明确留白建立层次。
  • 复用 kit 内 .cal-btn / .composer / .nav-item / .chip / .event-card 规则。
  • 标题可以更有编辑感，但正文必须保持清晰易读。
  • 新增页面前先读取 DESIGN.md，再决定布局与组件。

Don’t

  • 不要使用默认 Tailwind / shadcn 的蓝紫色 SaaS 风格。
  • 不要加入玻璃拟态、霓虹光、复杂渐变或赛博质感。
  • 不要随意新增字体、圆角、阴影和 container 宽度。
  • 不要把 Brand Ink #111827 作为大面积背景或过度强调色。
  • 不要为了丰富而添加无意义插画、3D 或复杂动效。
