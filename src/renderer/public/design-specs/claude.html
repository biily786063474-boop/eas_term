Claude Style Prompt

这是用户最常用的入口：不需要理解完整 DESIGN.md，直接复制这段上下文给 AI，就能生成更接近 Claude 风格的页面。 

You are building a Claude-style interface.

Use this design kit as the visual source of truth.

Style:
Warm, quiet, minimal, editorial, reading-first, trustworthy.

Foundation:
- Use warm neutral backgrounds: #f8f8f6, #efede8, #e8e5de.
- Use Claude orange only for primary CTA, brand mark, and key highlights.
- Use Söhne for UI/body/headings, Tiempos Text only for editorial emphasis, Söhne Mono for code/specs.
- Use generous whitespace, subtle borders, low shadows, and calm hierarchy.
- Use 4px spacing base, 1120px max content width, 14px bento/grid gap.

Components:
- Primary button: pill radius, orange background, one main action only.
- Secondary/ghost actions must stay quiet and never compete with primary CTA.
- Cards: 16–20px radius, thin border, soft neutral surface, no heavy shadow.
- Composer/input: white surface, subtle border, 16px radius, readable text.
- Navigation: quiet sidebar on bg-200, active item uses bg-300 (never blue).

Motion:
- Hover: 150ms, easing cubic-bezier(.165,.85,.45,1).
- Entrance: 240–280ms, fade/translate only.
- Focus: 3px subtle ring for accessibility; no blue glow.
- Avoid bounce, spin, exaggerated scale, scroll jank.

Avoid:
- Blue/purple SaaS gradients.
- Glassmorphism, neon glow, cyberpunk, gaming, heavy 3D.
- Bootstrap/Material/shadcn default look.
- More than one primary CTA per section.
- Random new fonts, random radius, random container widths.

When generating a page, first choose the closest Pattern (Navigation for app shells), then apply Foundation + Components + Guardrails.

# Claude.ai Design Kit

Design Intent
Create quiet, warm, trustworthy AI product interfaces. The system should feel editorial, precise and calm — not generic SaaS, not futuristic neon.

Visual Language
- Warm neutral surfaces: #f8f8f6, #efede8, #e8e5de.
- Claude orange is an accent, never a full-page decoration.
- Prefer subtle borders over heavy shadows.
- Use spacious rhythm, soft contrast and restrained components.
- Interface should feel text-first, intelligent and composed.

Typography Rules
- Sans: Söhne for UI, headings and body.
- Serif: Tiempos Text only for editorial emphasis or brand moments.
- Mono: Söhne Mono only for code, tokens, specs and metadata.
- Heading: bold / tight tracking / compact line-height.
- Body: regular / readable line-height / no excessive letter spacing.

Layout Rules
- Page max width: 1120px.
- Outer padding: 28px desktop, 20px mobile.
- Bento gap: 14px.
- Cards: 16–20px radius, quiet borders, low shadow.
- Use strong grid, open framing, full-bleed feeling inside constrained canvas.
- Avoid random container widths across pages.

Component Rules
- Buttons use pill radius by default.
- Composer is the primary interaction component: white surface, 16px radius, subtle border.
- Cards should be calm, low contrast, with clear hierarchy.
- Chips are secondary actions; never compete with primary CTA.
- Icons are filled, simple, 20px base size.

Motion Rules
- Hover duration: 150–200ms.
- Entrance duration: 240–320ms.
- Easing: cubic-bezier(.165,.85,.45,1).
- Use fade/translate only; avoid bounce, spin, exaggerated scale.

Guardrails
- Do not use blue/purple SaaS gradients.
- Do not use glassmorphism or cyberpunk glow.
- Do not create Material Design or Bootstrap-like components.
- Do not overuse orange; it is for focus and brand punctuation only.
- Do not introduce extra fonts.
- Do not change radius/spacing arbitrarily.

Landing Skill

用于生成官网、产品页、活动页，保持 Claude 式温和与高级感。

  • Hero 使用强标题 + 克制副文案 + 单一 CTA。
  • 模块采用 bento grid，但避免过度装饰。

  • 用户消息使用浅色 bubble，助手消息保持开放排版。

生成防跑偏规则给 Coding Agent 的正负约束

Do

  • 使用温暖中性色作为基础背景，保持柔和与可信赖。
  • 优先使用细边框、轻阴影和明确留白建立层次。
  • 所有页面复用同一套 button、composer、card、chip、nav 规则。
  • 标题可以更有编辑感，但正文必须保持清晰易读。
  • 新增页面前先读取 DESIGN.md，再决定布局与组件。

Don’t

  • 不要使用默认 Tailwind / shadcn 的蓝紫色 SaaS 风格。
  • 不要加入玻璃拟态、霓虹光、复杂渐变或赛博质感。
  • 不要随意新增字体、圆角、阴影和 container 宽度。
  • 不要把橙色作为大面积背景或过度强调色。
  • 不要为了丰富而添加无意义插画、3D 或复杂动效。
