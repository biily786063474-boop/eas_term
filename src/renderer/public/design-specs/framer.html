Marketplace Skill

用于生成 Framer Community Feed 首页、目的地页、搜索结果页。

  • Community Feed：深色 canvas + post-card + like/comment。
  • 引用 community-sprite #id；navbar + bottom-bar。
  • Primary Blue #3b75fb 用于 btn-solid。

Search & Booking Skill

用于生成搜索、筛选、预订流程界面。

  • Composer 字段：地点 / 入住 / 退房 / 入住人（来自 kit）。
  • Filter chips：.active / .brand 状态来自 kit §8。
  • Listing card 280×280 + 价格 + 评分结构保持一致。

Host / Account Skill

用于生成房东中心、账户设置（沿用 kit 表单组件）。

  • 表单：.field-stack + .input h44 r8。
  • Secondary 按钮 #222 底；Danger #ea4f3d。
  • Elevation el-1…el-3 建立层级，不用玻璃拟态。
生成防跑偏规则给 Coding Agent 的正负约束

Do

  • 使用 #ffffff / #f4f4f5 作为基础背景（kit Background swatches），保持柔和与可信赖。
  • 优先使用细边框、轻阴影和明确留白建立层次。
  • 复用 kit 内 .btn-solid / .composer / .nav-item / .post-card / .bottom-bar 规则。
  • 标题可以更有编辑感，但正文必须保持清晰易读。
  • 新增页面前先读取 DESIGN.md，再决定布局与组件。

Don’t

  • 不要使用默认 Tailwind / shadcn 的蓝紫色 SaaS 风格。
  • 不要加入玻璃拟态、霓虹光、复杂渐变或赛博质感。
  • 不要随意新增字体、圆角、阴影和 container 宽度。
  • 不要把 Brand Blue #2c46f1 作为大面积背景或过度强调色。
  • 不要为了丰富而添加无意义插画、3D 或复杂动效。
