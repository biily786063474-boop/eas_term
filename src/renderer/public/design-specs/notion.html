You are building a Notion-style interface.

Use Notion Design Kit as the visual source of truth (scraped from notion.so).

Style:
Clean workspace UI — white cards on warm gray canvas, blue accent for links/focus/primary actions.

Foundation:
- Surfaces: #ffffff (primary) / #f9f8f7 (secondary) / rgba(42,28,0,0.07) (tertiary wash)
- Text: #2c2c2b / #7d7a75 / #8e8b86
- Accent: #0088ff (links, focus ring, primary button) — hover #0077e6
- Semantic: success #27ae60, warning #f2994a, destructive #eb5757
- Font (product): -apple-system, BlinkMacSystemFont, Segoe UI stack
- Font (kit doc UI): PingFang SC for Chinese labels
- Max width: 1200px
- Typography: H1 40px / Bold / -0.025em / Body 14px / Regular / 1.5

Components (from source kit):
- btn-primary / btn-secondary / btn-ghost / btn-destructive
- composer input with focus border #0088ff
- nav-item sidebar rows, chip/tag pills
- heading-1/2/3 scale

Motion:
- Fast: 120ms; normal: 200ms

Avoid:
- Airbnb Rausch naming, gradient CTA, or listing cards
- Claude orange / ChatGPT ds-composer patterns
- Invented semantic colors (#008A05 Info blue) not in source swatches

# Notion Design Kit Design Kit

## Source
Notion Design Kit 设计系统 — AI-first 展示套件
Source file: Notion-kit.html

## Design Intent
Notion workspace UI — calm neutral surfaces, system UI typography, blue accent for focus and primary actions.

## Visual Language
- Primary bg: #ffffff; secondary: #f9f8f7; tertiary wash: rgba(42,28,0,0.07)
- Text: #2c2c2b / #7d7a75 / #8e8b86
- Accent: #0088ff; hover: #0077e6
- Semantic: success #27ae60, warning #f2994a, destructive #eb5757
- Borders: #e0dfed / #f0efed

## Typography
- Sans: -apple-system, BlinkMacSystemFont, Segoe UI, Helvetica, Arial
- Serif (editorial): Lyon-Text, Georgia
- Mono: iawriter-mono, Menlo
- Scale: H1: 40px / Bold / -0.025em; H2: 30px / SemiBold / -0.02em; H3: 24px / SemiBold / -0.01em; Body MD: 16px / Regular / 1.5; Body Base: 14px / Regular / 1.5; Body SM: 13px / Regular / 1.5; Caption: 12px / Regular / 1.5; Mono: 14px / iawriter-mono; Serif: 16px / Lyon-Text, Georgia

## Spacing
2px 1, 4px 2, 6px 3, 8px 4, 10px 5, 12px 6, 16px 8, 20px 10, 24px 12, 32px 16, 40px 20, 48px 24

## Radius
0px, 3px (sm), 3.5px (avatar), 6px (md), 8px (lg), 12px (xl), pill

## Motion
- Fast: 120ms; normal: 200ms

## Components
- Buttons, icon-btn, nav-item, chip, composer, heading scale
- Icons: 35 inline symbols (#icon-*)

## Guardrails
- Use only colors from source swatch-card grid
- No Airbnb Rausch gradient or invented Info blue
- System UI font stack — not a custom Notion webfont in this kit

用于生成 Notion 工作区、侧栏 + 页面编辑布局。

  • 侧栏 nav-item：工作区 / 页面 / 数据库 + icon。

生成防跑偏规则给 Coding Agent 的正负约束

Do

  • 使用 #f9f8f7 / #ffffff 作为基础背景（kit Background swatches），保持柔和与可信赖。
  • 优先使用细边框、轻阴影和明确留白建立层次。
  • 复用 kit 内 .btn / .composer / .nav-item / .chip 规则。
  • 标题可以更有编辑感，但正文必须保持清晰易读。
  • 新增页面前先读取 DESIGN.md，再决定布局与组件。

Don’t

  • 不要使用默认 Tailwind / shadcn 的蓝紫色 SaaS 风格。
  • 不要加入玻璃拟态、霓虹光、复杂渐变或赛博质感。
  • 不要随意新增字体、圆角、阴影和 container 宽度。
  • 不要把 Accent #0088ff 作为大面积背景或过度强调色。
  • 不要为了丰富而添加无意义插画、3D 或复杂动效。
