# Perplexity Kit Design Kit

## Source
从 Perplexity.ai 真站 DOM 提取的完整设计 Token 与组件规范。所有数据来自 getComputedStyle 真值。
Source file: perplexity-kit.html

## Design Intent
Perplexity.ai home UI — warm neutral canvas, centered composer, sidebar nav, mode chips.

## Visual Language
- Canvas: #fafaf9; surface: #ffffff; quiet: rgba(39, 26, 0, 0.07)
- Text: rgb(39, 37, 30) / rgba(39, 37, 30, 0.65) / rgba(39, 37, 30, 0.45)
- Button ink #272520; inverse text #fdfbfa
- Borders: rgba(39, 26, 0, 0.08) / rgba(39, 26, 0, 0.14)

## Typography
- Product UI: system-ui stack (no custom web font)
- Heading XL 30px/400 · Body/Input 16px · Button 14px/500

## Spacing
4px grid: one 1px, 2xs 2px, xs 4px, sm 6px, md 8px, ml 10px, lg 12px, xl 16px, 2xl 20px, 3xl 24px, 4xl 28px, 5xl 32px, 6xl 36px, 7xl 40px, 8xl 44px, 9xl 48px

## Radius
9999px Button, 24px Composer, 12px Card, 10px Nav item, 6px Badge

## Motion
- Hover: 150ms
- Medium: 200ms

## Components
- Buttons: quiet / outline / primary #272520 / ghost icon
- Composer: 24px radius, 580px max, submit chip
- Chips: active quiet fill, dashed border variant
- Nav: nav-item with sprite icons
- Icons: 618 sprite ids (pplx-icon-* / pplx-logo-*)

## Guardrails
- Use only tokens from source kit swatches
- Do not use Airbnb Rausch or ChatGPT ds-* components
- Reference icons via &lt;use href="#pplx-icon-search"/&gt; pattern

Do

  • 使用 #fafaf9 / #ffffff 作为基础背景（kit Background swatches），保持柔和与可信赖。
  • 优先使用细边框、轻阴影和明确留白建立层次。
  • 复用 kit 内 .btn / .composer / .chip / .nav-item 规则。
  • 标题可以更有编辑感，但正文必须保持清晰易读。
  • 新增页面前先读取 DESIGN.md，再决定布局与组件。

Don’t

  • 不要使用默认 Tailwind / shadcn 的蓝紫色 SaaS 风格。
  • 不要加入玻璃拟态、霓虹光、复杂渐变或赛博质感。
  • 不要随意新增字体、圆角、阴影和 container 宽度。
  • 不要把 Button Ink #272520 作为大面积背景或过度强调色。
  • 不要为了丰富而添加无意义插画、3D 或复杂动效。
