Motion Rules (v0 from source kit):
- Hover: 150ms, easing all 0.15s ease
- Medium: 200ms (composer box-shadow, swatch hover)
- Exit: cubic-bezier(0.4,0,1,1)

生成防跑偏规则给 Coding Agent 的正负约束

Do

  • 使用 #fafafa / #ffffff 作为基础背景（kit Background swatches），保持柔和与可信赖。
  • 优先使用细边框、轻阴影和明确留白建立层次。
  • 复用 kit 内 .btn / .composer / .nav-item / .chip / .btn-icon-round 规则。
  • 标题可以更有编辑感，但正文必须保持清晰易读。
  • 新增页面前先读取 DESIGN.md，再决定布局与组件。

Don’t

  • 不要使用默认 Tailwind / shadcn 的蓝紫色 SaaS 风格。
  • 不要加入玻璃拟态、霓虹光、复杂渐变或赛博质感。
  • 不要随意新增字体、圆角、阴影和 container 宽度。
  • 不要把 Primary #000000 作为大面积背景或过度强调色。
  • 不要为了丰富而添加无意义插画、3D 或复杂动效。
