# 插件独立更新补齐（用户已批准）

1. 在隔离 worktree 将既有市场实现与 origin/main 0.4.103 合并，保留事件宿主、热插拔与配置安全。
2. 市场显式「检查更新」「更新」；未知版本/内置副本使用「安装独立版」而非假装可比较版本；同名用户副本遮挡内置副本时提示。
3. 安装确认覆盖 canvas / event / remote 权限，保留记录与配置，不自动授权全局记录；沿用下载校验/活动宿主门禁/普通 IO 失败回退。
4. 最新时间线生成独立版本、兼容性要求和不可变发布包；增量保留线上六个既有插件及 v1 目录，不用默认开发目录覆盖生产。
5. 隔离真实应用验证未知版本迁移、版本更新/失败保持、数据与授权不变；构建打开眼验。随后才可做应用发布验收与 unbundle，不能仅删掉内置包让既有用户失去入口。

边界：本轮不等于原 Demo 32 个连接器全部完成；普通回退不等于崩溃事务。发布前须独立 npm ci、正式包与多平台验证；Computer Use 指针未解决，不混入本轮结论。
