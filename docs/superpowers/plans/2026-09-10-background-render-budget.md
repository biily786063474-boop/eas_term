# 后台数据与渲染解耦
目标：不停止任务和数据接收，后台取消装饰绘制；不使用丢弃终端文本来降内存。
1. 终端写入独立调度器：前台合帧，后台由到达事件/解析回调驱动，不等待rAF；单写入飞行并分块，卸载清理。
2. 移除全局禁节流参数，主窗口暂保留 backgroundThrottling:false（xterm异步解析/状态接收），网页恢复默认；背景CSS动效暂停。
3. 单测模拟rAF永不回调、慢解析、持续输出/恢复及释放；真实独立app最小化输出、CPU对比及长跑。
4. 其他排查：页面120秒回收、无限CSS动画、队列/监听释放。没有长跑证据不得宣称长时卡顿已杜绝。

进度：实现及构建/完整check通过；6000+30000行真实后台输出验证通过。发现并修正星空焦点/视口状态相互覆盖。前台恢复截图受同路径多实例识别限制未完成；Windows、三CLI真实任务及小时级多模块压测未完成。证据与具体边界见docs/verification/background-render/README.md。
