# 三 CLI 返回图片实现计划

目标：Claude/Codex/OMP 已传出的图片块统一显示、放大和恢复历史；不推断 CLI 未传出的像素。

采用现有聊天历史存储，不新增任意路径写入或网络抓图接口。图片以严格校验的 PNG/JPEG/GIF/WebP data URL 表示，单图 2 MiB、单结果最多 4 图，历史合计 8 MiB；超限显式降级提示。不接受 SVG、远端 URL 或文件路径作为图片块。Markdown 原链路不扩大权限。

- [x] 共用图片校验与工具结果归一化：先失败测试，再实现；不将 base64 作为工具文本输出。
- [x] 三 CLI 翻译器分别接工具图片；支持实际文本消息图片块（Claude source / OMP content）。协议没有像素时只显示未传图提示，不能凭路径绕读。
- [x] 通用事件、归约器、历史裁剪贯通图片，保持旧记录兼容及独立容量限制。
- [x] UI 图片条独立于工具文本折叠，点击放大、Esc/按钮关闭，加载失败明确显示。
- [x] 单测、类型与构建；隔离 Electron 读取持久化夹具验证图片加载、预览、重载，三 CLI 翻译夹具分别验证。真实模型端到端未跑不得声称已跑。
