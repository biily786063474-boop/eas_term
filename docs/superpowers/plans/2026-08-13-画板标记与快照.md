# 画板标记置顶与面板快照 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让用户画的标记浮在活终端之上，加一个「拍下当前画板 → 存进项目 → 一键送进对话」的快照链路，顺带修两处独立的小缺口。

**Architecture:** 标记从 `CanvasStage` 内部提成独立的 `CanvasShapeLayer`，渲染在 `PaneLayer` 之后、用同一套视口变换对齐（`.canvas-world` 带 transform、自成层叠上下文，加 z-index 逃不出去）。快照走 Electron 的 `webContents.capturePage(rect)`，拍照前给根节点挂 `.snapshotting` 把 11 个浮层 `visibility:hidden`，拍完摘掉。送进输入框复用 `TerminalInput` 已有的 `PastedImg.external` 机制。

**Tech Stack:** Electron + React 18 + TypeScript + zustand；测试用 Node 26 原生 `node --test`（`.ts` 直接跑，零测试框架依赖）。

## Global Constraints

- **标记层的指针事件**：层容器 `pointer-events: none`，每个 shape 自身 `pointer-events: auto`。这条错了整个画布点不动。
- **截图必须排除那 16 个浮层**：`canvas-drawer` / `wiki-drawer` / `cd-edge` / `wk-edge` / `canvas-minimap` / `canvas-minimap-mini` / `crm` / `crm-mini` / `canvas-toolbar` / `canvas-zoombar` / `ctoolbar-mini` / `cd-attn-bubble` / `cdict-bubble` / `cdict-pop` / `build-stamp` / `csnap-err`。
  判据是「**默认就在、用户关不掉**」—— 那种一定会进图。写这份清单时漏了 5 个，都是真机看图才发现的：
  `crm` 是运行监视的**展开态**（`collapsed` 初值 `useState(false)`，有 agent 在跑时默认就展开，
  原清单只有收起态的 `crm-mini`）；词典气泡与版本水印是常驻的；`csnap-err` 是快照自己的失败提示条，
  不清空的话上一次的红字会串进下一次成功的图里。
  **验这条时必须让被藏的东西真的在 DOM 里** —— 运行监视在没有 agent 跑时整个 `return null`，
  拿「图里没有它」当通过是假阳性。
- **藏浮层用 `visibility: hidden`**，不许用 `display: none`（触发重排，抽屉宽度变化会让画布跳）也不许用 `opacity: 0`（仍参与合成，可能在图里留痕）。
- **没选中工作区时快照按钮禁用**，hover 提示恰好是 **「请在画板中选择一个工作区」**。
- **快照存 `<项目>/screenshot/<YYYY-MM-DD>/<YYYYMMDD-HHmmss>-<当日序号>.png`**，序号从 1 起。
- **「最近」的文档过滤必须做在主进程扫描时、在 `slice(0, limit)` 之前**。做在渲染层会正好起反作用（实测：本项目最近 60 个里文档类只有 3 个，全库有 64 个）。
- **不动 `.gitignore`**（`screenshot/` 要不要忽略是用户的决定）。
- **不改 `canvas_get_state` 的返回结构**，只改它的描述。
- 测试用 `node --test`，不得引入测试框架依赖，不得改 `package.json`。
- 现有测试一个都不能坏（当前 64 个）。

```ts
// 快照的目录与文件名计算。
//
// **不引 electron、不碰文件系统**：这样能被 node --test 直接加载。
// 当天已有哪些文件由调用方读盘后传进来 —— 纯计算才测得住，
// 而「序号该是几」这种事错了，用户会看到两张同名的图互相覆盖。
import path from 'path'

const p2 = (n: number): string => String(n).padStart(2, '0')

/**
 * 这一张快照该写到哪。
 *
 * 按**天**分文件夹：按小时分会碎成一堆，按月分一个目录几百张。
 * 文件名同时带完整时间戳和当日序号 —— 时间戳保证排序与唯一，
 * 序号让人能说「今天第 3 张」。
 */
export function snapshotTarget(
  projectPath: string,
  now: Date,
  existing: string[]
): { dir: string; file: string } {
  const y = now.getFullYear()
  const mo = p2(now.getMonth() + 1)
  const d = p2(now.getDate())
  const stamp = `${y}${mo}${d}-${p2(now.getHours())}${p2(now.getMinutes())}${p2(now.getSeconds())}`
  const dir = path.join(projectPath, 'screenshot', `${y}-${mo}-${d}`)
  // 只数 .png：目录里可能有别人放的东西，把它们算进序号会让编号跳
  const n = existing.filter((f) => f.toLowerCase().endsWith('.png')).length + 1
  return { dir, file: path.join(dir, `${stamp}-${n}.png`) }
}
```

- [ ] **Step 2: 主进程实现**

创建 `src/main/snapshot.ts`：

```ts
// 画板快照：截主窗口的指定区域，写进项目的 screenshot/ 下。
//
// 为什么是主进程截而不是渲染层用 canvas 画：画布上跑着活终端（xterm 渲染到 canvas）
// 和内嵌网页（webview），渲染层没法把它们画进一张图 —— 只有 capturePage 拿得到合成后的结果。
import { BrowserWindow, ipcMain } from 'electron'
import fs from 'fs'
import path from 'path'
import { snapshotTarget } from './snapshotPaths'
import { isIslandWindow } from './island'
import type { SnapshotRect, SnapshotResult } from '../shared/types'

/** 主窗口（排除灵动岛那个）。和 island.ts:40 同一个判据 */
function mainWindow(): BrowserWindow | null {
  return BrowserWindow.getAllWindows().find((w) => !w.isDestroyed() && !isIslandWindow(w)) ?? null
}

export function registerSnapshotHandlers(): void {
  ipcMain.handle(
    'canvas:snapshot',
    async (_e, projectPath: string, rect: SnapshotRect): Promise<SnapshotResult> => {
      try {
        // 路径校验走 fsGuard，和 fs.ts 里其余 9 个写盘 IPC 同一套：白名单是已注册的项目根
        // 与知识库根，且先 realResolve 再比对（项目里塞个软链指向别处就能绕开字符串前缀比对）。
        // 这是仓库的沙箱代码，新的写盘面不许自己另起一套。
        const g = guardDir(projectPath)
        if (!g.ok) return { ok: false, error: g.error }
        // 后续一律用 g.path（解析后的真实路径），用回原始的 projectPath 等于白防
        if (!fs.existsSync(g.path)) return { ok: false, error: '项目目录不存在了' }
        const win = mainWindow()
        if (!win) return { ok: false, error: '找不到主窗口' }
        // 取整：capturePage 的 rect 只接受整数，小数会被静默取整、截偏一两像素
        const r = {
          x: Math.round(rect.x),
          y: Math.round(rect.y),
          width: Math.round(rect.width),
          height: Math.round(rect.height)
        }
        if (r.width < 1 || r.height < 1) return { ok: false, error: '画布区域太小，截不了' }

        const img = await win.webContents.capturePage(r)
        const buf = img.toPNG()
        if (!buf.byteLength) return { ok: false, error: '截出来是空的' }

        const now = new Date()
        // 先算目录，读一次当天已有的文件名，再算序号
        const probe = snapshotTarget(projectPath, now, [])
        let existing: string[] = []
        try {
          existing = fs.readdirSync(probe.dir)
        } catch {
          /* 目录还不存在 = 当天第一张 */
        }
        const target = snapshotTarget(projectPath, now, existing)
        await fs.promises.mkdir(target.dir, { recursive: true })
        await fs.promises.writeFile(target.file, buf)
        return { ok: true, path: target.file }
      } catch (err) {
        return { ok: false, error: err instanceof Error ? err.message : String(err) }
      }
    }
  )
}
```

而全库文档类有 **64** 个。一次构建就能把 60 个名额占满。
在渲染层滤已返回的那 60 条，勾上之后只会看到 3 个 —— 比不勾还难找，正好背离这个功能的目的。

在松手（mouseup）时，若落点是**终端**且被拖的节点/Frame 绑定了项目，则插它的根路径：

```ts
  // 拖模块落到终端上 → 把它所属项目的根路径写进那个终端。
  // 拖文件插文件路径这条已经在资源抽屉里了（CanvasDrawer 的 startFileDrag:288-297），
  // 这里是同一个手势的另一半：拖模块插项目路径。落点判定与写入方式**照抄那边**。
  const dropModuleOnTerminal = (frameId: string, ev: MouseEvent): boolean => {
    const el = document.elementFromPoint(ev.clientX, ev.clientY) as HTMLElement | null
    // 判据是 data-leaf-id 不是 pty id —— PaneLayer 上挂的是前者
    const termPane = el?.closest('.pane[data-leaf-id]') as HTMLElement | null
    if (!termPane?.dataset.leafId) return false
    const leaf = useStore
      .getState()
      .tabs.flatMap((t) => collectLeaves(t.root))
      .find((l) => l.id === termPane.dataset.leafId)
    if (leaf?.pane.kind !== 'terminal') return false
    const f = useStore.getState().canvas.frames.find((x) => x.id === frameId)
    const proj = useStore.getState().projects.find((p) => p.id === f?.projectId)
    if (!proj) return false
    // 和 startFileDrag 一样：直接写进 PTY，末尾带一个空格。
    // **不是**「插进输入栏」—— 那条路不存在，现有实现走的就是 pty.write
    window.api.pty.write(leaf.pane.ptyId, shellQuote(proj.path) + ' ')
    return true
  }
```

`shellQuote` 在 `CanvasDrawer.tsx:20` 有一份。本任务要在 `CanvasStage` 用，
**把它提到一个共用模块再两处 import，不要复制第二份** —— 引号规则有两份迟早对不上。
