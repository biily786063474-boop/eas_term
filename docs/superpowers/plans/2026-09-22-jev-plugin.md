# Jev Plugin Implementation Plan
> 使用 executing-plans 顺序执行，按独立验收点推进，不把局部检查算整体完成。
**Goal:** 将批准的 Demo 落地为默认关闭、可撤销的通用 Jev 插件。
**Architecture:** 插件提供 panel/skills/typed decisions；复用宿主配置金库、权限及 MCP shim。控制器统一处理开关与撤销代次，任何 UI/模型只能经授权接口访问。
**Tech Stack:** Electron、TypeScript、stdio MCP、standalone HTML。
