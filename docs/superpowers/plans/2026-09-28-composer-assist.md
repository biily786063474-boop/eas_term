# 输入框推荐与历史回填（已批准方案）

## 交互与视觉
沿用现有 CodeMirror 输入框、明暗主题和字号，不另造面板。空白时以灰字显示本次 AI 回复中已有的可选回答，旁边小型 Tab 键帽；填入后变为正常文字，绝不自动发送。没有可靠候选则显示原占位语。首次新会话没有历史/推荐时不伪造。

当前会话已加载的最近 50 条用户文字作为 ↑ 历史；↓ 回到较新一条，越过最新一条恢复浏览前草稿。只能从空输入框进入历史模式；编辑、鼠标重新定位或切换会话立即退出模式。普通多行文本中的方向键保持编辑行为。只回填文字，不自动重新授权/附加历史图片，现有草稿附件不改变。

按键优先级：输入法组合/只读 → 原有 @ 和 / 候选 → Tab 推荐 / 历史导航 → 默认编辑。Shift+Tab 和其他修饰键保留原行为。Tab 不发送，发送快捷键不变。推荐只来自最近一次尚未回答的 assistant 组，运行中和审批等待不显示；不读取其他会话，不调用模型，不新增 IPC/数据库/凭证。

## 实施
1. 纯函数测试：候选选取、去重历史、上限、已回答/忙碌不推荐、IME/候选/修饰键/编辑保护。
2. 共享 ComposerInput 接入动态灰字与历史导航；AgentChatView 启动输入框和 ChatToolbar 常规输入框共用来源函数。
3. 隔离 Electron 测试：Tab 只填入、↑↓回填、草稿/多行/IME/候选优先级、会话隔离、冷恢复、明暗和窄宽布局；build/check。在线 CLI 不需要参与（功能无模型请求）。

视觉路由已读取；本机缺少路由指向的 visual-router 子 skill。按用户已批准的“沿用现有输入框样式”实现，不重新选型或引入设计依赖。
