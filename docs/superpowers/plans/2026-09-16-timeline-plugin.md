# 时间线插件实施计划

**Goal:** 已确认 V3 拨轮 / 月热力图 / 任务详情接真实 AI 工具与项目内持久化。
**Architecture:** 新增 resources/plugins/timeline，复用现有插件宿主与沙箱面板，不注册第二种画布组件。宿主 guardDir 校验当前项目，插件只写固定 .eas/timeline.json。时间线规则只注入选中插件的受管会话，宿主记录真实成功回执并在下一次用户消息中提示疑似遗漏，不另启模型。
**Tech Stack:** Node stdio MCP、纯 HTML/CSS/JS 面板、现有 Electron 宿主。
**Spec:** docs/prototype/2026-09-16-timeline-plugin.html（用户确认）；本会话确认省 token 方案。

## Constraints
- 不改已有未提交内容；不安装/重启正式应用；不加外部依赖或出站请求。
- 固定 CSS 动画与 blur=2；默认静音、支持 reduced motion。
- 一个可独立验收成果为一条；taskKey 去重、状态更新不新增计数。保存发生日与记录时间；本地日期热力图按发生日统计。
- 待验证 / 已验证 / 已验收区分；后两者必须有依据。失败不冒充空库、原子落盘、拒绝软链越界。
- 不扫描历史、不自动叫模型；手动补漏仅预填 AI 请求，用户发送才执行。
