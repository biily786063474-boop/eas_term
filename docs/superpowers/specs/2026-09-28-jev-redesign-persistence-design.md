# Jev 重设计与持久连接规格

日期：2026-09-28。状态：待用户审阅；不是实现完成声明。

## 已确认的目标

用户同意将七个能力开关重设计为「判断台 / 自动化 / 连接与用量」。本轮明确选择：恢复连接及上次开关状态；之前暂停则继续暂停，已授权自动化可继续运行。长期有效指本地不主动遗忘已保存连接，不保证服务商永久接受已撤销/过期凭证。

## 方案比较与决定

- 只缓存界面的 connected：排除。显示连接不等于运行时取得有效凭证，会造成假成功。
- 每次启动重新登录：排除。不符合一次连接长期使用的目标。
- 宿主管理凭证恢复、插件持久化用户意图：采用。复用加密凭证库、设备信任与租约撤销，不另造密钥存储，不修改其他插件授权语义。

## 一、界面

沿用 Eas-Term 现有视觉体系，中性色为主体，单一高亮色表示当前状态；不重做软件主题。

1. 判断台：选择明确任务、提供材料、预览实际出站材料与问题、确认调用、查看结构化结果与不确定性。首版提供反馈分类及自定义明确问题；不承诺独立完成代码评审或引用查证。不直接执行后续动作。
2. 自动化：与手动调用分开。时间线里程碑增强及项目建议单独授权；默认关闭。展示触发条件、允许的项目、发送字段、预算和弃答规则。来源项目明确时不额外调用模型猜归属。
3. 连接与用量：显示已保存连接、当前可用性、全局暂停状态、实际请求记录、输入/输出 token、已知费用估算及未知费用标识。不把估算称为账单。
4. 全局暂停始终可见。暂停不删除密钥；「退出并移除 Jev 凭证」二次确认后删除插件凭证并清除恢复授权；不影响其他插件。

## 二、持久化与恢复

- 密钥只由宿主加密凭证库存储，禁止写入插件偏好、localStorage、日志、报告或模型上下文。
- 持久化的是用户意图：总开关 enabledIntent、能力/配方选择、授权范围和版本；不持久化可直接用于授权的 connected=true。
- 重启或插件进程重建时，宿主检查插件仍启用、凭证记录身份未变化、密钥柜可用、原授权仍有效，再用当前凭证租约恢复插件。所有条件满足后才允许业务调用。
- 连接可用性与运行意图分离；已保存不等于本轮联网验证通过。离线显示「连接已保存 · 暂时离线」，不显示已退出。
- 已暂停状态优先恢复，恢复流程不得再次启用；后台自动化只恢复明确授权的范围，不自动扩大到新增项目或新增能力。
- 使用现有「信任此设备」机制实现免重复解锁，必须由用户显式开启。未开启或密钥柜被手动锁定时保留连接记录，但停留「待解锁」。不得新增绕过锁柜的权限。
- 锁柜、撤销、卸载/禁用插件、修改密钥时立即废止旧租约、取消请求并拒绝迟到结果。自动恢复与用户暂停/退出并发时，以最新撤销版本为准，旧恢复任务不得重启调用。
- 临时断网、超时、限流不删除凭证，不将 enabledIntent 改成 false；认证失败停止业务出站并提示更新凭证，不无限自动重试。结果未知的收费请求不自动重放。
- 恢复连接不重复发送收费测试问题；是否需网络检查由明确的非推理验证契约决定。没有可靠验证结果时如实显示待检查，不伪造在线状态。
- 不补跑软件退出期间或离线期间累积的历史事件；恢复后只处理新的合法事件，避免意外费用与重复建议。

## 三、架构边界

- 宿主连接层负责凭证、安全租约、恢复编排、授权范围与生命周期；插件负责判断模板、偏好、结果解释和界面。不要把 Jev 特例分散写进每个消费者。
- 内部统一 DecisionService 管理请求、预算、取消与结构化日志；模板声明版本、输入字段、输出选项、阈值和弃答行为。
- AI 提供的原始材料须经宿主出站预览确认，调用许可绑定实际材料、问题、模型与当前会话，不能用总开关代替单次材料许可；后台配方采用已确认的字段白名单和项目范围。
- 旧五个同构工具迁移为单一明确判断契约；旧名称过渡期经过相同授权路径并提示迁移，不得继续保留可绕过预览的原始代理接口。
- 同一候选的相互独立问题合并请求；置信度阈值只能作为可校准策略，低置信度返回待确认，不自动移动项目或认定验收完成。
- 自动化进程由宿主按已授权事件获取/释放受管引用，不依赖面板常开；插件不可用时保留基础时间线，不阻断记录。
- 固定已评估模型版本；模型升级须重新测试，不能将动态别名悄悄当作不变模型。
- 预算以持久化日限额为统一用户口径，并发限制单独保留；保留失败与结果未知记录，不凭空填费用。

## 四、迁移与范围

已有加密密钥复用；旧能力选择可迁移，但旧版本没有持久化总开关意图，无法猜测过去状态：首次升级需明确确认是否启用，之后才恢复上次状态。新数据范围、新自动化与新增项目均需重新授权。损坏或未知版本配置关闭业务调用并提示修复，不覆盖原始数据。

首轮不做官方网页登录/OAuth、不做跨设备密钥同步、不改其他插件连接模型、不发版、不自动付费测试。中文模型效果与真实账号验证需独立记录，离线夹具通过不等于生产验收。

## 五、验收矩阵

1. 已启用后重启：不重复输入密钥；凭证柜可用时恢复连接及相同授权开关。
2. 已暂停后重启：仍暂停；业务请求数为零。
3. 关闭面板但软件运行：已授权新时间线事件可增强；未授权项目不出站。
4. 断网/限流/超时：连接记录不丢，状态准确；未知结果不重放。
5. 锁柜与解锁：锁定后无新请求、迟到结果丢弃；解锁后仅恢复仍有效的原意图。
6. 退出/密钥修改与恢复竞态：旧恢复不能重连；旧请求不能提交结果。
7. 修改材料或问题后，旧单次许可不可复用；旧工具名也不能绕过。
8. 升级旧偏好、损坏配置、过期授权：不偷偷启用，不拓宽范围。
9. 用量记录跨重启连续，成功与未知费用区分，UTC 日界线预算可验证。
10. 构建隔离应用，亲眼验证三页、连接状态、暂停、重启恢复和面板关闭；不得以单元测试替代 UI 验收。真实 TypeSafe 与 Windows 未做就标注未验证。

## 六、多视角自审

体验：一次配置，重启不丢状态；故障不伪装成退出。
安全：持久化意图不是永久权限，所有调用仍经过实时凭证与授权校验。
成本：恢复不重复收费测试、不补历史事件、同材料批量判断、未知结果不重放。
实现风险：范围包括插件与宿主接口，必须隔离分支实施并同步架构图纸；不在当前时间线功能分支混入产品代码。
