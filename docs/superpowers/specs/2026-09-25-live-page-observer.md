# 页面开发观察窗 · 设计规范

## 目标
用户在 AI 开发本地网页时，看到**同一浏览器会话**中的页面变化和 AI 操作，而不是一个与 AI 操作无关的第二个预览页。分屏模式从应用右侧平滑滑出；画板模式在该 AI 对话模块内临时并排显示；可弹出独立窗口、收起或关闭。

## 范围和边界
- 第一版只接本机开发服务器 `http(s)://localhost|127.0.0.1|[::1]:port`；不静默接管现有 Chrome、不共享其 Cookie/登录态，不支持任意 `file://` 路径。
- 由新的 AI MCP 工具显式打开/导航/点击/输入/滚动观察窗。代码热更新由网页自己的开发服务器提供；不能把外部 CLI 浏览器的动作冒充为已同步。
- 观察窗归属 AI 会话的 leaf/PTY；托管能力走租约，遗留 MCP 桥走现有 token 鉴权。主进程限制并发数量并在关闭时释放。遗留 token 持有者能声明上下文身份，不把它表述为跨本地进程的安全隔离。
- 不自动录制历史、不传截图到远端；实时画面仅由本地 Electron 渲染。截图推送限制尺寸与帧率，隐藏后暂停。第一版不提供 DevTools 嵌入。
- AI 工具返回当前页面的标题、文字与交互元素摘要供 AI 判断；截图只供本地 UI 观察，不作为 AI 图像输入，也不注入日志。明确区分导航失败、开发服务器未启动、浏览器会话已关闭。

## 交互
1. AI 调 `page_live_open` 后，UI 自动展示归属该对话的观察窗；首帧到达前显示加载反馈，不闪白块。
2. 分屏模式：右侧覆盖式抽屉，宽度随视口约 36–45%，有标题、地址、操作状态、弹窗与关闭/收起入口；背景保持原布局。画板模式：对话区域平滑收窄，右侧预览约 45%，窄节点退化为上下布局，避免对话变成窄条。
3. 入场/退场 440ms ease 曲线，先挂载后动画、收起后保留状态；`prefers-reduced-motion` 关闭位移动画。不得在收到首个事件时直接 `display:none → block` 跳变。
4. 关闭 UI 仅隐藏；“结束预览”才销毁浏览器会话。任务结束不擅自关闭用户正在看的预览。
5. 弹出独立窗口时显示同一浏览器会话；内嵌区域改为状态/返回入口，不新建第二个网页。

## 技术方案
- 主进程新建会话归属的隐藏 `BrowserWindow`；AI 操作通过 Electron `webContents.sendInputEvent` / `executeJavaScript` 作用于其 `webContents`。弹窗时显示同一窗口。通过 `capturePage` 低频传帧给渲染层，避免在两种布局下复制浏览器进程。
- 仅对所需 MCP 工具在工作台宿主中主进程直通，其他现有工具继续走 renderer IPC。所有输入校验、窗口所有权、URL 限界在主进程执行。
- 渲染层一份共享观察状态，分屏右抽屉和画板对话内预览读取同一状态。主窗口关闭、进程异常、任务切换时清理监听与计时器。

## 验收
- AI 以工具打开本地测试页，页面 HMR/导航/点击/输入/滚动在对应观察窗可见；其他会话无法控制它。
- 分屏与画板两种布局开合有逐帧过渡，独立窗口/关闭/返回可用；窗口缩放与低宽度不溢出。
- 关闭预览后浏览器进程释放；隐藏时不持续截图；断开开发服务器有明确错误；亮暗主题及减少动效可用。
- 构建、全量检查、隔离应用实际打开观察截图；外部 Chrome 同步与跨平台用户机若未验证则明示。
