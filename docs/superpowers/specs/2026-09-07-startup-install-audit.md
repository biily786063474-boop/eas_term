# 启动安装引导与旧功能接入审查

状态：用户已批准进入代码。Figma 35–50 对应的安装状态入口、认证归属与切换清理已接入；提问导航、双色文件/工具图标和分屏 Worktree 徽标已实施。以下缺陷表记录实施前审查结果；当前验证以 docs/verification/agent-chat/README.md 为准，回放测试不等于真实外部服务验收。

## 真实启动链路

`AgentChatView` → `agentChat.listClis` → `session.ts` / `cliList.ts` → adapter 检测可执行文件、聊天能力、认证方式和安装方案。`clis === null` 是探测中；空列表和未安装不是同一种状态。启动模型由 `StartupModelPicker` 通过 `modelCatalog` 在首条消息前读取，读取本身不创建会话。

用户选择有安装方案的未安装 CLI 时，`installCli` 打开 `CliSetupPanel`。它承接安装、验证和 `CliLoginPanel`；登录完成必须依据重新探测的真实认证状态。当前安装方案只给 Claude / Codex。默认 harness（adapter id 为 omp）是内置运行环境，走 `OmpSetupPanel` 的服务商 → 订阅授权或 API key → 模型 → 显式测试流程。内置运行文件缺失不能显示成去外部官网安装一个通用 CLI。

## 已确认与待验证

| 项目 | 代码证据与实际边界 |
|---|---|
| 切换后旧未安装提示残留 | `AgentChatView.tsx` 的 `cliMenuItems` 可用分支只 `writeLastCli`、`setSelected`，不清理 `cliNote`。缺陷确认；0764b25 中该分支相同，不能断言由本次布局引入 |
| 提示 CLI 与当前选择不一致 | 没有安装方案的不可用项只 `setCliNote(c)`，保留旧 selected；可出现 Claude 选择与默认 harness 提示并列 |

| 认证异步隔离 | 现有 selected/session effect 有取消标志；安装完成回调和服务商重查还需按当前 CLI 与请求代次防旧响应回写 |

## 原型与状态规则

[Figma 安装入口](https://www.figma.com/design/xgXySVpD0pfr0eBw2738Zq?node-id=13-2103)；[接入审查画板](https://www.figma.com/design/xgXySVpD0pfr0eBw2738Zq?node-id=14-3146)。

35 未安装 → 36 安装中 → 37 登录 → 45 Claude 就绪；35 → 42 切换检测 → 41 Codex 就绪。38 服务商配置 → 46 订阅授权 / 47 API key → 48 模型与显式测试 → 49 默认 harness 就绪。39 内置文件缺失、40 安装失败、43 首次检测、44 手动安装退路。50 标注已接入、缺陷、仅原型及测试边界。

- 切换时立即移除前一个 CLI 的未安装卡片和过期提示；新结果回来前只显示当前 CLI 的检测态。
- 草稿保留，模型选择按 CLI 隔离；安装/授权成功不自动发送用户第一句话。
- 安装成功后重新探测列表与认证，再显示可用；未知状态不能当成未安装或已登录。
- 进度依据真实阶段和输出，不制造百分比；错误保留输出、重试和帮助。原型的定时跳转仅演示成功路径。
- 同一视觉框架承接不同能力；不把默认 harness 的服务商设置套进 Claude 登录。
- 面板最小宽度 640px，主操作单行，刷新/语音/发送/复制使用图标。

原型有 15 个状态画板和 21 条导航/定时连线；通用 CLI 下拉和次级刷新/复制未制作完整交互。Figma 不执行真实安装、认证或模型请求。

原型眼验：已经在 Figma 演示中查看完整未安装和登录画板；实际点击登录入口到 Claude 就绪，CLI 保持 Claude；重新开始后点击“改用已安装的 Codex”，进入 Codex 检测态，Claude 的未安装卡片立即消失且草稿仍在。这些是原型点击验证，不是产品安装测试。

随后确认 Codex 检测态自动进入 Codex 就绪态，没有旧错误；并点通默认 harness 的服务商配置 → API key 示例 → 模型与显式测试 → 就绪，草稿保持。未输入真实密钥或调用真实模型。

## 审查后实施与验收顺序

1. 统一当前选择、提示和 setup 的归属；清理旧提示并防旧异步响应回写。
2. 接回安装 → 重新检测 → 登录/服务商设置 → 模型 → 用户手动发送；覆盖内置缺失和无安装方案的退路。
3. 实施已画的提问导航，覆盖逐条定位、悬停、当前刻度、Frame 外侧/空间不足内收、分屏和缩放。
4. 按上表逐入口验证旧功能，记录每项真实/模拟边界。涉及远端认证、麦克风和真实工具操作时不能用截图或事件回放代替验收。

本审查没有声称“聊天功能全部恢复”。完整远端端到端验证仍未完成。
