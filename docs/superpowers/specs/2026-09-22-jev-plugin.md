# Jev 通用热插拔插件 Spec
状态：用户已批准方向，实施中；不是已完成声明。
## 目标与范围
独立可分发插件，不是时间线私有模型。不安装/不启用时零 Jev 请求，宿主基础能力不缩水。
总开关默认关闭；连接成功与启用授权分开。LLM 五项默认选中但不生效，时间线两项默认关闭。
LLM：分类优先级、资料证据、结果辅助评审、任务工具推荐、自定义判断。
软件增强：时间线里程碑候选判断、项目标签推荐；不得把 AI 最后一条回复当验收证据。
首版不含浏览器执行、自动上下文删减、自动合并或自动敏感操作。
## UI
以时间线实际 ui/panel.html 为视觉规范：#111316/#090b0d、#eceff2、#78828c、#b7d2c5，系统中文字体，微光与轻层级。
未连接仅引导；连接并确认启用后仪表台；暂停保留仪表台；断开删除凭证后回引导。
顶部总开关与全部选中/全部取消分离，后两者不绕过授权。
“赋能本软件”下插件卡片占一个普通卡片宽度，时间线注册 logo + 内部两张小开关卡片。
LLM 能力多列网格。独立问号 hover/focus 说明，点击固定，Escape 关闭；不改变开关。
每项说明：哪里用、何时触发、示例结果、不会做什么/发送什么；SVG 辅助演示且支持减少动态。
市场、模块标题、面板共用经校验 composerIcon 元数据。缺失/失败才兜底；不得冒充官方图标。
Demo: docs/design/jev/panel.html；正式 UI 不允许残留模拟连接、虚假费用。
## 连接和信任边界
凭证仅经已有宿主加密存储及安全表单，不进入聊天、日志、工具参数、插件 HTML。
服务地址固定白名单，禁止模型传入任意 endpoint；不因失败切换提供商或模拟。
无 key 引导官方获取，连接验证区分无效/权限/限流/网络/余额未知。测试动作必须用户触发。
首次授权列明用途、数据外发与费用。目录读取走原生授权，不接受文本路径充当权限。
AI 与 UI 不能通过自报 purpose 获得权限；宿主派生调用方/会话/插件身份。
通用自定义能力意味着通用语义判断权限，无法证明自然语言不模拟其他场景。禁止承诺语义级隔离；
各分项控制预设自动流程/工具入口，资源访问、写入、执行权限始终独立强制校验。
## 生命周期与成本
停用/断开/锁定/卸载：拒绝新请求，取消排队，尽力 abort 在途，代次校验丢弃迟到结果。
已经外发不可收回，已产生费用可能继续计费。独立第三方直连不受总开关管辖。
并发和大小限额、次数预算、有限重试、每请求唯一 ID；不无限重复直到模型给期望答案。
统计记录来源、时间、状态、用量；不默认存原文和凭证；费用未知明确显示未知。
重启不自动开启之前关闭的总开关；更新权限扩张重新确认。

## 验收门槛
离线：关闭零请求；验证连接不启用；默认 5/7；全选不启用；停用后迟到结果拒绝；
锁定/卸载/权限变化拒绝；缓存旧工具不可调用；错误不泄密；限额并发无竞态。
实机：引导→连接→启用→切换→暂停→重启→断开；窄面板、滚动 hover、不误触、键盘；
市场 logo 三处一致。隔离数据，保留系统 HOME，绝不改真实钥匙串。
三 CLI：真实 shim + 在线模型实际按需调用分别列明，测试夹具不算在线。
插件安装/更新/卸载必须真实宿主验证。在线缺凭证明确未验证，不索要聊天密钥。
