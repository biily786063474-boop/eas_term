# 运行中心收进设置 · 设计说明（2026-09-14 定稿）

视觉稿：`docs/prototype/2026-09-14-runtime-center.html`（提案 02，已定稿，PNG 同名）。
本文只记**决定**与**约束**，落地照视觉稿。

## 一、决定

1. **运行中心变成设置里的一页**：「系统管理 › 运行与资源」（key `runtime`，排在「更新」与「性能与诊断」之间）。
   原右侧贴边对话框 `RuntimeCenter` 删除；「性能与诊断」页不再内嵌 `RuntimeMonitorPanel`，只留图形加速与诊断日志。
2. **标题栏拆掉两个常驻入口**：`McpIndicator` 那盏灯、`RuntimeCenter` 的「运行 N · 等待 M」按钮。
   MCP 已有自己的设置页（`mcp`），不用再画。
3. **标题栏只保留一个「有事才出现」的临时提示** `TitlebarAlert`，两种情形，没事不渲染：
   - `等待 N`：运行时调度器里有任务排队（终端 / AI 启动等被资源准入挡住）。点击 → 打开设置 `runtime` 页。
     **理由（用户 2026-09-14 拍板）**：终端 / 对话被排队时模块本身没有任何提示，这是用户唯一能知道「为什么点了没反应」的地方。
   - `MCP 已拒 N`：MCP 接入被关闭，却仍有调用进来被拒（`mcpLog` 里 `ok:false` 且 `mcpEnabled===false`）。点击 → 打开设置 `mcp` 页。看过一次（打开过页）即清零。
   排队数**由主进程推送**（调度器变化时 `runtime:waiting`），标题栏不轮询；提示只在有事时出现，和 `UpdateBadge` 是同一模式。
4. **读数每 3 秒刷新只在「运行与资源」页打开时进行**，离开即停。
5. **页内布局**（自上而下）：
   - 模式行：`资源模式` 分段开关（普通 80% / 节能 50%）+ 一句准入范围 + 「阈值怎么起作用」折叠说明。
   - 四格读数：CPU（带阈值刻度量表）、内存（同）、托管服务数、等待中数（>0 时黄色）。
   - 工具行：按项目筛选（`<select>`）、分组开关（按项目 / 按类型）。
   - 三个分区：**任务与启动队列**（展开）、**托管服务**（默认折叠、折叠态一行摘要「终端 5 · AI 对话 2 …」+ 停止中计数）、**最近结束**（默认折叠、摘要只留最新一条）。
     选了项目筛选时两个折叠分区自动展开。折叠状态**按会话记**（组件 state），不持久化。
   - 每个分区标题右侧「包含什么 ▾」折叠原来那三段准入范围说明，**文字一字不删**。
6. **托管服务**：项目卡片（两列，`按类型` 时卡片按类型）+ 芯片（类型图标 + 名字 + 状态点）。点芯片弹出小面板：状态、时长、类型、归属、`定位`、`关闭`。
   跨窗口共享的服务面板里标「跨窗口共享」、关闭置灰；停止中的关闭置灰。
7. **定位**：只对终端与 AI 对话服务显示。**纯渲染层实现**：服务 id `pty:<ptyId>` ↔ 终端 pane 的 `ptyId`，
   `agent:<sessionId>:<gen>` ↔ agent pane 的 `sessionId`；找到 leaf → 画布节点 → `focusCanvasNode(frameId,nodeId)`，并关闭设置。
   找不到（服务不属于画布上的模块，或在分屏模式）时按钮置灰并给 tooltip。

## 二、不变的东西

- 所有动作沿用现有 IPC：`runtimeMonitor` / `runtimeSetMode` / `runtimeCancelTask` / `runtimeStopPlugin`；主进程的所有权与确认框逻辑一字不动。
- 视觉：跟项目设计系统走（`docs/architecture/15-视觉令牌与主题.md`），只用令牌不写死值；量表填充 `--accent`，超阈值 85% 起 `--sem-warn`、超线 `--sem-danger`。
- 状态色永远带文字，不单靠颜色（运行中 / 停止中 / 排队中 / 完成 …）。

## 三、验收判据

- 标题栏无 `MCP`、无 `运行` 项；无排队时无任何提示；人为让调度器排队（隔离实例里 `EAS_VERIFY` 下用 `runtime:setMode` 节能 + 制造 CPU 压力，或直接从主进程 `manager.submit` 一个占位任务）→ 出现 `等待 1`，点它打开设置 `runtime` 页，队列清空后提示消失。
- 设置 `runtime` 页：读数刷新；托管服务默认折叠且摘要数字 = 服务总数；选项目后自动展开；点芯片弹出面板；`定位` 把画布视口挪到对应模块并关闭设置。
- `npm test` / `typecheck` / `build` 全绿；CDP 真机截图放 `docs/verification/runtime-settings/`。
