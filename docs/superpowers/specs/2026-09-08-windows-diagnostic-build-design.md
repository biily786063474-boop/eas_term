# Windows 私发诊断包设计

状态：用户已同意独立 Windows 安装包和自家服务器接收、测试者确认后上传；本文已获用户最终确认（2026-09-08）。尚未实现或构建。

## 目标与非目标

定位 Windows 打开 AI 对话时的窗口消失、渲染/GPU 崩溃及 CLI 启动失败。交付 x64 NSIS exe 和 SHA256，由用户转发测试者。不改官网、latest.json，不打发布 tag，不创建 GitHub Release，不将测试包纳入更新通道。不宣称已修复闪退。

以已发布 0.4.85 的冻结源码为基线，独立 worktree/诊断分支；不携带当前工作区其他未提交修改。独立 appId、产品名及 userData，与正式版并存，不自动拷贝聊天或设置；仍可能读取系统现有 CLI 登录，验收记录注明这一边界。测试版显示明确诊断版标识，禁用正式更新提示。版本拟为 0.4.85-diag.1，打包前验证 NSIS 版本兼容性。

## 客户端

新增独立诊断模块，不改变匿名 telemetry.ts 的采集约定。采用结构化事件白名单：构建版本、平台/系统版本/架构、随机的本次运行编号、相对时间、对话所选 CLI 类型、启动阶段、退出码和信号、渲染/GPU 退出原因、异常类型与经过清洗的应用栈帧。

不采集聊天正文、终端输出、完整命令/参数、模型回复、环境变量、密钥、项目名和原始路径。不能直接打包现有 agent-sessions.log/flicker.log；其中自由文本不满足新的上传边界。异常 message 可能带提示词/密钥，不原样保留；仅保留白名单错误码、错误类型以及归一的应用内栈位置。Windows 路径、URL 参数与凭证模式需覆盖脱敏测试。

在 app 初始化、对话启动各阶段、PTY 创建、主进程异常、renderer/GPU gone 及退出时记录。注册不重排既有 whenReady 顺序。同步小事件落盘且所有诊断 IO 失败不得影响业务；日志按总字节硬限额 10 MiB 轮转。

启动标记与正常退出标记用于识别上次未正常结束，但不把断电或系统强杀自动称作软件崩溃。下次启动显示“上次未正常退出，是否发送诊断”；拒绝不上传，不无限提示。手动发送和导出与异常启动共用同一份结构化报告构建逻辑，报告预览显示字段、大小与目的域名。

不默认采集或上传原生 dump：本期保留为明确限制，原生崩溃只能从最后阶段和系统退出记录缩小范围，必要时另行征求同意采集 Windows 系统报告。

## 回传协议与接收服务

自家 HTTPS 独立 POST /diagnostics/v1/reports 接口，独立服务只监听 loopback，由现有 nginx 精确路由转发，不改 /e 统计链路。报告为 schemaVersion=1 的白名单 JSON，压缩后上传；客户端未压缩报告上限 1 MiB，压缩请求上限 256 KiB，服务端同时限制压缩与解压大小，拒绝不明字段/版本及无效值。不把任何服务端管理凭证嵌入客户端。

测试者逐次确认发送；网络失败显示失败、保留本地报告，用户手动重试，无后台无限重试。固定报告 UUID 用于幂等，响应只有在报告原子落盘成功后返回同一报告编号；同 ID 不同内容拒绝。客户端不跟随到第三方的重定向，设超时，日志中不记请求原文。

服务端限制请求频率、并发、单报告大小和总存储（初始 100 MiB）；满额拒绝新上传而非影响官网。报告存在 webroot 外，目录 0700、文件 0600，保留 14 天自动清理。客户端不提供列表/下载接口，维护者通过既有服务器管理通道按报告编号读取。该 location 关闭请求访问日志，避免为诊断新增 IP 留存。

部署前备份现有 nginx 配置，验证 nginx -t 后仅 reload；接收端健康和拒绝用例验证失败时撤回独立 location/service，不改官网文件及统计脚本。现有 deploy/eas-stats.py 有未提交修改，本任务不改它。

## 验证与交付

1. TDD：白名单、任意异常不泄露内容、Windows 路径清洗、轮转硬上限、写失败降级、异常/正常退出判断、拒绝发送不联网、超时/大小上限、幂等回传。
2. 接收端：schema 拒绝、gzip 炸弹、超限/限流、重复 ID、文件权限、清理期限和存储满；本地端到端发送并读取同一报告编号，再用合成数据验证线上。
3. Windows CI：独立 workflow_dispatch，仅上传 Actions artifact，不复用正式 Release 发布步骤。检查实际 exe 启动、对话启动阶段事件、模拟退出后的提醒、取消零上传、同意回传、导出报告以及正式版数据隔离。
4. 下载安装包并核对 SHA256；给用户本地 exe 路径、校验值及简短操作说明。实际账号对话需测试者机器执行，CI fixture 不替代模型验收。
5. 同步架构 01 外部端点、10 模块地图、13 跨文件所有权与诊断验收记录。Computer Use 生命周期问题继续保持未解决，不全局终止服务。
