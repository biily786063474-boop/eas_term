# 更多抽屉 · 用量仪表盘

用户已确认视觉方向并授权摸代码、写计划、落地。右侧名称改为「更多」，保留 Skill 与知识库真实组件；新增纵向用量页。以已有视觉稿为参考，沿用产品设计变量。

## 数据口径
- 统计 Eas-Term AI 对话交付的请求；不扫描聊天正文，不重复累计恢复历史，不覆盖外部终端 CLI。
- 主进程记账，按项目根目录、会话、请求开始时间归属；一轮 ID 去重。历史未采集不补假数据。
- 折线横轴为真实请求开始时间（时间区间聚合），不是任务序号。阶段由用户明确标记，默认「未标记」。
- 缺失 token / 费用保持未知；取消的合成零值不当真实零消耗。缓存字段按 CLI 口径处理，Claude 缓存写入单列；Codex 不重复加缓存。
- 累计费用仅在同一计数域、有前值且不倒退时取差值，首次样本费用未知；不根据价格表猜费用。
- 提供今日/7天/30天、项目筛选、趋势、输入/输出/缓存、CLI 分布、已知费用/覆盖率、分页轮次明细与手动阶段标签、CSV 导出。
- 本轮不做账户账单对账、自动推断任务阶段、预算强制拦截；预算可以后续扩展，不用假数据占位。
- 本地独立账本最多 90 天 / 50,000 轮，超限裁剪，显示保留边界；不记对话、命令、密钥。写入故障不得影响对话，要在仪表盘提示。
