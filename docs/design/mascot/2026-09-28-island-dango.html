灵动岛团子 · 第六轮

去掉眼神高光；身体从扁圆改成「圆角方」（超椭圆，iOS 图标那种轮廓）—— 有一点方正感，但边是连续的弧，没有硬角；身体也更高一些，不再扁平。方正多少不好一次拿准，下面给三档。第五轮加「记忆点」；第六轮按选择定为「小脚 + 耳朵」，耳朵和脚一样软糯。

这一版改了什么
  • 圆角方身体：超椭圆轮廓，四边微微鼓、四角是大弧 —— 有方正感，但没有任何一处是直线或硬角。
  • 更高：宽高比从约 1.4 : 1 收到约 1.2 : 1，不再像一块扁饼。
  • 眼睛：纯色椭圆，没有高光；仍然大、低、分开。
  • 嘴：保持很小的一道短弧。

我的倾向：A + C

光标舌头是只有它有的动作 —— 别的吉祥物吐舌头是舌头，它吐出来的是光标，这个梗一次就记住；运行时舌头像光标一样闪，功能和性格合在一个点上。小脚给了它姿态，剪影不再是一块方糖。B 的红绿灯很「像产品」，但偏装饰，而且会和眼睛抢视线。

Ears

小脚 + 耳朵

耳朵和脚用同一种做法：从轮廓边缘软软冒出来的小圆团，只露一截。三种耳朵，都配小脚。

歪耳（主推）
左耳立着，右耳软软歪向外，像被捏过一下
对称小耳
两只一样，微微向外张
豆耳
更圆更小，像两颗豆
为什么主推歪耳

对称的耳朵 + 对称的脚，整体会变成一个很「标准」的小动物；一只耳朵歪下来，轮廓立刻有了性格，剪影也独一无二 —— 远远看一眼就知道是它。歪的那只做得软、低、往外倒，和脚尖是同一种软糯的手感。
