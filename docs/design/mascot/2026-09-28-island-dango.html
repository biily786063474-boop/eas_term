灵动岛团子

一只胶囊形状的小团子：眼睛是终端光标，尾巴是 Eas-Term 图标里那条缎带。它不只是 logo，而是界面上的状态角色 —— 运行、等你、完成、后台、出错，各有一个表情。

日期 2026-09-28形式 手写 SVG（非 AI 生图）明暗 两个主题都成立

Verdict

主形象

静态 logo 版。先看它在两个主题底色上是否都站得住，再往下看状态和尺寸。

暗色主题 · 双光标眼
亮色主题 · 同一套形状，只换墨色与纸色
设计要点
  • 身体 = 胶囊：和灵动岛、按钮同一套形状语汇，放进界面不突兀。
  • 眼睛 = 光标：两根竖块，一看就是「终端」；眨眼就是光标闪烁，不用额外发明表情。
  • 尾巴 = 缎带：沿用图标「T」的双线缎带，在身后绕一个环，和现有 logo 认亲。
  • 只有两种颜色：墨色 + 纸色，跟随主题互换；不发光、不描边、不加品牌色。

眼睛的备选

方案 B · 光标 + 下划线（▮ _），像在眨一只眼，更俏皮
无尾版 · 更干净，但和 logo 的关系只剩形状

States

五种状态表情

对应软件里已有的状态：运行中 / 等你审批 / 完成 / 后台任务 / 出错。动作只用眨眼、倾身、跳一下、呼吸、抖一下，全部是透明度和位移。

运行中
光标眼交替闪烁
等你审批
一只眼抬起，身体前倾
完成
笑眼，轻轻跳一下
后台任务
半眯着眼，慢慢呼吸
出错
× 眼，抖两下就停

Sizes

从 128px 到 16px

24px 以下去掉尾巴、眼睛加粗（小尺寸专用版），否则缎带的双线会糊成一团。

Anatomy

构成与规格

落地进应用时按这张表实现：只用主题令牌的墨色和纸色。

部件形状（viewBox 140×84）颜色说明
身体胶囊 rect 40,16 92×56 r28墨色与灵动岛同一胶囊比例
眼睛两个 8×18 r2 竖块，间距 22；下方一道小弧嘴纸色状态只改眼睛和嘴：闪烁 / 抬起 / 弯成弧 / 压扁 / 叉；嘴让它先是「一张脸」而不是插座
尾巴从身后向左甩出、绕一个交叉环、尾梢外甩；粗 7 的墨线里挖粗 2.6 的纸线墨色 + 纸色复刻图标「T」的双线缎带；24px 以下省略
动作只用 opacity / transform—系统「减少动态效果」时全部静止
保留的疑虑
  • v1 自检发现：黑胶囊 + 两道竖缝，缩小后很像电源插座 / 暂停键。v2 加了小弧嘴、眼睛上移缩短来破掉这个联想；24px 以下没有嘴，仍有这个风险，要在真实灵动岛里看过才能下结论（方案 B 的「▮_」天然没有这个问题）。
  • 尾巴若卷成螺旋会被看成蜗牛（v2 自检），v3 改为单个交叉环。缎带尾巴在 48px 左右开始吃力；如果主要用在界面里，也许无尾版更合适，尾巴只留给官网和宣传。
