# 斜杠命令按钮化 · 原始数据

> 这份是 `斜杠命令按钮化分析.html` 的数据附件。命令清单从两个 CLI 的二进制里提取，
> 方法与噪声见下，别当成官方文档。

## 提取方法

| CLI | 版本 | 二进制 | 方法 |
|---|---|---|---|
| Claude Code | 2.1.227 | `/opt/homebrew/lib/node_modules/@anthropic-ai/claude-code/bin/claude.exe`（Mach-O，285MB） | `strings` → 匹配 `name:"x",description:"y"`，再要求 700 字符窗口内出现 `isEnabled` / `type:"local"` / `type:"prompt"`，并剔除 snake_case（那些是工具名不是斜杠命令） |
| Codex | 0.145.0 | `/opt/homebrew/Caskroom/codex/0.145.0/codex-aarch64-apple-darwin`（Mach-O，271MB） | `strings` → Rust 静态字符串表里名字段与描述段连续排布，按顺序对齐 |

**噪声说明**：`claude -p "/help"` 会回「/help isn't available in this environment」——
斜杠命令是交互式会话专有的，管道模式下问不出来，所以只能走二进制。
筛后 Claude 得 82 条；未筛时 124 条里混着工具名（`computer_batch` / `read_clipboard`）
和参数描述（`count` / `duration` / `files`）。Codex 侧名字段与描述段的对齐是按出现顺序推的，
个别冷门命令可能错位 —— 判断价值不受影响，但要引用具体命令名时请以 CLI 内 `/help` 为准。
