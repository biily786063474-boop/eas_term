DESIGN NOTES / 设计说明

一个 @，找到所有上下文。

左侧切分类，右侧看结果。预加载的辞典词条优先出现，文件保留相对路径以便区分同名项。

01辞典是一级分类

与文件、技能、插件并列。分类内分「已加入候选」和「全部辞典」，搜索支持中文名、英文名和关键词。

02备选与发送分清楚

候选词条保留在输入框上方，正文 @ 后标记「本次引用」。发送前可查看展开后的内容。

03三个端口，同一套操作

Codex、Claude、omp 的分类、搜索、选中、移除一致。命令能力按当前端口显示，选中命令先填入，不自动发送。

04候选不会无声消失

加载中、无结果、失败都留在浮层里；支持重试、键盘操作和中文输入。浮层随输入框定位，空间不足向下展开。

对标范围待核对：本机 Codex UI 暂无法直接读取。文件、文件夹、技能、插件、应用、浏览器标签是本稿的覆盖清单，原版的实际分类名称、顺序和可用项仍需以目标版本界面核准。

参考：官方命令文档 · 技能与插件
设计范围：仅本地原型，未接入真实 CLI、应用或插件。辞典沿用现有发送规则：有正文引用时按位置展开被引用词条；没有任何辞典引用时，明确提示将附带全部备选词条。候选来源与支持状态均为演示数据，不代表已连通。
