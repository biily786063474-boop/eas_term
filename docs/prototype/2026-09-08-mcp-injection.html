ENGINEERING MAP / 2026.09.08

Eas-Term 怎么把 MCP 交给 AI？

两个独立动作：告诉模型怎么用，以及给 CLI 配置真正可连接的工具。注入提示词 ≠ MCP 已握手。

受管 AI 对话：Claude Code / Codex / OMP复用已有插件宿主会话租约决定项目与 Frame

01 / 当前内置架构

Eas-Term 应用启动

保留现有 whenReady 注册顺序：启动本机 MCP 网关，再注册插件接口与插件宿主。

index.ts → mcpBridge.ts → pluginHost / builtinCapabilityHost
↓ 用户在项目 Frame 新建或恢复会话

A · 指引注入：模型知道怎么用

按模块开关生成简短指引，指向随包 SKILL、canvas、generate 等文件；由各 CLI 适配器带入会话。

capabilityGuidance.ts · sessionCapabilityGuidance()

保留用户规则。guidance 被禁用时不注入；文件存在不代表工具已连上。

B · 连接装配：CLI 真正获得工具

签发所属会话租约，明确绑定项目、AI 节点/终端身份；配置工作台与笔纵 MCP 入口。

EAS_TERM_PORT + EAS_CAPABILITY_LEASE

Codex 重启时重新合并原生配置，保留 enabled=false / disabled_tools；Claude、OMP 使用会话快照。

↓ CLI 通过 stdio 启动轻量连接端

eas-capability-shim.mjs

按 workbench / bizone 模块转发 JSON-RPC。独立 connectionId；心跳维护连接，不自动重放工具调用。

↓ HTTP · 127.0.0.1 · POST /capability/rpc

本机网关：先鉴权，再执行

校验会话租约、模块开关与归属；异步等待后再次校验。调用参数里的 ctx / _meta 不能更改项目和 Frame。

mcpBridge.ts → capabilitySessions → builtinCapabilityHost → 共享 HostRegistry
↓ 按模块分发

工作台工具 → 当前 Frame

工具目录：workbench-tools.json
执行：invokeRenderer → IPC → mcpHandler → store

图片先校验项目内路径、真实路径与文件类型，再确认 Frame 身份并添加节点。文件写入仍受 fsGuard 约束。

笔纵工具 → 官方连接器

bizoneHosted → runtime / McpClient / connector → 笔纵本地服务

目录握手不等于账号登录；实际调用前检查连接。生成 guard 持久记录请求身份，断线先查原任务，不盲目重复扣费。

02 / 一次调用的时序

1
用户 → Eas-Term

新建 / 恢复会话

解析所属项目、Frame 和 CLI，读取禁用与权限设置。

2
会话管理 → CLI

配置工具入口 + 注入使用指引

生成会话租约；把本机路由放入环境，凭证不写入命令行参数。两条注入链分别完成。

3
CLI → shim → 网关

initialize / tools/list 握手

授权后读取工具目录；失联、依赖缺失和禁用分别处理，不能把“配置好了”说成“连接成功”。

4
模型 → CLI → 网关

tools/call：例如 canvas_open_image

网关从租约取可信上下文，再调用宿主。模型不能通过参数指定其他用户会话。

5
宿主 → 渲染层 / 笔纵

执行并原路返回结果

工作台落到正确 Frame；笔纵按原任务身份处理。成功、失败和审批结果回传给 CLI。

6
退出 / 中断 → 租约管理

只释放所属会话的连接

重启 CLI 时重新装配；不杀其他会话。心跳约 15 秒，宿主回收超过 45 秒失联引用；在飞调用保留到结束。

受管终端 PTY 的额外一步

PTY 父租约 → app-owned PATH 入口 → eas-pty-launcher → /capability/launch 按实际 cwd 签发子租约 → CLI。CLI 退出释放子租约；PTY 退出撤销所属子租约。绕过受管入口的绝对路径/别名不能一概保证自动注入。

03 / 这次改动放在哪一层？

仅改工作台图片预览末端，不改握手和权限

mcpHandler → addFileNode → capContent → nodesToEvict

图片校验成功后，新增与 FIFO 清理同步完成。只关闭当前 Frame 最早的未固定内容预览；固定模块不占名额，终端、AI 对话和组件永不参与。返回被关闭的节点 ID，不删除源文件。

版本边界

线上 0.4.86 的图片工具仍是满额拒绝；图中 FIFO 改动与登录界面收尾优化均待下次发版。旧 eas-mcp / bizone-mcp 全局兼容入口仍保留，但不是上图的受管内置主路径。
