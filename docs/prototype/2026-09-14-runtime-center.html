01 / 入口收进设置

标题栏不再常驻「MCP」和「运行 N」。MCP 早有自己的设置页；运行中心变成「系统管理 › 运行与资源」一页，不再每 3 秒轮询。

02 / 只在有事时冒头

有任务排队时标题栏出现「等待 1」，MCP 关着却仍有调用进来时出现「MCP 已拒 N」；没事不渲染。和现有的更新角标是同一个模式。已定（2026-09-14）：排队的终端模块本身暂不显示排队状态，这条提示是用户唯一能知道「为什么点了没反应」的地方。

03 / 读数先行

CPU、内存做成带阈值刻度的量表，切换普通 / 节能时刻度跟着挪；旁边是服务数和等待数。

04 / 服务收成卡片、默认收起

每个项目一张小卡，芯片是在跑的东西；时长、归属、定位 / 关闭收进点芯片弹出的小面板。托管服务与最近结束默认折叠，折叠态留一行摘要；选了项目筛选时自动展开。

05 / 定位到模块

弹出面板里的「定位」把画布视口挪到那个模块（会先收起设置）。需要新增 pty / agent → 画布节点的映射，尚未落地。其余动作都对应现有 IPC。
