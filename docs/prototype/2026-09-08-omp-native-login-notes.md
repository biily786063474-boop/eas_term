## 交互稿
`2026-09-08-omp-native-login.html`：10 个场景，支持亮暗切换和模拟状态跳转。

1. 从 OMP 动态读取供应商；稿中 Google / Anthropic / GitHub 只是示例，不是兼容性承诺。
2. 浏览器授权：只展示当前动作、打开页面和复制链接。自动回调流程不默认展示文本输入。
3. 确认连接：仅在收到真实原生事件时呈现，不虚构中间状态；若协议无法观察凭证保存阶段，显示通用等待状态。
4. 已连接：必须凭证保存成功后进入。真实模型列表单独加载，失败不能反向宣称账号未登录。
5. 手动补充：仅在 OMP 支持且请求时出现。授权码和完整回调内容作为文本转交，不能强制 HTTP URL 校验、主动抓取或打开。
6. 设备码：独立呈现供应商要求的设备授权，不假设所有供应商支持此方式。
7. API 密钥：只在原生流程明确需要时呈现，不让订阅账号走错误分支。
8. 失败：原型展示超时；实现时按真实错误区分端口占用、拒绝、网络、过期，避免错误归因。
9. 取消：失效当前请求，旧进程、旧回调不得修改新一代登录状态。
10. 光标：近白/近黑 2 px 绘制光标、原生 caret-color 和聚焦描边；此稿可编辑区仍为系统光标，2 px 为旁边视觉示意，需真实 CodeMirror 回归。
