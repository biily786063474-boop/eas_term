# Eas-Term 口播稿 · 简短版（≈ 90 秒）

> 用途：短视频 / 安利向口播。面向「经常用终端 Vibe Coding」的人群。

经常用终端 Vibe Coding 的小伙伴们有福了！我最近发现一款超顺手的桌面终端工具，叫 **Eas-Term**，简直是给我们这种天天泡在终端里、一边跟 AI 对话一边跑命令的人量身做的。

它最戳我的一点是——**终端跟着项目走**。你把项目文件夹往侧边栏一加，新开的终端自动就在这个项目目录里，再也不用一遍一遍敲 `cd` 了。

更爽的是，主区域能像 Blender 那样**任意分屏**：一个窗口里，这边跑终端、那边开代码预览、底下再放个图片预览，想怎么摆怎么摆。点一下文件，代码、图片立马在旁边显示出来，不用来回切窗口。

细节也很到位——终端里打印出来的**文件路径能直接点开**，选中文字一键复制，右键菜单该有的全都有，用起来特别跟手。

颜值还在线，整个界面是那种**液态玻璃**的半透明磨砂质感，看着就舒服。而且 **macOS 和 Windows 都能用**。

总结一句：如果你也经常一边跟 AI 结对、一边跑命令、一边管一堆项目，那这款工具能把你乱糟糟的桌面收拾得清清爽爽。感兴趣的话，去试试看！
