已批准设计与边界

全局时间线与插件热启停 · 已确认设计

产品目标

时间线是全局工作轨迹，不是单项目专属对话。默认月热力图汇总所有已授权项目；点击某日，弧形拨轮显示跨项目成果及项目标签。顶部项目标签支持多选/全部，月份统计、日期列表与详情共享筛选条件。保留 CSS 弧形动效、zoom、呼吸粒子、减少动态效果。

范围与边界

- 全局仅指本机 Eas-Term 已登记且获授权的项目/受管 AI 对话；不是全盘扫描，也不承诺任意第三方软件和裸终端可观测。

- 开启不要求重启应用或重建已有对话，不抢占当前对话选中的 MCP 插件。新事件开始捕获，不默认回填历史。

- 全局开关默认关闭；用户开启一次后，新登记项目默认纳入，并可排除单个项目。界面必须写明范围。展示筛选不改变采集范围。

- 关闭、卸载、更新替换立即撤销事件订阅并清空未提交缓冲；已落盘数据保留。持久化开关重启恢复，插件缺失时显示不可用，不装作仍在记录。

- 无额外模型调用、无 TypeSafe、无外网。捕获的是候选，不是验收证明。

数据与身份

项目仍用现有 .eas/timeline.json 保存正式成果；候选用独立 .eas/timeline-candidates.json，不污染成果表。

全局授权配置放 userData/plugin-event-grants.json，项目登记沿用 userData/projects.json，由宿主固定路径管理；插件只获取用户授权项目的可信 id/name/root 快照，不能通过参数自报任意路径。

使用 projectId + 本地记录 id 联合寻址；不同项目相同 taskKey 不是重复。根目录按真实路径规范化，worktree 归属通过现有 projectRootOf，重复根只读一次。

全局读取按发生日与创建时间稳定排序后统一分页；不得先各项目分页再直接拼接。项目损坏/离线时返回局部错误，界面显示“不完整”，不能伪装零成果；继续显示其他可用项目。

项目筛选为空数组表示未选项目，省略表示全部；非法/未授权 projectId 拒绝，不能悄悄退回全部。

热插拔协议（待实现）

宿主提供通用、按授权范围派发的受管会话完成事件，而不是把时间线规则硬编码进所有 CLI：

- 插件清单声明 versioned 事件订阅权限（agent.turn.completed），默认不授权。

- 仅面板用户操作可调用宿主开启/关闭；AI tools/call 不能代替用户开全局权限。

- 事件最小字段：eventId/sessionId/turnId/projectId/完成时间/有界结果文本/终止类型。来自宿主真实事件，不信任模型自报项目或成功。

- 不转发 text.delta、不转发完整历史、工具秘密/环境变量；仅 turn.done 形成摘要事件，文本最多 4000 字。失败/取消不产成功候选。

- 每次开关/排除项目/卸载增加 generation；队列执行前检查权限与 generation，过期任务丢弃。单插件有界串行队列，报错可见，不阻塞聊天。

- 插件进程更新时撤销旧订阅并以新 generation 重握手；文件仍在不代表旧进程自动更新。

候选与成果

本地规则仅识别明确交付语句，从原文摘取标题与说明，不生成不存在的证据；否定、未来计划、仅问答应跳过。规则可漏判/误判，因此 UI 必须显示“待确认候选”。

同一个 turn event 重投以 eventId 幂等；跨轮语义相同不能仅靠字符串判断自动合并，用户可以选择关联已有成果。

正式 timeline_record 成功回执存在时不重复产候选；候选确认通过原 record 路径写入，再标记已处理。候选忽略不删除正式成果。

热力图默认计数正式成果（含 pending），候选另显示数量；避免启发式误判放大热力图。详情明确来源与状态，不把文字“测试通过”当真实已验证。

评审结论

- 完成性：必须以未绑定时间线的既有受管对话触发事件验收，专属插件对话不算热插拔验证。

- 体验：一个全局入口，筛选与采集范围明确区分；空态能说明“未开启 / 无成果 / 读取失败”。

- 成本：事件转发和规则筛选为本地执行，额外模型 token 为零；代价是候选需确认，不能宣称零漏记。

- 安全：事件订阅新增读权限，需要用户授权和撤销；所有项目写入仍过 guardDir/guardPath，不能删除旧守卫。

发布边界

当前本机 0.4.101 未包含旧时间线宿主集成，不能靠复制插件目录假装升级完成。首次启用通用事件协议需要更新宿主；后续兼容该协议的插件可热启停。旧宿主明确显示“不支持自动记录”，保留手动工具路径。
