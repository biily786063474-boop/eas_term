# AI 对话公共协议

2026-09-07。类型真相在 `src/shared/agentChat.ts`；本图纸解释约束，不定义第二份协议。

## 能力与生命周期

`CliAdapter` 负责 CLI 参数、传输、探测与原始事件翻译。会话层管理进程和公共事件，前端根据 `CliCapabilities` 渲染，不能按 Codex/Claude/omp 名称决定控件。

`agentChat:event` 使用固定通道和 sessionId 信封；preload 提前监听的顺序不变。`session.ready.sessionId` 是 CLI 的恢复标识，`model` 为空表示 CLI 未确认实际模型，不能用用户选择填造事实。`turn.start` 表示已投递；`turn.done` 结束当前轮，进程退出和会话删除是不同状态。Codex 保持 stdin ignore，恢复参数为 `exec --sandbox X resume ID …`。

## 模型目录

`ChatModelOption` 包含 id、label，可选 effortLevels、defaultEffort。按模型给出的档位优先；没有时保留 harness 的全局档位。模型选择和强度选择通过 setParams 在下一轮应用；切模型清除原强度覆盖。

`capabilities` 事件按字段更新，数组整体替换；缺席字段不清空其他能力。可选 `modelCatalog` 包含 status（loading/ready/error）、source（probe/cache/fallback/none）、updatedAt 和 note。旧 harness 不提供该字段时维持旧行为。

首次探测失败也保留状态与刷新入口；缓存、内置目录须标明来源。`agentChat:refreshModels` 校验 sender 所有权，复用原探测通路，不重启对话。目录更新只要求会话对象和请求代次仍匹配，不要求本轮进程存活；删除或替换会话后忽略晚到结果。

Codex 通过共享 PROBE_ENV 启动 app-server，依次 initialize → initialized → model/list，读取 nextCursor。握手失败、坏响应、循环分页、超时均降级，收尾先 TERM 后 KILL。成功探测在进程内缓存 60 秒，以可执行文件和环境的哈希隔离来源；刷新绕过成功缓存，同时复用正在进行的同源请求。磁盘目录仍按 CLI 保存，只能证明上次成功，不能证明当前账号可用；账号变化后应刷新，失败时明确显示缓存来源。

## 文本、工具与插件

`text.delta/text.done` 继续交给已有 Markdown 渲染器。工具使用 `exec.start/exec.done`，可选 tool（server/name）和 resources（uri/name/mimeType）；缺省仍按 label/detail/output 显示。三个翻译器将工具内容归一为可读文本，未知内容保留降级信息；Codex MCP 的 isError 不能显示为成功。

资源元数据随历史保存。HTTP(S) 入口再次验证协议和凭证，使用对话 leafId 定位同 Frame 浏览器。`ui://` 只映射当前会话插件清单中 entry 完全匹配的面板，交给既有 PluginPanel 的 resources/read、握手和权限检查；未知或缺失资源显示不可打开，不执行任意 URI。

`plugin.status` 的 selected/missing 来自用户选择和已安装清单，只读展示，不代表已注入、已认证或连接成功。实际调用结果由 exec 事件表达。插件选择仍保持单插件语义；本次没有新增安装或连接授权流程。

修改能力/事件时同步 shared、adapter/translator、session、preload、reducer、toolbarModel、history 和隔离基线；UI 文案不得伪造未报告的运行状态。验证记录在 `docs/verification/agent-chat/README.md`。测试回放覆盖公共组件，不能替代每个真实服务的端到端验证。

## 首轮前模型选择（2026-09-07 补充）

`agentChat:modelCatalog(cli, force)` 返回 AgentChatModelCatalog，不要求 sessionId，不创建对话。与会话后的刷新共用 resolveAdapterModels、缓存与探测器。StartupModelPicker 在选择 CLI 时立即请求，组件以 CLI id 为 key，卸载后忽略旧响应；选择按 CLI 隔离保留。启动页显示启动模型、思考强度和首条消息模型摘要。显式选择优先于角色默认；更换模型不继承角色的强度覆盖；未选择时保留角色/CLI 默认，不填造未知的默认模型。首轮与恢复失败重试共用 startupParams。
