浏览器最大化比例入口（2026-09-28）：`WebView.onZoomChange` 仅由 `CanvasFileNode/CanvasFreeFileNode` 在 `isMax` 时传入 `setMaxScale`，地址栏的「−/百分比/＋」共用 `zoomMath.clampContent` 0.5–3。这控制 guest `setZoomFactor`，不改 `canvas.viewport`，不恢复刻意隐藏的 `.canvas-zoombar.on-max`（否则重新遮挡终端/AI输入框）。`dom-ready` 用最新 `zoomRef` 恢复比例，覆盖刷新及懒挂载，退出最大化仍沿用原有归1逻辑。

聊天返回图片与调整方向（2026-09-28）：`agentChat/session.emitEvent` 在三CLI事件进 preload 缓冲前调用 `chatImages.persistChatEventImages`；原图由 `chatImageStore` 按 SHA-256 去重写入 app userData/chat-images，`shared/chatImages` 只接受受限 inline 或 `eas-chat-image:<sha>.<ext>`。IPC/renderer/history 存引用，`fsGuard.guardChatImageFile` 限定固定目录、文件名和 symlink；不能新增任意模型路径读取或网络取图。`historyImages` 迁移旧档；`saveArchive` 必须把 previous 交给迁移器，防止迁移写失败后 UI 引用回存覆盖唯一 inline。`chatImageDimensions` 在 main 仅解析尺寸，拒绝 >16MP，绝不在 main 解码；renderer `ReturnedImages` 可视区加载、两路解码、384px缩略图、离屏清除像素并保持固定布局。恢复仅接受原哈希对应的用户已有文件，不调用生成模型。单图2MiB与单事件4图安全上限仍保留，历史8MiB只适用于旧inline兜底，不裁剪本地引用。

对话提问导航性能（2026-09-25）：`agentChat/QuestionNavigator.tsx` 会随画布几何变化更新 body portal 的轨道位置，但画布纯平移不改变提问在消息容器内的相对位置。`questionIndex.ts` 的 `QuestionTopMeasure` 缓存这一判据：仅滚动、缩放比例变化、正文 DOM 变化、异步媒体加载、字体加载或容器 resize 时重读每条提问的 rect。**不能停止几何观察器**，否则轨道在平移时脱节；也不能把正文变化当作纯平移，否则活动提问会错位。隔离应用 4 对话×60 提问、60 帧平移：提问 rect 读取 4560→120；滚动后活动提问仍更新。此优化不代表长运行内存或标题栏合成闪烁已解决，见 `docs/verification/performance/2026-09-25-root-cause.html`。

### 对话待发送队列（2026-09-07）

`agentChat/messageQueue.ts` 是每个会话的渲染层 FIFO 控制器，`useMessageQueue.ts` 按 sessionId 隔离生命周期。普通发送在忙碌或投递未返回时入队；只有实际投递才进入现有乐观消息/失败回滚路径。`turn.done` 释放下一条，fatal 或投递失败暂停并保留；手动停止也暂停。调整方向优先选中消息，经过原有 interrupt IPC，收到终止事件后发送，其他消息保留。主进程仍保留忙碌校验；非 ACP 显式中断需淘汰旧 processGeneration，禁止旧输出污染新轮次。不得用渲染完成或定时器猜测可发送。

队列当前为会话内存状态，不跨应用重启持久化；新建对话有放弃队列确认，销毁后不得继续投递。验证入口：`node scripts/verify-agent-chat-ui.mjs --queue`（三端真实 Electron UI、隔离模拟 CLI）。

- **中键平移（修复轮 1）**：`CanvasStage` 的中键平移挂在 document 捕获阶段，iframe 接收指针后会吞掉正文上的中键（用户未接受这个代价）。桥把可信的中键 `pointerdown` 报成 `canvas-pan-start`（不报 select，并 preventDefault 中键 mousedown），按住期间 `pointermove` 报 `canvas-pan-move`（带 `screenX/Y`），松开/失焦报 `canvas-pan-end`。宿主（「指针在面板里」闸门）在 iframe 元素上派发合成 `mousedown(button 1)` 进 `CanvasStage` 原有中键监听起 `beginPan`，后续移动换成 document 上的合成 `mousemove/mouseup` 交给 `beginPan` 自己的监听 —— **不另写平移**。移动坐标用屏幕坐标差推算（平移会挪动 iframe，按 iframe 坐标换算会自激）。`beginPan` 走共用画布拖拽，拖动期间 body 挂 `canvas-dragging` 让 `.plg-frame` 不接指针；宿主真实 mouseup、窗口 blur、`buttons` 不含中键、卸载都会收尾。中键平移不看选中，与「模块上按中键也能拖」一致。**Chromium 在中键按下后是继续把拖动路由给 iframe 还是交回宿主，未经真机确认**；两条路都有接应，不会同时发生。

### 2026-09-29 发布台插件（publish-desk P1）
`resources/plugins/publish-desk/`：内置插件，自动发现、默认开启。AI 用 `desk_*` 六个工具按平台写卡片，用户在面板里复制、打开发布页（画布网页节点，`persist:browser` 记登录，每个平台一个账号）、自己点发布、回来标记。数据在插件全局 `EAS_PLUGIN_DATA/publish-desk.json`（不按项目）；平台表 `lib/platforms.mjs` 每条字数规则带来源与 `verified`，非官方值只提醒不拦。插件不联网、不注入网页、不点发布。
宿主为它加了两个面板动作 `panel/clipboard.write`、`panel/reveal`：判定在 `shared/panelHostActions.ts`，渲染层闸门在 `PluginPanel.tsx`（本地插件 + `document.activeElement` 是本面板 iframe + `navigator.userActivation.isActive`，**取值必须在任何 await 之前**），主进程 `pluginHost.ts` 再判内容（≤64KB 纯文本；reveal 过 `guardPath` 且须为已存在文件）。不要给这两个动作开批量或定时口子，每次一击是它们安全的全部理由。设计与偏差见 `docs/superpowers/specs/2026-09-29-publish-desk-design.md`。

### 2026-09-30 发布台违禁词检测（publish-desk P2）
词库在 `resources/plugins/publish-desk/lexicon/`（`law.json` 广告法与执法指南、`platform.json` 各平台社区规范），引擎 `lib/lexicon.mjs`，加载 `lib/builtin.mjs`。**每条必须带依据链接、条款号、原文摘录**，缺依据整库拒绝加载（不跳过）；命中一律是提示不是禁止。原文与取法、哪些没找到原文见 `docs/knowledge/publish-desk-lexicon-basis-2026-09-30.md`——**加词条前先对原文，提示文字不许比原文说得更重**（例如抖音第 35 条有「以谋取不正当利益等为目的」的前提，B站条款限定「可能引发争议、损害用户利益」）。视频号对一般内容、X / Reddit 没有对应条款，故意不设词条。用户记下的词存在插件数据的 `lexicon` 数组（`desk_lexicon`），内置词条删不掉。
