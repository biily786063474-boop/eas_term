# 首次发送自适应网络退让

## 规则
- 正常1秒FIFO错峰，不限制正在执行的任务数量。
- Electron本机联网提示为离线时暂停未发送队列，每秒复核，无外部探测请求；恢复至少2秒后逐个放行。
- 仅当前任务真实协议错误中的明确网络码/429触发退让，每任务一次，间隔2/4/8/16/30秒封顶。
- 退让之后启动的新任务正常完成后，间隔逐步减半回到1秒；此前旧任务的成功不覆盖新故障。
- 未知错误、慢响应、工具执行、MCP错误、鉴权/配额错误不用于推断网络波动。没有自动重发；已发送请求不因本功能取消。
