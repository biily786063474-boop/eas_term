# 执行清单外挂圆环交互验收

## 产品规则
- 仅画板中的 AI pane 外挂，不占正文布局；宽度上限 260px。
- 当前组件首次读取一个新 planId 时完整展示 3 秒；同计划版本更新不重复预览。
- 3 秒后收起，鼠标停留或键盘焦点在清单内时保持展开；移开/焦点离开后延迟 240ms 收起。
- 每项任务一个圆环：空心待办、缺口环执行中（仅会话 busy 时旋转）、灰实心 AI 报告完成待验收、强调色实心用户已验收、虚线环受阻（不旋转）。标题提示保留准确状态。
- 悬停、点击、键盘聚焦均能展开。展开 280ms，减少动态效果时禁用旋转与过渡。
- 任务多时圆环列限制 40vh 可滚动；窄屏详情钳制在屏幕内。
- 这些逻辑属于统一 renderer 产品代码，随主程序分发/升级；不是提示词或测试实例专属。目前未合入 main、未发布。
