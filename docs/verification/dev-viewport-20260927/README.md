# 调试页比例留白修复

原因：观察窗固定1080×780，截图用contain放入任意宽高比的区域，产生额外白边。此前真实应用截图已显示此现象。

修改：ResizeObserver读取容器布局尺寸（不受画板缩放影响），120ms合并尺寸变化，经受限宿主IPC更新原观察窗口contentSize。最长边2048等比限制；非法值拒绝；独立弹出及隐藏会话不调整。不重新导航，不改变本机网络隔离，不使用cover裁切或拉伸。页面自身的空白内容不属于本次修复。

验收：构建及类型检查通过；真实隔离Electron测试涵盖容器改宽高、画板双层区域、最大化比例匹配、非法尺寸、弹出返回，以及原报告/授权/工具操作回归。初次新增的默认比例测试旧版也能通过（默认窗口尺寸恰好接近），因此补上了显式容器尺寸变化测试，未把初次测试作为有效红灯证据。
