# 后台闲置内存整理：非窗口重建

实现连续后台闲置一小时后，保守条件满足时调用Chromium HeapProfiler.collectGarbage，仅释放不可达JS对象。不会刷新页面、关闭会话、清除Markdown缓存或删除草稿。活动服务、任务、guest、调试器阻止整理，前台返回重置计时；设置可关闭。

验收：纯策略及控制器8项测试通过；scripts/verify-idle-memory.mjs在隔离真实Electron中以加速时钟验证busy阻止、原生GC执行、未保存DOM文本保留、调试器归还，result.json/native.png留证。未改用户网络或正式应用。

限制：这不是完整的“像刚启动一样”恢复。全模块持久化屏障/整窗替换未实现；实际一小时驻留、内存释放量、恢复延迟和Windows未验证；不能声称解决所有挂机卡顿。此阶段不以GC次数冒充性能收益。

最终复验：3862通过、19跳过、0失败；构建通过，选项隔离UI与真实Chromium加速内存整理再次通过。独立复审两项修复通过。
