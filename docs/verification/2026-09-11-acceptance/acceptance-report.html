1 · 密钥柜解锁 通过

  • 锁定即弹窗：柜子锁定后调 secret_check，开发实例自动弹出「解锁密钥柜」窗，底层画布灰化模糊；无需用户去找钥匙入口。
  • 原请求自动续上：用户输入六位码提交后（20:56:58 弹→20:57:05 关），同一次 secret_check 调用直接返回柜内清单，画布恢复。
  • 解锁 ≠ 授权：弹窗文案「解锁不会新增密钥授权」，且解锁只放行清单读取，不放行任一密钥组。
  • 首次说明：再次解锁窗无「在这台设备上加密保存 / 由你决定哪个会话可用」那段介绍（仅建柜 !configured 时渲染）。未验证 本轮未重建柜子，建柜首次说明未复核。
观察缺陷 B2：弹窗挂满 10 分钟后主进程侧按上限超时，工具返回 渲染层超时未响应，但渲染层弹窗与 pending 不清除 → 孤儿弹窗残留，后续任何密钥请求被拒（已经有一个密钥请求在等用户处理了），需用户手动关窗。且该超时文案对密钥三件套词不达意（wiki_archive_plan/team_spawn 有人话版）。

2 · 密钥柜界面 通过

  • 最近使用记录：收起时无大块空白；展开后区域可滚动（.sec-audit[open]{max-height:180px;overflow-y:auto}）。
  • 预设切换：新增密钥时点 Lovart → 阿里云 → AWS，组名与变量列表同步变化（如 LOVART_ACCESS_KEY/… ↔ ALIBABA_CLOUD_ACCESS_KEY_ID/…）。
  • 全程未替用户填写或提交任何凭证。

3 · 当前 AI 节点的密钥能力 通过

  • 命令可用：eas-secret 在 PATH（隔离 bin/），会话通行证 EAS_SECRET_TOKEN 存在（长度 48，未打印值）。
  • 先拒后批：未授权时 secret_check 报 missing、eas-secret run 返回 密钥柜里没有这些变量；经 request_secret 授权后同一终端重跑成功，无需重开终端。
  • 只输出长度：printf "%s" "${#VAR}" 得 EAS_VAULT_ACCEPTANCE_X=14、_Y=6；值从未进对话。
  • 拒绝即无权：对 _Z 点取消 → saved:false，secret_check 仍 missing，eas-secret 被拒 → 未获得访问权。
  • 审计可追溯：记录形如 eas-secret · ac-2 · EAS_VAULT_ACCEPTANCE_X，含会话 ID 与变量名，不含值。
未验证 ①「已存在但未授权组，只授权不重填」子路径——本会话所有测试组建时即授权，无该中间态可测；②旧 token 在节点关闭后失效——需独立控制端，无法在本节点安全完成，未导出 token。

4 · 图片 popup 用户自行验收

  • 按用户明确要求，此项由用户自行验收，我未重复驱动，不对居中放大 / Esc / 遮罩 / 关闭按钮 / 滚动位置做独立结论。
附带观察 B4（既有限制）：本项目路径含空格（vibe coding），而 Markdown 图片正则 !\[..\]\(([^)\s]+)\) 不接受带空格路径 → 本项目内 AI 回复里的图片无法以图渲染，只显示原始 ![](...) 文本。

5 · 产物交付到 Frame 主体通过

  • 三类落 Frame：test-doc.md(code)、test-page.html(web)、test-image.png(image) 经 canvas_open_file/html/image 显式提交，全部落当前 Frame，content_slots 3/5。
  • 重复提交复用：三者再次提交均返回相同 nodeId、reused:true，名额仍 3/5，不新增节点。
  • 内容刷新：改为 v2 后再提交，Markdown 标题+追加行、HTML 标题、图片图案均刷新。
  • 不越权：提交前 Frame 仅 agent 节点；多次在回复中提到路径、Read 过图片，均未触发自动打开——不扫描回复路径、不把输入素材当产物。
  • 脏草稿保留 通过：隔离 CDP 中在编辑器输入 ZZZ-DRAFT（dirty=true），随即触发同一产物「重新提交」（refresh），草稿保留（仍 123 字符、仍在编辑态）；磁盘文件未改。
失败 B1：dev 实例上某个 test-doc.md 节点点「编辑」后，编辑器正文空白且无法输入（「保存/完成」按钮在 = text 已加载，却无内容）。磁盘文件完好（213 字节），是显示问题非数据丢失。隔离实例三条路径（新建→编辑 / 反复刷新→编辑 / 编辑中途刷新）均未稳定复现该空白态，根因未隔离，记为「观察到一次的失败」，建议开发者在真实 dev 实例复查。
观察 B3（可复现）：进入编辑态但尚未输入（未变脏）时，若同一产物被重新提交，会被静默切回排版视图，编辑意图丢失（无数据丢失，因尚无草稿）。
