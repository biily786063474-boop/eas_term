# 安全闲置窗口恢复验收（2026-09-27）

## 实现
生产一小时连续后台、无任务/服务的策略先请求保存确认；隐藏候选窗口只读加载内存快照，验证成功后由旧 renderer 同步 seal 交接，销毁旧 renderer。失败保留旧窗口。没有全局杀进程、没有写入明文草稿/密钥存储、没有自动发版。

## 验证与边界
- `scripts/verify-idle-window-recovery.mjs`：隔离真实 Electron，检查新旧 OS PID 不同、旧窗口销毁、草稿/图片/聊天历史/分屏恢复；见 result.json 和 restored.png。
- `idleMemoryRecovery.test.ts`：生产计时器假时钟覆盖 59.5 分钟不触发、60 分钟触发一次、失败 GC 回退、前台/任务/关闭开关否决。**未真实等待一小时**。
- 独立审查修复：异步 seal 编辑缝隙（改同步交接）、destroy 失败旧权限保留、候选 ready 后崩溃粘性否决。新增回归包含注入异常与迟到活动；崩溃用例先红后绿。
- 第一次实机替换因窗口最大化被正确否决；改测试为普通窗口。一次测试误用 Electron 不支持的 Browser CDP 方法，改为仅 EAS_VERIFY 下设置验收窗口大小。没有放宽生产检查。

## 保守范围（不等于全部重启）
未知编辑器/网页/插件面板、仍有 sessionId 或归属的会话、待确认、辅助窗口（含灵动岛）、原生全屏/最大化仅执行 GC，不强制替换。候选 renderer 崩溃、保存失败、恢复中输入或新任务均取消交接。不会重启主进程，也不承诺内存值等同刚启动。

macOS 12+；实体跨屏、真实模型付费端到端、macOS x64 签名公证未在此验收中覆盖。Windows 检查记录独立列出，不将旧提交 CI 冒充本次 CI。

最终本机全量：3930 项 / 3915 通过 / 15 条件跳过 / 0 失败（去掉8项未用原型测试，加入2项bridge测试）；typecheck、build通过。真实新窗口15项通过，截图已眼验。failure.json/png保留早期失败记录，以result.json为最新结果。

## 最终封口
- 同步 seal 的 `event.returnValue` 只在提交完成后赋值，避免提前释放旧 renderer；setter 断言先红后绿，独立复核通过。
- 设置/密钥等有 `role=dialog` 或 `aria-modal=true` 的弹窗、打开的知识/资源/辞典抽屉、待归档以及非空转录队列也否决窗口替换。未登记、未标注语义的局部表单不作为已全面覆盖的能力宣传。
- 合并候选另启 Electron42 独立依赖目录验证，未修改主工作区已有 Electron37 依赖链接。
- 额外启用本机条件项：真实 OMP admission/redirect、缺失 Bizone 的本地模型链路、原生 Codex 配置解析、clangd 共16/16通过；这些不调用付费上游，也不等于在线模型端到端。
- 主进程发起的 MCP 调用也独立登记 admission（普通工具与 page_live 分支），直到结果/超时/异常才释放，不能只统计 renderer 发来的 IPC。
- 一次实机“确认弹窗否决”测试遇到后台只读 IPC 在途，先在主进程入口被拒，而非到 prepare 才拒；测试改为等待在途操作结束后再验证该层否决，不放宽生产保护。CDP调用补有界超时，防止隐藏窗口失败截图令验收脚本挂起。
