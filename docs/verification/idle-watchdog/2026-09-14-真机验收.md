## 证据（隔离实例，`node scripts/verify-app.mjs --seed`，构建 = 本次改动）

- 单元测试：`npm test` 3186 条，0 失败（新增 7 + 4 条）；`npm run typecheck` 0 错；`npm run build` 通过。
- 看门狗（`EAS_IDLE_WATCHDOG_INTERVAL_MS=5000 EAS_IDLE_WATCHDOG_THRESHOLD=20`）：
  - 空闲 12 秒：`flicker.log` 无 `idle-watchdog` 行（不误触发）。
  - 渲染层放每帧烧 2.2ms 的 rAF 循环 `burn25`：
    `m idle-watchdog 渲染 33% · GPU 1%（单核口径）空闲超线 ≥ 5s ×2 → 已抓 idle-20260914-092935 | JS 忙 25.8% · burn25 @ ?:0 839.6ms …`
    `diagnostics/idle-20260914-092935.cpuprofile` + `.json` 落盘。
  - 换算坑：`percentCPUUsage` 按全部核心归一化，主线程烧满在 15 核机上只读 7%（第一次实测），已乘核数修正。
- 光环：摘掉失焦暂停属性（`html[data-visual-paused]`，app 自己的后台停绘）后，9 个光环 = 视口内 3 个 running、视口外 6 个 paused。
  注意：隔离窗口通常无焦点，`data-visual-paused` 会把**全部**动画 paused，验这类东西先摘它。
- 提示音：设置 › 试听「任务完成」，`sample` 渲染进程线程名：试听后 0.5s 出现 `AudioOutputDevice`，3.5s 后消失（挂起生效）；
  `Reverb convolution` 两条线程仍在（卷积节点自带，全程等消息，不占 CPU）。
- 广播分发：`window.api.browser.onFavorites` 挂两个订阅者后 `browser.change({type:'folder'…})`，两者都收到（`received:true`）；
  写的是隔离实例自己的 `browser-favorites/`，真实 userData 无该目录，未污染。
