# 代码地图：点文件即打开代码预览 · 隔离验收（2026-09-14）

用户要求：地图上点 `xxx.ts` 这类文件节点时直接打开代码，而不是只在图上高亮。

| 步骤 | 观察 |
|---|---|
| 画布放入「代码地图」组件（Frame 绑定 p-verify） | 领地视图渲染，SVG 节点带 `role=button` 与 aria-label |
| 点「主进程」下钻 → 点 `pty.ts` 节点 | 同一 Frame 新增代码预览节点，`filePath` 为该文件绝对路径；Frame 节点数 1 → 2 |
| 点下方文件列表里的 `pty.ts`（第二个入口） | 复用已有节点，不重复开（节点数不变） |
| 点文件列表里的 `fsGuard.ts` | 再新增一个预览节点（2 → 3），见截图 `click-opens-code-node.png` |

分屏模式下走既有 `openFile`（向右分屏出预览），未单独眼验；符号视图（SymbolView）的节点是符号不是文件，未改。
