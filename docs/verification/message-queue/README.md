# 对话消息队列验证

普通消息忙时加入 FIFO 队列；调整方向停止当前轮次，收到结束确认后优先发送所选消息，其余队列保留。手动停止暂停队列，发送失败保留内容并允许重试。新建对话需确认放弃待发送内容。

- `npm run check`：2555 项通过，0 失败。
- `node scripts/verify-agent-chat-ui.mjs --queue`：Codex / Claude / OMP 共 30 项真实 Electron UI 检查通过，渲染控制台错误 0。
- UI 检查通过隔离夹具控制 CLI 发送、停止和轮次事件，没有调用真实模型；不能替代三家服务的线上端到端验收。
- 队列仅保存在当前会话内存，不跨应用退出或重载保存。
