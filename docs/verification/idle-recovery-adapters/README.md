# 闲置恢复：实际模块接入验收（2026-09-27）

## 本轮接入
- 首轮/后续聊天输入：文本、辞典引用chips、图片元数据、模型/沙箱选择进入有界的内存检查点，不新增明文磁盘草稿文件。
- 图片：异步缩略图/落盘期间否决恢复；已被历史引用的retained文件所有权随检查点转移；交接卸载不删除附件，正常用户移除仍沿用原有删除规则。
- 聊天记录：跟踪进行中的写盘，只有成功ACK清待保存引用；恢复准备阶段等待写盘并补写最新记录，历史未加载/任务/消息队列/切换中拒绝恢复。
- App画布：已接成功ACK保存屏障；启动加载失败不授予恢复资格；补异步启动晚到卸载保护。
- 工作区：显式传递项目选择、tabs及分屏树/比例/leafId、画布布局/viewport/撤销栈/最大化选择。不是序列化所有store函数或插件数据。
- 编辑器、网页、插件/未知组件、存活会话/终端、待确认对话和未解析节点明确否决，不强行关闭。

## 验证方式与边界
scripts/verify-idle-recovery-adapters.mjs 用独立临时userData/项目、实际Electron和真实输入、粘贴图片、磁盘聊天历史，执行React root卸载再从检查点重挂载。没有调用在线模型、没有修改用户正式应用。
这是**实际界面状态恢复**验证，不是BrowserWindow替换、不是新渲染进程、更不是真实一小时驻留资源回收。main闲置事务尚未接生产计时器、窗口生命周期与任务准入闸门；全功能仍不可标完成。dev/EAS_VERIFY的__recoveryVerify仅测试入口，普通打包运行不暴露；不向插件开放恢复权限。
