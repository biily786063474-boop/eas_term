Eas-Term Windows 诊断测试版 0.4.85-diag.1（x64）

用途：收集“打开对话时退出”等问题的排查线索，不是已修复版。
这是单独提供的测试包，不上官网、不走正式更新。

1. 先退出正式版 Eas-Term。安装本包，运行“Eas-Term Diagnostic”。
   两版可以并存安装，数据目录分开；系统 AI CLI 与其接入配置仍共享，请勿同时运行。
2. 在诊断版重新添加要测试的项目，使用原来的 AI CLI 账号。
   不会自动复制正式版聊天或项目，不需要删除正式版数据。
3. 重复之前触发闪退的操作。记一下具体点击步骤、所选 AI 及大致时间。
4. 如果整个软件退出，重新启动诊断版，在“上次未正常退出”的提示里选“同意并发送”。
   若只是对话停止/白屏后恢复，去“设置 → 隐私”，点击“发送或导出诊断报告…”。
5. 看到“诊断报告已收到”后，把报告编号和复现步骤发给测试负责人。
   没看到成功提示不代表送达；可手动重试。网络不通可选“导出查看”，把定位到的
   diagnostic-report.json.gz 文件发送给负责人（不要发送整个用户数据目录）。
6. 测试结束退出诊断版，再打开正式版。诊断版可单独卸载，不需要卸载正式版。

隐私与大小：
只发送版本、系统版本/架构、启动阶段、错误类型、应用栈位置和退出码。
不包含聊天正文、完整命令、终端输出、密钥或私人路径。不默认收集原生崩溃转储。
新增诊断存储有总量上限（不超过10 MiB），单次上传不超过256 KiB；每次发送需本人确认。
报告在自家 eas.biily.top 接收服务保存14天，到期删除，没有公开报告下载页面。

Windows 若提示未知发布者：先确认文件确实由测试负责人提供，并核对SHA256SUMS.txt。
不要关闭杀毒软件或全局安全保护；如被拦截，请把提示截图发给负责人。
