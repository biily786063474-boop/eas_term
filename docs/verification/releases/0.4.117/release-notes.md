## 0.4.117 — 2026-09-28

### 升级前必读
- 本版需要 macOS 12+；macOS 11 用户请继续使用下载页保留的 0.4.113。本软件不会自动安装更新。

### 新增
- Eas-Term 有了自己的吉祥物「像素团子」：灵动岛状态、AI 对话里的「正在处理…」与「后台任务运行中」、画布左上角的任务监视器、空画布提示和 AI 对话首页都换成了它。运行中它的左耳会像光标一样闪；窗口不在前台或看不见时它就停下，不额外耗电。

### 改进
- 输入框下方「↑ 历史消息 · ↓ 返回」的键位提示更淡，不再和输入框的占位文字抢层级。

### 修复
- 恢复一个带着未完成后台任务的 Claude 对话时，第一条消息不再「没回答就显示完成」、需要再发一次才有回复。
- 任务清单卡片不再压在画布左上角的任务监视器和额度条上面。

### 兼容与限制
- Windows 仍为 10+ x64，安装包未代码签名，可能提示 SmartScreen；Intel 验证使用 Rosetta，不是实体 Intel。
- 本轮界面验收使用隔离实例与按真实协议录制的回放，未做真实在线模型端到端；外部 Computer Use 指针残留仍未解决。
