# Eas-Term 0.4.85 发布验收（已发布）

产品源提交 `9510ff29e94b143015691715f3e0bfbe16b1caa7`，分支 `feat/builtin-capabilities`。笔纵 1.21.31 已按用户授权先行上线；Eas-Term 0.4.85 已上线，标签 v0.4.85 指向发布提交 0cec8d9；0.4.84 安装包保留回退。

## 变化

- 工作台 MCP、笔纵连接器、使用指引统一为随包内置能力，复用现有插件宿主；设置中分别控制，不占用用户选中的业务插件位置。
- Claude Code、Codex、omp 的 AI 对话和受管终端入口显式装配能力，按发起会话绑定项目和 Frame。状态区分禁用、依赖不可用、未请求与握手就绪，不以零工具冒充成功。
- 笔纵连接按需建立并恢复；生成提交使用持久请求身份，未知结果先查询认领，不自动重新付费提交。实际计费断线验收仍待完成。
- 精确旧规则托管段在真实工具成功后才迁移，完整备份、校验并保留用户正文；第三方 MCP 与归属不明段保持。
- Windows 官方 npm CLI 统一解析到经过校验的原生或 JS 入口，Codex 取消/断连只清理所属启动进程和子进程，保留旧 vendor PATH 与包来源语义。
