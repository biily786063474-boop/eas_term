## 0.4.121 — 2026-10-02

### 升级前必读
- 本版需要 macOS 12+；macOS 11 用户请继续使用下载页保留的 0.4.113。本软件不会自动安装更新。

### 新增
- 插件市场支持用访问令牌连接的远程插件：令牌经系统加密保存、填完不再回显，可一键测试连接；关掉插件后，已经接好它的对话也会立刻断开。

### 改进
- 插件怎么用更直接：在侧边「插件」里点它、在 Frame 上右键 →「插件」、或配置完点「开始对话」，都会新开一个已经接好这个插件的 AI 对话；对话顶部会标明「已接好」。
- 在输入框里 @ 插件名不会建立连接，现在会直接告诉你该从哪里打开接好插件的对话。

### 修复
- 开着 Clash、Surge 这类代理（fake-ip 模式）时，远程插件不再因为地址被误判成内网而连不上；走代理时按域名连接。

### 兼容与限制
- Windows 仍为 10+ x64，安装包未代码签名，可能提示 SmartScreen；Intel 验证使用 Rosetta，不是实体 Intel。
