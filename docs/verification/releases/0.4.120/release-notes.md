## 0.4.120 — 2026-10-01

### 升级前必读
- 本版需要 macOS 12+；macOS 11 用户请继续使用下载页保留的 0.4.113。本软件不会自动安装更新。
- 新增英文界面。已经在用的你升级后仍是中文；新安装按系统语言显示，可在设置里切换。

### 新增
- 英文界面：主窗口、画布、各类面板、设置、灵动岛、终端、代码地图、时间线、知识库都有英文版；界面为英文时，AI 也用英文回复。
- skill 面板新增「AI 自动发现」开关：关掉后 AI 看不到这些 skill 的名称和说明，只有你在输入框用 / 点名时才用，能省上下文、也不会在不相干的任务里乱触发。可整体关，也可右键单个设置。用 / 点名时会直接执行。
- 发布台插件：按平台存稿、一键复制、在画布里打开发布页；本地检查违禁词（命中只提示，附法条或平台规范原文）；读取素材信息对照各平台规格，列出要准备的素材和封面。
- 设置里新增「关于与开源致谢」，列出用到的开源软件及其许可。
- 插件市场新增「效率工具」分类。

### 改进
- AI 的任务转到后台继续运行时，用单独的提示音和「后台运行中」标签，不再显示成「完成」；这条提示会一直留到 AI 接着回复。灵动岛直接显示 AI 的结果，不再先闪一个占位。
- 插件抽屉：品牌插件显示官方 logo，自家插件统一图标；系统插件不再混在「我的插件」和市场里，改到设置的「内置能力」；插件按来源分组。
- 作品画廊插件改为信息流：整行自适应网格、无限滚动，先加载看得到的图，并提前预取下一页。
- 启动和查看密钥柜状态时不再访问系统钥匙串，不会一打开软件就弹授权。
- 下载更新时立刻开始，不再排在其他任务后面等待。

### 修复
- 画布上的插件面板：第一次点击就能点到面板；没选中时滚轮仍然平移画布；拖拽不再被网页或插件面板「吞掉」，中键平移恢复，调整大小拖过面板也不会中断。
- 后台任务完成后 AI 自己接着回复的那一轮，执行清单不再报「缺少有效项目或轮次」。
- 后台任务还在收尾时新开对话，旧对话的提示不再串到新对话里。
- 密钥柜：从任何入口解锁后，等待中的功能都能马上继续；检查密钥前先真实确认密钥柜状态，不再误弹解锁；「信任此设备」勾选框不再超出弹窗边距。

### 兼容与限制
- Windows 仍为 10+ x64，安装包未代码签名，可能提示 SmartScreen；Intel 验证使用 Rosetta，不是实体 Intel。
- skill「AI 自动发现」开关只对 Eas-Term 里新开的 AI 对话生效；在终端里手动启动的 CLI 不受影响，omp 暂不支持。
