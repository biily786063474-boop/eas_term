交互行为

防抖 Debounce

高频事件(输入、resize、scroll)触发后延迟 N 毫秒再执行;若期间又触发就重置计时器,只有"停手"超过 N 毫秒才真正执行一次。用一个 timer 变量配合 clearTimeout/setTimeout 实现。典型场景:搜索框联想、表单校验。

交互行为

节流 Throttle

无论事件触发多密集,固定每隔 N 毫秒最多执行一次,保证匀速输出。与防抖的区别:防抖是"停手才执行",节流是"匀速持续执行"。典型场景:滚动加载、拖拽、鼠标跟随。

交互行为

骨架屏 Skeleton Screen

数据加载期间先渲染一组与真实内容布局一致的灰色占位块(常配合微光 shimmer 动画),等数据到达再替换。比转圈 loading 更能降低等待焦虑、减少布局跳动(CLS)。

交互行为

虚拟列表 Virtual List

长列表只渲染视口内可见的少数几项(外加上下缓冲),用一个撑高的占位容器 + 计算偏移量模拟完整滚动条。把 DOM 节点数从上万降到几十,解决大数据列表卡顿。

动效

缓动曲线 Easing

动画的速度不是匀速,而是按一条时间-进度曲线变化(cubic-bezier 控制)。ease-out 起快收慢显得干脆,ease-in-out 两头慢中间快最自然。缓动是让动效"有生命感"的关键。

动效

关键帧动画 Keyframes

用 @keyframes 定义动画在 0%、50%、100% 等时间点的样式快照,浏览器自动在关键帧之间补间(interpolate)。适合循环、多阶段的复杂动效(呼吸灯、加载转圈、位移+缩放组合)。

动效

交错动画 Stagger

一组元素(列表项、卡片)入场时,每一项比上一项延迟一小段时间依次出现,形成波浪式的节奏感。比全部同时出现更有层次、更高级。实现:按 index 递增 animation-delay,或用动画库的 stagger 参数。

动效

视差滚动 Parallax

滚动时,不同图层以不同速度移动(背景慢、前景快),模拟真实世界近快远慢的视觉,营造空间纵深。实现:监听 scroll 按系数给各层设置 translateY,或用 CSS transform + perspective。

UI视觉

毛玻璃 Glassmorphism

半透明面板 + backdrop-filter: blur() 对其背后内容做模糊,形成磨砂玻璃质感,配合细边框与轻微高光。常用于弹窗、导航栏、卡片。注意性能:大面积 blur 较耗 GPU。

UI视觉

新拟态 Neumorphism

元素与背景同色,靠一亮一暗两组方向相反的 box-shadow 模拟从背景"挤出/凹陷"的柔和立体感,像软塑料。视觉柔和但对比度低,慎用于需要清晰边界的按钮。

UI视觉

渐变 Gradient

颜色沿方向平滑过渡:linear 线性、radial 径向、conic 锥形。用于背景、按钮、文字(background-clip:text)。进阶:多色标(color-stop)、渐变叠加、动态角度做流光效果。

UI视觉

阴影层级 Elevation

用阴影的模糊半径与偏移大小表达元素"离页面多高",高度越高阴影越大越虚,建立清晰的层级关系(卡片 < 悬浮按钮 < 弹窗)。一套统一的 elevation 阶梯能让界面秩序感更强。

交互行为

自动保存 Autosave

监听表单或编辑器的 change 事件,配合防抖计时器在用户停止输入后延迟触发保存;通常用 setTimeout/useDebouncedCallback 把草稿 PUT 到后端或写入 localStorage/IndexedDB,并用 saving/saved/error 状态机在 UI 回显进度。为防丢数据,常在 beforeunload 或路由切换前 flush 最后一次未保存的变更。

交互行为

乐观更新 Optimistic UI

发起 mutation 时先立刻用预测结果更新本地缓存/状态,不等服务器响应就渲染成功态;请求成功用真实数据 reconcile,失败则回滚到 mutation 前的快照并提示。React Query 里 onMutate 中 cancelQueries + setQueryData 保存 rollback 上下文是典型写法。

交互行为

输入法组合事件 IME Composition Handling

中日韩输入法在拼字过程中会连续触发 input,直接取值会拿到未上屏的拼音串;通过监听 compositionstart/compositionend 设一个 isComposing 标志,组合期间跳过校验或搜索,组合结束再处理最终文本。也可读 event.isComposing 或 keyCode===229 来判断。

交互行为

请求取消 Request Cancellation

用 AbortController 生成 signal 传给 fetch/axios,当输入变化或组件卸载时调用 controller.abort() 终止在途请求,防止过期响应覆盖新结果或触发已卸载组件的 setState 警告。通常在 useEffect 的 cleanup 里 abort,或用 axios CancelToken、react-query 的自动取消。

交互行为

陈旧再验证 Stale-While-Revalidate (SWR)

命中缓存时先立刻返回旧数据(stale)让界面秒开,同时后台重新请求最新数据,拿到后静默替换并重渲染。SWR/React Query 用 key 做缓存索引,配合 focus/reconnect 重新验证、dedup 时间窗和 cache-control: stale-while-revalidate 头实现。

交互行为

请求去重 Request Deduplication

短时间内对同一 key 的并发请求只发一次真实网络请求,其余调用复用同一个 in-flight Promise;实现上维护 Map<key, Promise>,发起时若已有 pending 就返回缓存 Promise,resolve 后清除。也叫 request coalescing,常与 batching 一起把多次调用合并成一个批量请求。

交互行为

指数退避重试 Retry with Exponential Backoff

请求失败后不立即重试,而是按 delay = base * 2^attempt 递增等待,并加入随机 jitter 抖动避免惊群;达到最大重试次数或遇 4xx 不可重试错误则放弃。常用递归 setTimeout 或库的 retry/retryDelay 配置,只对幂等请求和网络/5xx 错误重试。

交互行为

游标分页 Cursor Pagination

不用 offset/limit(深翻页慢且易漏易重),而用上一页最后一条记录的稳定游标(id 或时间戳)作 next cursor,后端 WHERE id > cursor ORDER BY id LIMIT n 取下一批;响应带 nextCursor/hasMore,前端作为下次请求参数。适合无限滚动和实时插入的数据流。

交互行为

竞态响应防护 Race Condition Guard

快速连续请求时后发的可能先返回,导致旧响应覆盖新结果;通过给每次请求打递增序号或时间戳,响应回来时比对是否仍是最新一次,过期的直接丢弃。React 里常用 useEffect cleanup 中的 ignore 标志或 AbortController 保证只有最后一次生效。

交互行为

轮询 Polling

前端用 setInterval 或递归 setTimeout 定期向服务器拉取最新数据以模拟实时;为避免堆积,常在上一次响应返回后才排下一次(递归 setTimeout),并在页面隐藏(visibilitychange)或失焦时暂停轮询省流量。React Query 的 refetchInterval 是声明式实现。

交互行为

服务器推送事件 Server-Sent Events (SSE)

用 EventSource 建立单向长连接,服务器以 text/event-stream 持续推送 data: 消息,浏览器自动重连并通过 Last-Event-ID 断点续传;前端 onmessage/addEventListener 监听事件流。比 WebSocket 轻、天然走 HTTP,适合日志、通知、AI 流式输出等只需服务端到客户端的场景。

交互行为

悬挂加载 Suspense

组件在数据或代码未就绪时 throw 一个 Promise,最近的 <Suspense fallback> 边界捕获后渲染占位,Promise resolve 后自动重试渲染真实内容。配合 React.lazy 做代码分割,或支持 Suspense 的数据源(use hook / RSC)实现声明式加载态,避免手写 isLoading 分支。

交互行为

流式服务端渲染 Streaming SSR

服务器不等整页渲染完就用 chunked transfer 分块把 HTML 流式发给浏览器,先发外壳再逐步 flush 各 Suspense 边界内容,配合内联脚本做选择性注水。用户更早看到首屏(TTFB/FCP 提升),慢数据区块用占位符后到。renderToPipeableStream 是典型 API。

交互行为

并发渲染 Concurrent Rendering

React 18 的并发特性把渲染切成可中断的工作单元,用 startTransition/useDeferredValue 把非紧急更新标记为低优先级,让输入等紧急更新先响应,避免大列表重渲染卡住打字。底层通过时间切片在浏览器空闲时分批提交。

交互行为

记忆化 Memoization

缓存纯函数的计算结果或组件渲染输出,输入不变时跳过重复计算;React 用 useMemo 缓存昂贵计算、useCallback 缓存函数引用、React.memo 用浅比较跳过子组件重渲染。要点是依赖数组要准确,滥用反而增加比较成本。

交互行为

空闲回调调度 Idle Callback Scheduling

把非关键任务(埋点上报、预渲染、日志)用 requestIdleCallback 排到浏览器主线程空闲的帧尾执行,通过回调里的 deadline.timeRemaining() 在剩余时间内分片处理,超时用 timeout 兜底。避免和渲染、输入抢主线程导致掉帧,新 API 为 scheduler.postTask。

交互行为

内容可见性懒渲染 Content Visibility

给屏幕外的区块加 CSS content-visibility: auto,浏览器会跳过其布局和绘制直到滚动进入视口,大幅降低首屏渲染成本;配合 contain-intrinsic-size 预留占位高度防止滚动条跳动。是无需 JS 的原生懒渲染手段。

交互行为

被动事件监听 Passive Event Listener

给 scroll/touchmove/wheel 监听器加 { passive: true },向浏览器承诺不会调用 preventDefault,浏览器就能立即滚动而不必等 JS 执行完,消除滚动卡顿。现代浏览器对这些事件默认 passive,需阻止默认行为时才显式设 passive: false。

交互行为

布局抖动 Layout Thrashing

在循环里交替读取(offsetHeight/getBoundingClientRect)和写入 DOM 样式,会反复触发强制同步重排(forced reflow),性能急剧下降;解法是把所有读操作批量放前面、写操作放后面,或用 requestAnimationFrame / FastDOM 分离读写阶段。

交互行为

水合 Hydration

SSR 发来的静态 HTML 需要在客户端由 hydrateRoot 附加事件监听、恢复组件状态,把死标记变成可交互应用;要求客户端首次渲染结果与服务端 HTML 完全一致,否则报 hydration mismatch。首屏可见早但可交互(TTI)要等 JS 下载执行完。

交互行为

部分水合/岛屿架构 Partial Hydration / Islands

整页大部分保持静态 HTML 不注水,只把交互组件(岛屿)单独打包并按需 hydrate,大幅减少下载和执行的 JS;Astro 用 client:load / client:visible / client:idle 指令声明每个岛屿的注水时机。也叫 islands architecture。

交互行为

可恢复性 Resumability

Qwik 提出的替代注水方案:服务端把组件状态和事件监听位置序列化进 HTML,客户端启动时无需重新执行组件代码,而是恢复暂停点;真正交互发生时才按需懒加载对应那一小块代码。实现近乎零启动 JS,TTI 与页面大小解耦。

交互行为

代码分割 Code Splitting

用动态 import() 把 bundle 按路由或组件切成多个 chunk,首屏只加载必要代码,其余在需要时异步拉取;React.lazy + Suspense 或框架的路由级分割是常见做法,webpack/vite 据此自动产出分包并做按需预取。

交互行为

无限滚动 Infinite Scroll

监听滚动接近底部(或用哨兵元素 + IntersectionObserver)时自动请求下一页并 append 到列表,配合 cursor 分页和 loading/末页标志避免重复触发。长列表还需搭配虚拟化回收 DOM,否则节点无限堆积会导致内存和性能崩溃。

交互行为

下拉刷新 Pull-to-Refresh

在列表顶部监听 touchstart/touchmove,当已滚到顶部还继续下拉时,按手指位移显示一个可拉伸的刷新指示器,松手超过阈值则触发 refresh 请求并回弹。要处理 overscroll、阈值判定和刷新中锁定,也可用原生 overscroll-behavior。

交互行为

交叉观察器 Intersection Observer

用 IntersectionObserver 异步监听目标元素与视口(或指定 root)的相交比例,进入视口时回调触发图片加载、懒渲染、曝光埋点或无限滚动,替代低效的 scroll + getBoundingClientRect 轮询。可配 rootMargin 提前预加载、threshold 控制触发比例。

交互行为

懒加载 Lazy Loading

资源延迟到真正需要时才加载:图片/iframe 用原生 loading="lazy" 属性交给浏览器按视口调度,或用 IntersectionObserver 把 data-src 换到 src。核心是首屏只加载可见资源,减少初始带宽占用与主线程阻塞。

交互行为

滚动位置恢复 Scroll Restoration

前进/后退或返回列表页时恢复上次的滚动位置,提升浏览连续性;可用 history.scrollRestoration='manual' 关掉浏览器默认行为,自己在路由切换时把 scrollTop 存进 history.state 或 sessionStorage,回来时再 scrollTo。SPA 尤其需要手动处理。

交互行为

资源提示 Resource Hints

用 <link rel> 提前建立连接或获取资源:preconnect/dns-prefetch 预热跨域连接,preload 高优先抓取当前页关键资源(字体、首屏图),prefetch 低优先预取下一页可能用到的资源存进缓存。浏览器据 rel 类型决定优先级和时机。

交互行为

意图预取 Intent-based Prefetching

预测用户下一步动作提前拉取数据或代码:鼠标 hover、mousedown、进入视口或触摸开始时就预取目标页面资源,等真正点击时已就绪。Next.js 的 <Link> 视口内自动 prefetch、quicklink/instant.page 是典型实现,靠概率换首屏速度。

交互行为

推测规则预渲染 Speculation Rules API

通过 <script type="speculationrules"> 声明式告诉 Chromium 在后台 prefetch 或 prerender 哪些 URL,配合 eagerness(conservative/moderate/eager)控制触发时机(如 hover 200ms、进入视口),命中导航时几乎瞬开。不支持的浏览器会忽略,属渐进增强。

交互行为

往返缓存 Back-Forward Cache

浏览器把整页(含 JS 堆栈和 DOM)冻结存入内存,后退/前进时瞬间恢复而非重新加载;要保住它就别用 unload 事件、别设 Cache-Control: no-store,改用 pagehide/pageshow 并检查 event.persisted 来区分是否从 bfcache 恢复。

交互行为

归一化缓存 Normalized Cache

把接口返回的嵌套数据按 __typename+id 拆成扁平的实体表存储,不同查询引用同一实体的同一份副本;某处 mutation 更新该实体后,所有引用它的视图自动同步。Apollo Client/urql 的 normalized cache 靠此避免数据不一致和重复存储。

交互行为

离线优先 Offline-First

应用先读写本地存储(IndexedDB/Cache Storage)保证离线可用,再把变更异步同步到服务器;Service Worker 拦截请求走 cache-first 或 network-falling-back-to-cache 策略,网络恢复时对账。用户断网也能浏览和操作。

交互行为

后台同步 Background Sync

离线时把用户操作放进队列(常存 IndexedDB),用 Service Worker 的 Background Sync API 注册一个 sync 事件,等网络恢复浏览器自动唤醒 SW 重放队列请求到服务器,即使页面已关闭。适合发消息、提交表单等最终一致场景。

交互行为

Service Worker 缓存 Service Worker Caching

Service Worker 在 fetch 事件里拦截网络请求,用 Cache Storage API 按策略响应:cache-first(静态资源)、network-first(接口)、stale-while-revalidate 等;install 时预缓存 app shell,activate 时清理旧版本缓存。是 PWA 离线和秒开的核心。

交互行为

低质量图片占位 LQIP

先加载一张极小(几百字节)的模糊缩略图或 base64 内联占位,撑起布局并给出色彩轮廓,原图加载完成后再淡入替换,避免布局跳动和白屏。构建时预生成低清版本,常与 aspect-ratio 占位配合。

交互行为

BlurHash 模糊占位 BlurHash

把图片编码成 20~30 字符的紧凑字符串(存进接口 JSON),客户端解码成模糊渐变占位图在原图加载前显示,比传缩略图省带宽。基于 DCT 提取少量频率分量,前端用 blurhash 库 decode 到 canvas 再画上去。

交互行为

ThumbHash 紧凑占位 ThumbHash

BlurHash 的改进版,同样字节数下细节更多、还原色彩更准,并支持透明通道和自动推断宽高比;把图片编码成极短二进制(base64 存储),前端 thumbhash 库解码为 data URL 或 canvas 当占位。适合列表缩略图预览。

交互行为

渐进式图片加载 Progressive Image Loading

用渐进式 JPEG/交错 PNG,让图片按由模糊到清晰的多遍扫描逐步呈现,而非从上到下逐行刷出;浏览器边下载边多次重绘。也泛指先小图后大图的 blur-up 渐进策略,弱网下更早给出可辨识画面。

交互行为

拖放 Drag and Drop

HTML5 原生方案给元素设 draggable="true"，dragstart 时往 dataTransfer 写入数据，目标区必须在 dragover 里 preventDefault 才允许放置，drop 时读回数据。现代库(dnd-kit、react-dnd)改用 pointer 事件模拟，自维护拖拽层与碰撞检测，以获得更顺滑的动画和触摸支持。

交互行为

滑动手势 Swipe Gesture

在 touchstart/pointerdown 记录起点坐标，touchmove 里算 deltaX/deltaY 得到位移与方向，touchend 时结合距离阈值和速度(velocity)判定是否触发左右滑。为区分滚动通常锁定主轴，横向位移超过纵向才认定为 swipe。

交互行为

长按 Long Press

pointerdown/touchstart 时启动一个约 500ms 的 setTimeout，期间若发生 pointerup、移动超过容差或 pointercancel 就 clearTimeout 取消。计时器如期触发即认定长按，通常弹出上下文菜单或进入多选态。

交互行为

双指缩放 Pinch to Zoom

监听两根手指的 touchmove，用 Math.hypot 计算两触点距离，当前距离除以初始距离得到 scale 作用于 transform:scale()。需设 touch-action:none 阻止浏览器默认缩放，并以两指中点作为 transform-origin。

交互行为

滑动删除 Swipe to Dismiss

卡片或通知随手指 translateX 跟手移动，松手时判断位移或速度是否过半/过阈：过则继续动画飞出并从列表移除，未过则弹回原位。常用于列表项左滑露出删除按钮，或整条向下划走关闭浮层。

交互行为

底部弹层 Bottom Sheet

从屏幕底部升起的面板，支持多个 snap points(收起/半展/全展)，拖动把手时跟手改 translateY，松手吸附到最近停靠点。背后有遮罩，向下拖过阈值则关闭，打开时通常锁定背景滚动。

交互行为

悬停意图 Hover Intent

不在 mouseenter 立刻响应，而是延迟(如 150ms)后才展开菜单，期间若 mouseleave 就取消，避免鼠标划过时误触发。进阶版比较指针移动速度，慢下来朝目标移动才判定为真实意图。

交互行为

框选 Marquee Selection

在空白区 mousedown 记录起点，mousemove 时以起点与当前点画出绝对定位的半透明选择矩形。实时用 getBoundingClientRect 做矩形相交测试，命中的元素标记为选中，mouseup 结束框选。

交互行为

点击热区 Hit Area

视觉尺寸偏小的按钮通过放大可点击区域来达到 44x44 的可触控标准，常用透明的 ::before 伪元素或负 margin 扩展点击范围，而不改变视觉大小。React Native 里用 hitSlop 属性实现同样效果。

交互行为

右键菜单 Context Menu

监听 contextmenu 事件并 preventDefault 阻止系统菜单，用鼠标坐标定位一个自定义浮层。需处理贴边翻转(空间不足时向上/向左展开)、点击外部与 Esc 关闭，并给菜单项加 role="menuitem" 支持键盘上下选择。

交互行为

可调整大小 Resizable

在元素边缘放置 resize handle，handle 上 mousedown 后监听 document 的 mousemove，用指针位移增量改变宽高并夹在 min/max 之间。CSS 简单场景可直接用 resize:both + overflow:auto，复杂场景则自行计算。

交互行为

拖拽排序 Sortable

拖动列表项时其他项用 transform 平移让出空位，实时根据指针位置计算新的插入索引。释放时对数据数组做 arrayMove 重排并触发过渡动画，常配合 FLIP 技术让重排前后位置平滑衔接。

交互行为

焦点陷阱 Focus Trap

打开模态时把 Tab 焦点限制在容器内：找出容器里所有可聚焦元素，监听 Tab/Shift+Tab，在最后一个按 Tab 时回到第一个、第一个按 Shift+Tab 时跳到最后。关闭时把焦点还给触发它的元素。

交互行为

漫游焦点 Roving Tabindex

一组同类控件(工具栏、菜单)里只让当前项 tabindex="0"、其余 tabindex="-1"，使 Tab 键一次跳入整组而非逐个穿过。组内改用方向键移动焦点，切换时更新各项 tabindex 并调用新项的 focus()。

交互行为

键盘快捷键 Keyboard Shortcut

全局监听 keydown，组合判断 metaKey/ctrlKey/shiftKey 加 e.key，匹配到注册的组合就 preventDefault 执行命令。需跨平台归一(Mac 的 ⌘ 对应 Ctrl)、在输入框内忽略触发，并维护一张映射表避免冲突。

交互行为

命令面板 Command Palette

Ctrl/Cmd+K 唤起一个带搜索框的浮层，输入时对命令列表做模糊匹配(fuzzy)并高亮，方向键上下选择、回车执行。命令注册为带标题/图标/回调的对象，常用 cmdk、kbar 等库实现分组与列表虚拟化。

交互行为

跳过链接 Skip Link

页面首个可聚焦元素放一条"跳到主内容"链接，平时用 sr-only 视觉隐藏，聚焦(Tab)时才显现。点击后焦点跳到主内容锚点，让键盘和读屏用户免于逐个 Tab 穿过导航栏。

交互行为

焦点可见 Focus Visible

用 :focus-visible 伪类只在键盘导航时显示焦点环，鼠标点击则不显示，兼顾可达性与视觉整洁。应避免用 outline:none 一刀切去掉焦点样式，而是在 :focus-visible 下自定义醒目的 ring。

交互行为

滚动吸附 Scroll Snap

容器设 scroll-snap-type:x mandatory，子项设 scroll-snap-align:start/center，滚动松手后自动吸附到最近的对齐点。纯 CSS 即可实现轮播或分页式滚动，配 scroll-padding 处理吸附时的偏移。

交互行为

滚动监听导航 Scroll Spy

页面滚动时高亮当前所在区块对应的导航项。用 IntersectionObserver 观察各 section 进出视口，或滚动时比较每个 section 的 offsetTop 与 scrollTop，把最近进入视口的那个标为 active。

交互行为

粘性头部 Sticky Header

用 position:sticky;top:0 让元素滚动到边界时钉住，超出祖先容器范围才松开。要检测"已吸顶"状态(如加阴影)，常在顶部放一个哨兵元素，用 IntersectionObserver 观察它是否离开视口。

交互行为

滚动锁定 Scroll Lock

弹层打开时锁住背景滚动，最简单是给 body 设 overflow:hidden，但会因滚动条消失导致布局抖动，需补偿 padding-right。iOS 上还需 position:fixed 配 top=-scrollY 或 overscroll-behavior:contain 防止滚动穿透。

交互行为

模态对话框 Modal Dialog

原生 <dialog> 的 showModal() 自带焦点陷阱、Esc 关闭和 ::backdrop 遮罩。自实现则需 role="dialog" aria-modal="true"、打开时锁焦点与背景滚动、Esc 与点遮罩关闭，关闭后把焦点归还给触发元素。

交互行为

抽屉 Drawer

从屏幕一侧滑入的面板，平时用 transform:translateX(-100%) 移出视口，打开时置 0 并显示遮罩。支持点击遮罩或 Esc 关闭，移动端常加边缘手势拖拽跟手，并配焦点陷阱与背景滚动锁。

交互行为

浮层气泡 Popover

相对触发元素定位的浮层，定位靠 Floating UI/Popper 计算，自动处理翻转(flip)与平移(shift)避免溢出视口。新的原生 Popover API 用 popovertarget 属性和 top-layer，天然置顶并带轻量关闭(light dismiss)。

交互行为

工具提示 Tooltip

悬停或聚焦触发元素时显示简短说明，用 aria-describedby 关联 role="tooltip" 的气泡以便读屏播报。需同时响应 hover 和 focus(保证键盘可达)、延迟显示防误触、Esc 可关，定位与 popover 一样靠 Floating UI。

交互行为

手风琴 Accordion

多个可折叠区块，标题按钮切换 aria-expanded 并显隐对应内容区。高度动画常用 max-height 过渡或 grid-template-rows:0fr→1fr；原生 <details>/<summary> 可零 JS 实现，单开模式则展开一个时收起其余。

交互行为

标签页 Tabs

一组 role="tab" 按钮控制对应 role="tabpanel" 的显隐，当前项 aria-selected="true"。键盘用方向键在 tab 间移动(配 roving tabindex)，tab 与 panel 用 aria-controls/aria-labelledby 互相关联。

交互行为

轮播 Carousel

横向排列的幻灯，切换靠 transform:translateX 位移或 scroll-snap 吸附滚动，配指示点与左右箭头。要点是自动播放可在 hover/focus 时暂停、支持触摸拖拽、无限循环用克隆首尾帧，并给读屏加 aria-roledescription。

交互行为

分步向导 Stepper / Wizard

把长流程拆成若干步，维护 currentStep 状态控制显示哪一段并做上一步/下一步导航。每步做局部校验通过才放行，顶部步骤条用 aria-current="step" 标出当前位置，允许已完成步骤回跳。

交互行为

轻提示 Toast / Snackbar

短暂浮现的非阻塞提示，推入一个队列/堆栈渲染，定时器到点自动移除(hover 时暂停计时)。放在 aria-live="polite" 或 role="status" 区域让读屏播报，支持多条堆叠与手动关闭。

交互行为

就地编辑 Inline Edit

点击文本就地切换成输入框并聚焦选中原值，失焦(blur)或回车提交、Esc 取消回滚。提交常配乐观更新，用 contenteditable 或切换 span↔input 两种呈现来实现"显示态/编辑态"互换。

交互行为

多选 Multi-select

维护一个选中 id 的集合(Set)，普通点击单选，Cmd/Ctrl+点击切换加减，Shift+点击基于上一次锚点做范围选择。常提供含半选(indeterminate)态的全选复选框，以及选中后浮现的批量操作栏。

交互行为

自动补全 Combobox / Autocomplete

输入框边打字边请求或过滤候选，下拉用 role="listbox" 呈现，方向键移动高亮项靠 aria-activedescendant 指向而非真正移动焦点。需防抖请求、回车选中、Esc 收起，并处理无结果与加载态。

交互行为

可供性 Affordance

通过视觉线索暗示元素可交互及如何交互，如按钮的凸起阴影、cursor:pointer、可拖动区的抓手(grab)光标、输入框的边框。好的 affordance 让用户无需说明就知道"能点/能拖"，hover 与 active 态是重要的反馈信号。

交互行为

空状态 Empty State

列表或搜索无数据时不留白屏，渲染含插画、说明文案和引导操作(CTA)的占位视图。要区分"首次无数据(引导创建)""搜索无结果(建议改词)""加载出错"几种语义，而非统一一句"暂无数据"。

交互行为

加载态 Loading State

异步请求期间给出反馈以免界面像卡死，轻量用 spinner 或进度条，列表用占位骨架。用 idle/loading/success/error 状态机管理，按钮点击后进入 loading 应禁用以防重复提交，容器加 aria-busy="true" 让读屏知晓。

交互行为

撤销提示 Undo Snackbar

删除等破坏性操作不立即执行，先从界面移除并弹出带"撤销"按钮的 snackbar，同时启动一个约 5s 的定时器。定时器到点才真正提交删除，期间点撤销则取消定时器并恢复条目，是比二次确认弹窗更轻的模式。

动效

三次贝塞尔缓动曲线 Cubic Bézier Curve

用 cubic-bezier(x1,y1,x2,y2) 定义两个控制点 P1、P2（P0、P3 固定为 (0,0) 与 (1,1)），横轴是归一化时间、纵轴是进度值。控制点的 y 允许超过 1 或小于 0，从而做出回弹、预备下蹲等超出终点的效果。浏览器据此把 0→1 的时间映射成非线性的属性变化速率。

动效

缓动关键字 Easing Keywords

CSS 内置关键字本质是 cubic-bezier 的别名：ease=(.25,.1,.25,1)、ease-in=(.42,0,1,1) 开头慢、ease-out=(0,0,.58,1) 结尾慢、linear 匀速。UI 里入场元素常用 ease-out（快进慢停）、退场用 ease-in，让运动贴合物理直觉。直接写在 transition 或 animation-timing-function 上即可。

动效

步进缓动 Steps Easing

steps(n, jump-term) 把 0→1 的进度切成 n 个离散台阶、不做中间插值，常用于精灵图逐帧播放（每帧跳一格背景位置）。jump-start/jump-end/jump-both/jump-none 决定首尾格是否停留。相比连续缓动，它产生一格一格啪嗒跳变的定格效果。

动效

线性缓动函数 linear() Easing Function

linear(0, 0.25, 0.8, 1, …) 接受一串 0~1（可越界）的采样点，在相邻点之间做线性插值，从而拼出任意复杂曲线。把弹簧方程按几十个时间步采样后粘进去，就能在纯 CSS 里实现真实回弹/阻尼，值超过 1 即产生 overshoot。是 cubic-bezier 无法表达多次振荡时的替代方案。

动效

弹簧物理动画 Spring Physics

不设固定时长，而用胡克定律 F=-kx 加阻尼力模拟一个虚拟弹簧，每帧根据当前位移与速度积分出下一帧位置。由 stiffness（劲度）、damping（阻尼）、mass（质量）三参数决定手感，动画在接近静止阈值时自动结束。Framer Motion、react-spring 以此取代 duration+easing 的写法。

动效

劲度 Stiffness

对应弹簧方程里的劲度系数 k，值越大回拉力越强、动画越快越紧绷。在 react-spring 里叫 tension，Framer Motion 里叫 stiffness，通常与 damping 搭配调参。单独调高会同时加快速度并放大 overshoot。

动效

阻尼 Damping

表示消耗弹簧能量的阻力，值越大振荡衰减越快、越不回弹。阻尼比≈1 为临界阻尼（不过冲且最快稳定），<1 欠阻尼会来回振荡，>1 过阻尼则迟缓无回弹。调 UI 手感就是在 damping 与 stiffness 之间找平衡。

动效

质量 Mass

弹簧末端挂载物体的虚拟质量，质量越大惯性越强，起步更迟缓、过冲后摆动更久。它与 stiffness、damping 共同决定振荡频率与衰减速度（频率∝√(k/m)）。默认多为 1，加大可营造沉重厚实的运动质感。

动效

过冲回弹 Overshoot

元素运动到目标值后因惯性冲过头再回摆的现象，视觉上就是到位时弹一下。缓动里靠 cubic-bezier 控制点 y>1，或 linear()/弹簧参数（低 damping）实现。适度 overshoot 让动画有生命力，过度则显廉价。

动效

橡皮筋回弹 Rubber Banding

滚动或拖拽越过边界时，位移按阻尼函数（如 offset*0.5 或对数衰减）递减地跟随，松手后用弹簧动画弹回边界。iOS 的 overscroll 是典型，Web 里可用 overscroll-behavior 关掉原生行为再自行实现。核心是越拉越拉不动加释放回弹两段逻辑。

动效

惯性滚动 Momentum Scroll

手指抬起时记录松手瞬时速度，之后每帧按摩擦系数衰减该速度（v*=friction）继续移动，直到低于阈值停止，模拟真实滑行。甩动越快滑得越远。原生可用 -webkit-overflow-scrolling:touch，自定义则在 requestAnimationFrame 里做速度衰减积分。

动效

衰减动画 Decay Animation

给定初速度和摩擦/功率参数，用指数衰减公式预测落点并一路减速滑到静止，不需要目标终点。Framer Motion 的 inertia、iOS 的 UIScrollView 都属此类，常用于甩动列表、可拖拽卡片的自然停靠。落点还可再对齐到最近的吸附网格。

动效

插值 Interpolation

在起止值之间按进度 t（0~1）算出中间值，最基础的是线性插值 lerp = a + (b-a)*t。缓动其实就是先把时间 t 经 easing 函数弯曲，再喂给 lerp。颜色、变换矩阵、路径各有专门插值方式（如颜色需在特定色彩空间里插）。

动效

补间动画 Tween

in-between 的缩写，指在两个关键状态之间由引擎自动算出所有中间帧，与逐关键帧手绘相对。给定起点、终点、时长和 easing，tween 每帧用插值算出当前值写回属性。GSAP、Framer Motion 的 type:"tween" 都是这种时长驱动模型。

动效

运动模糊 Motion Blur

高速移动的物体单帧内本应留下拖影，Web 上常用近似：按速度方向叠加半透明残影层，或用 SVG feGaussianBlur / CSS blur() 沿运动轴做方向性模糊。速度越大模糊量越强，能掩盖低帧率跳格感、增强速度知觉。属性驱动时可用 filter 随 velocity 实时变化。

动效

FLIP 动画技术 FLIP Technique

First-Last-Invert-Play：先记录变化前(First)与变化后(Last)的位置尺寸，用 transform 把元素反变换回原位造成没动的假象(Invert)，再把 transform 清零播放(Play)动画。因全程只动 transform/opacity，能把开销大的 layout 变化转成廉价的合成动画。React 布局动画、View Transitions 底层都用此思路。

动效

动画延迟 Animation Delay

设定从触发到真正开始播放之间等待的时间，可为负值——负延迟让动画从中途开始，仿佛已经播了一段。给每个元素递增的 delay 就能手写错落进场。默认延迟期内元素停在初始态，除非用 fill-mode:backwards 改变。

动效

动画时长 Animation Duration

一次动画从 0% 走到 100% 所需的时间，是时长驱动动画的核心参数。UI 微交互通常 150~300ms，过长显拖沓、过短显生硬。它与 easing 共同决定速度曲线，但弹簧动画不用它，而由物理参数隐式决定时长。

动效

播放次数 Iteration Count

指定动画重复播放的遍数，可为整数、小数（播到某个百分比即停）或 infinite 无限循环。加载转圈、脉冲呼吸常用 infinite。配合 animation-direction:alternate 可让每遍来回往复而非硬跳回起点。

动效

填充模式 Fill Mode

决定动画在播放前(delay 期间)和播放后如何取值。forwards 让元素停在最后一帧、backwards 在延迟期就套用第一帧、both 两者兼具；默认 none 会在动画结束后瞬间弹回原样。想让状态定格在终点必须显式设 forwards。

动效

播放方向 Animation Direction

控制每遍动画沿关键帧正放还是倒放：normal 正向、reverse 反向、alternate 奇数遍正偶数遍倒（来回摆动）、alternate-reverse 相反。做呼吸灯、钟摆这类往返效果时用 alternate 就无需再写一套反向关键帧。

动效

播放状态 Play State

只有 running/paused 两个值，切到 paused 会在当前帧冻结动画、切回 running 从冻结处继续而不重置进度。常用 :hover 暂停轮播，或用 JS 切换实现播放控制。相比重设整个 animation 属性，它不会打断进度。

动效

滚动驱动动画 Scroll-Driven Animation

把动画的时间轴从时钟换成滚动进度：animation-timeline:scroll() 让 0%~100% 对应滚动条从顶到底，view() 则对应元素进出视口的可见进度。于是滚动多少动画就走多少，无需 JS 监听 scroll 事件。注意 animation-timeline 必须写在 animation 简写之后才生效。

动效

运动路径 Motion Path

offset-path 用 path()/shape()/url() 定义一条曲线轨道，再动画化 offset-distance 从 0% 到 100% 让元素沿轨道移动，比逐点写 translate 关键帧简洁得多。offset-rotate 可让元素自动朝向前进方向（如沿轨道行驶的车头）。整段运动仍是合成友好的 transform。

动效

变化预告 will-change

提前告诉浏览器某属性（如 transform、opacity）即将频繁变化，好让它预先把元素提升为独立合成层、备好优化。应在动画开始前加、结束后移除；长期挂在大量元素上反而吃内存拖慢页面。它是提示而非强制，滥用会适得其反。

动效

合成层 Compositor Layer

浏览器把某些元素单独绘制成一张位图纹理交给 GPU，动画时只需在合成线程平移/缩放/混合这些纹理，绕过主线程的布局和绘制。transform、opacity 的变化即走此路径，因此即便主线程卡住动画仍能流畅。层由 will-change、3D transform、video 等触发生成。

动效

仅合成属性 Compositor-Only Properties

只有 transform 和 opacity（及部分 filter）能只在合成线程处理、不触发 layout 和 paint，是最廉价的动画属性。用 translate 代替 top/left、用 scale 代替 width/height，就能把 60fps 稳稳跑在 GPU 上。动画 left、height、box-shadow 等则每帧回流重绘，极易掉帧。

动效

回流与重绘 Reflow & Repaint

改变几何属性（宽高、位置、字体）触发 reflow/重排——浏览器重新计算所有受影响元素的布局；仅改颜色、背景等外观则触发 repaint/重绘。两者都在主线程执行、成本高且会级联。动画应尽量避开它们，只动 transform/opacity 走合成路径。

动效

逐帧回调 requestAnimationFrame

注册一个在浏览器下次重绘前执行的回调，与显示器刷新同步（约每 16.7ms 一次），在里面更新动画状态并递归调用自身形成帧循环。回调收到高精度时间戳，据此按真实经过时间(delta)算位移，避免掉帧时速度失真。切到后台标签页会自动暂停，比 setInterval 更省电准确。

动效

帧预算 Frame Budget

要跑满 60fps，每帧从输入到绘制必须在约 16.7ms 内完成（120Hz 屏则约 8.3ms），其中还要留给浏览器合成，脚本实际可用约 10ms。单帧里 JS+样式+布局+绘制一旦超支就丢帧。优化就是把长任务切片、把工作移出主线程以守住这个预算。

动效

卡顿掉帧 Jank

帧率不稳、某些帧因主线程繁忙未能按时提交，画面出现停顿或跳跃的现象。成因多为长任务、布局抖动、动画非合成属性。可用 DevTools Performance 面板看红色长任务与掉帧标记定位，目标是让每帧都稳定落在帧预算内。

动效

硬件加速触发 Hardware Acceleration Hack

历史上用 transform:translateZ(0) 或 translate3d(0,0,0) 骗浏览器把元素当 3D 内容、强制提升为 GPU 合成层以求流畅（俗称 3D hack）。如今更推荐语义清晰的 will-change:transform。滥用会创建过多图层、暴涨显存，反而拖慢。

动效

背面可见性 Backface Visibility

控制元素旋转到背朝屏幕时是否显示其背面，设 hidden 则转过 90° 后不可见。做翻牌效果时把正反两面叠放、各设 backface-visibility:hidden，旋转 rotateY 时就只露出朝前的一面。旧写法还兼带触发合成层的副作用。

动效

Web 动画 API Web Animations API (WAAPI)

用 element.animate(keyframes, options) 在 JS 里直接创建动画，传入关键帧数组与 duration/easing/fill 等配置，返回可 play/pause/reverse/finished 控制的 Animation 对象。它复用浏览器原生合成引擎，性能等同 CSS 动画但可编程、可 await finished。适合动态生成或精细控制的场景。

动效

变换原点 Transform Origin

定义 transform 的基准点——旋转绕它转、缩放朝它缩，默认在元素中心 (50% 50%)。改成 top left 就让元素绕左上角旋转、像门一样开合。它不改变元素本身布局，只影响变换如何施加，配合 3D 变换还能设第三维 z 值。

动效

透视 Perspective

给 3D 变换设定观察者到 z=0 平面的距离，值越小透视越夸张（近大远小越明显）、越大越接近正交无透视。写在父元素上（perspective 属性）让所有子元素共享同一消失点，或写进子元素自身的 transform:perspective() 单独作用。没有它，rotateY 等只会像被压扁般缺乏立体感。

动效

3D 变换 3D Transform

在 X/Y/Z 三轴上做位移与旋转：translateZ 让元素靠近或远离观察者、rotateX/rotateY 绕水平或垂直轴翻转产生立体翻页。需配合父级 perspective 才有景深，且这类变换会自动触发 GPU 合成层。是卡片翻转、立方体、纵深视差的基础。

动效

矩阵变换 Matrix Transform

matrix(a,b,c,d,e,f) 和 matrix3d(16 个值) 是所有 translate/scale/rotate/skew 的底层统一表示——每个具名变换都会被浏览器编译成一个矩阵，多个变换相乘合并。读取 getComputedStyle 的 transform 拿到的就是 matrix 形式。手动写矩阵可做斜切等具名函数覆盖不到的复合仿射变换。

动效

3D 上下文保留 Preserve 3D

transform-style:preserve-3d 让子元素保留在父级建立的同一个 3D 空间里、各自的 z 深度真实参与排布；默认 flat 则把子元素拍平投影到父平面。做立方体、多面体时必须给容器设 preserve-3d，否则各面无法在三维中正确前后穿插。

动效

形状变形 Shape Morphing

通过在两个 SVG path 之间插值 d 属性的顶点坐标实现形状渐变,要求两段路径的点数一致或先做点位补齐对齐。常用 flubber、GSAP MorphSVGPlugin 做顶点匹配补间,简单图形也可只动画 clip-path 或 border-radius 近似。

动效

视口进度时间线(view()) View Progress Timeline

用 animation-timeline: view() 让动画进度绑定元素在滚动视口中的可见程度,再用 animation-range: entry / exit / cover 指定在元素进入、离开或完整穿越视口的哪一段区间内推进,天然实现'进入视口才动、随滚动推进'。

动效

滚动触发动画 Scroll-Triggered Animation

用 IntersectionObserver 监听元素与视口相交,在回调里给元素加上触发动画的 class 或调用 GSAP/AOS,threshold 与 rootMargin 控制触发点。区别于 scroll-driven 的是它是一次性触发播完整段动画,而非逐帧跟随滚动进度。

动效

动效

共享元素过渡 Shared Element Transition

给起点和终点视图里的同一元素设置相同的 view-transition-name,View Transitions API 会把它们识别为一组,自动在两者的位置、尺寸间做补间,呈现'同一元素飞过去'的连续变换。每个 name 在同一时刻必须唯一,否则过渡报错。

动效

英雄动画 Hero Animation

共享元素过渡的经典形态:列表缩略图被点击后连续放大成详情页的大图,同一'英雄'元素在两个视图间平滑变换位置与尺寸。Web 用 FLIP 或 view-transition-name 实现,Flutter 用两个页面里同名 tag 的 Hero widget 自动匹配。

动效

在点击坐标处以其为圆心生成一个绝对定位的圆形 span,从 transform:scale(0) 动画放大到覆盖整个容器并同时渐隐 opacity,父容器 overflow:hidden 裁掉溢出。用 pointer 事件的 offsetX/offsetY 定位圆心,是 Material 触摸反馈的标志。

动效

微光/流光 Shimmer Effect

用一条倾斜的线性渐变高光作为背景,通过循环动画 background-position 或 transform:translateX 让高光条反复扫过元素,形成流光掠过感。常叠在占位块或按钮上,用 mask 或 background-clip 限定扫光范围。

动效

脉冲/呼吸 Pulse Animation

用 @keyframes 在 transform:scale 与 opacity 之间往复(animation-direction:alternate)无限循环,或让一圈 box-shadow 由实到透明向外扩散,营造呼吸/心跳般的注意力提示。常用于未读红点、录音指示灯、CTA 按钮。

动效

数字增长 Count-Up

用 requestAnimationFrame 在设定时长内按 easing 从起始值向目标数值插值,每帧 Math.round 后写入元素文本,大数字再做千分位格式化。常用 countup.js 或自写 tween,用于仪表盘 KPI 的数字增长动效。

动效

数字翻牌/里程表 Number Ticker / Odometer

把每一位数字做成 0-9 的纵向长条列,数值变化时用 transform:translateY 把目标数字滚动到 overflow:hidden 的可视窗口内,形成机械里程表般的逐位翻滚。framer-motion 常用 useSpring 驱动每位的 y 位移做 NumberTicker/Odometer。

动效

动效

动效

动效

动效

微交互 Micro-Interaction

针对单个控件的即时反馈微动画——hover 变色、点击缩放、开关滑动、图标形变,通常用 transition 或 150-300ms 的短 keyframes 覆盖'触发→反馈→复位'的小闭环,给操作以确认感和精致度。

动效

动效

手势驱动动画 Gesture-Driven Animation

用 Pointer/Touch 事件跟踪拖拽的位移与速度,把手指位置实时映射到元素 transform,松手后按记录的速度用 spring/惯性收尾。framer-motion 的 drag 与 use-gesture 库封装了 velocity 计算与 momentum 抛掷。

动效

页面过渡/转场 Page Transition

路由切换时对离场旧页做 exit 动画、对入场新页做 enter 动画。SPA 用 framer-motion 的 AnimatePresence 配合唯一 key 或 Vue 的 <transition> 保证离场元素动画完成后再卸载;MPA 现可用跨文档 View Transitions。

滚动进场显现 Reveal on Scroll

元素初始 opacity:0 且带 translateY 下偏移,滚动进入视口时(IntersectionObserver 或 scroll-driven view())移除偏移、淡入上浮到位。多元素常配递增 delay 依次浮现,是落地页最常见的分块进场模式。

动效

动效

加载指示变体 Loading Spinner

暗角 Vignette

把画面四周压暗、中心留亮,引导视线聚焦并增强氛围。做法是在图像上叠一层 radial-gradient(ellipse, transparent 60%, rgba(0,0,0,.6)) 的伪元素,或用大扩散的 inset box-shadow 从边缘向内变暗。

内阴影 Inner Shadow

用 box-shadow 的 inset 关键字把阴影投在元素内部上沿,营造下凹或被按压的质感,常用于输入框、进度槽和按钮按下态。典型写法 box-shadow: inset 0 2px 4px rgba(0,0,0,.15),配底部 inset 高光更立体。

长阴影 Long Shadow

扁平设计里图标沿 45° 拖出一条延伸到边缘的实色长影。CSS 靠堆叠几十条逐像素偏移的同色 text-shadow/box-shadow(0 0、1px 1px、2px 2px…)累积成连续投影,通常用 Sass 循环或预生成,末端可渐隐透明。

轮廓投影 Drop Shadow

给元素加与背景分离的落影。box-shadow 沿盒子矩形边界投影,而 filter: drop-shadow() 会沿元素实际不透明轮廓(含透明 PNG、圆角、SVG 形状)投影,因此给异形图标或图片加影必须用 drop-shadow 而非 box-shadow。

斜面倒角 Bevel

在边缘做出倾斜的立体切面。视觉上用相邻两边一亮一暗的 border 颜色(左上亮、右下暗)伪造受光斜面,做出凸起或凹陷的 3D 边;几何切角则用 clip-path: polygon() 把矩形角切掉形成实体倒角。

高光泽反射 Gloss / Specular Highlight

在元素上半部叠一道半透明白色渐变模拟光滑表面的反射高光(Web 2.0 玻璃按钮的招牌)。做法是伪元素铺 linear-gradient(rgba(255,255,255,.5), transparent) 只盖上半区,配大圆角与轻微弧形 border-radius 让高光像弧面反光。

透明度合成 Alpha Compositing

用透明度让多层像素按 alpha 通道叠加混合。基础靠 opacity 或 rgba()/hsla() 的 alpha 分量做半透明叠层,进阶用 mix-blend-mode/background-blend-mode 指定 multiply、screen、overlay 等混合算法,决定上下层颜色如何运算合成。

弹性盒布局 Flexbox

给容器设 display:flex 后,子项沿主轴(flex-direction)一维排列,用 justify-content 管主轴分布、align-items 管交叉轴对齐。子项靠 flex:grow shrink basis 三值分配剩余空间,flex-wrap 控制是否换行。

网格布局 CSS Grid

display:grid 建立二维网格,用 grid-template-columns/rows 定义轨道(常配 fr 弹性单位与 minmax()、repeat()、auto-fill/auto-fit)。子项通过 grid-column/row 或 grid-area 跨行跨列定位,gap 设轨道间距。

子网格 Subgrid

在嵌套网格的 grid-template-columns 或 rows 上写 subgrid,让子网格直接继承父网格的轨道线,而非自建轨道。这样卡片内部的标题、正文、按钮能跨多张卡片对齐到同一基线。已 Baseline 广泛可用(Chrome 117+/Firefox 71+/Safari 16+)。

UI视觉

瀑布流布局 Masonry Layout

让不等高的项在列方向紧密堆叠(Pinterest 式),消除网格留白。规范仍在博弈:Firefox/Safari 用 grid-template-rows:masonry 扩展 Grid,Chrome 曾主张独立 display:masonry,2025 年 CSSWG 倾向 grid-lanes 方案。目前各浏览器均需开启实验旗标。

UI视觉

间距(gap) Gap

在 flex、grid、multicol 容器上用 gap(或 row-gap/column-gap)一次性声明子项之间的沟槽间距,替代给每个子项加 margin 再消除首尾的旧写法。gap 只作用于项与项之间,不产生外缘间距。

UI视觉

对齐简写 Place Items / Content

place-items 是 align-items 与 justify-items 的简写、place-content 是 align-content 与 justify-content 的简写,一行同时设两轴对齐。在 grid 上写 place-items:center 即可让所有子项双向居中,是最短的完美居中写法。

UI视觉

定位偏移简写 Inset

inset 是 top/right/bottom/left 的简写,遵循与 margin 相同的四值书写顺序。配合 position:absolute 写 inset:0 即可让元素铺满定位父级,常用于遮罩层、绝对定位居中。

UI视觉

粘性定位 Position Sticky

position:sticky 让元素在滚动到指定阈值(如 top:0)前表现为 relative,越过阈值后在其滚动容器内表现为 fixed 吸附。必须给一个方向的偏移值才生效,且受最近的可滚动祖先与 overflow 裁剪影响。

UI视觉

宽高比 Aspect Ratio

aspect-ratio:16/9 直接声明元素的宽高比,浏览器据已知的一维(通常是宽度)自动算出另一维,取代 padding-top 百分比撑高的老 hack。常用于图片/视频/卡片占位,避免加载时的布局抖动(CLS)。

UI视觉

替换元素填充 Object Fit

object-fit 决定 img/video 等替换元素内容如何填入自身盒子:cover 等比裁剪铺满、contain 等比缩放完整可见、fill 拉伸变形。配合 object-position 调整裁剪焦点,等价于背景图的 background-size/position。

UI视觉

多列布局 Multi-column Layout

用 columns(column-width 与 column-count 简写)让内容像报纸一样自动流入多栏,浏览器按可用宽度决定列数。column-gap 设栏间距、column-rule 画分隔线、break-inside:avoid 防止元素被拆栏。

UI视觉

书写模式 Writing Mode

writing-mode 切换文本的行进方向:horizontal-tb 为默认横排,vertical-rl/vertical-lr 令文字竖排(中日韩传统排版、侧边标签)。它会重定义块轴与内联轴的方向,配合 text-orientation 控制单字符的旋转朝向。

UI视觉

逻辑属性 Logical Properties

用 inline(行进方向)/block(块方向)取代物理的 left/right/top/bottom,如 margin-inline、padding-block、inset-inline-start。这样样式随 writing-mode 与 direction(RTL)自动翻转,一套代码适配多语种排版方向。

UI视觉

容器查询 Container Query

先在父级设 container-type:inline-size(可选 container-name)使其成为查询容器,再用 @container (min-width:400px) 根据容器自身尺寸而非视口来切换子组件样式。配套 cqw/cqi/cqh 等容器相对单位。Chrome 105+/Firefox 110+/Safari 16+ 已普及。

UI视觉

:has() 父选择器 :has() Relational Selector

:has() 是关系型伪类,parent:has(child) 会在父元素包含匹配的后代/兄弟时命中父元素,实现了长期缺失的"父选择器"与反向选择。支持 >、+、~ 组合符,如 label:has(+ input:checked)。不可嵌套自身,Baseline 广泛可用(Chrome 105/Safari 15.4/Firefox 121)。

锚点定位 Anchor Positioning

给锚元素设 anchor-name:--foo,给定位元素设 position-anchor:--foo,再用 anchor() 函数或 position-area 网格把它相对锚元素放置(tooltip、下拉、popover)。@position-try 提供空间不足时的翻转回退。Chrome 125+/Firefox 147+ 支持,Safari 18 缺 @position-try。

UI视觉

层叠层 Cascade Layers

@layer 用命名图层显式排定层叠优先级:先声明的层整体弱于后声明的层,与选择器权重解耦。可写 @layer reset, base, components; 预定义顺序,让第三方库、重置样式、业务样式的覆盖关系可控,减少 !important 滥用。

UI视觉

CSS 自定义属性 Custom Properties (CSS Variables)

用 --name:value 声明自定义属性,以 var(--name, 回退值) 读取;它遵循层叠与继承,可在运行时用 JS 或 :root 主题类改写,实现动态换肤。配合 @property 可注册类型使其可参与动画过渡。

UI视觉

颜色混合函数 color-mix()

color-mix(in oklch, blue 30%, white) 在指定色彩空间里按百分比混合两种颜色,原生实现 tint/shade/透明度派生。常配合自定义属性从一个品牌主色批量生成 hover、边框、浅底等衍生色。Chrome/Firefox/Safari 均已支持。

UI视觉

OKLCH 色彩空间 OKLCH Color

oklch(L C H) 用感知均匀的明度、彩度、色相三分量描述颜色,同一 L 值不同色相亮度观感一致,调色板更协调,还能表达超出 sRGB 的 P3 广色域。相比 HSL 避免了蓝色发暗、黄色过亮等失真。已在各主流浏览器可用。

UI视觉

文本均衡换行 text-wrap: balance / pretty

text-wrap:balance 让浏览器均分各行字符数,避免标题最后一行只剩孤词(适合少行数标题);pretty 则优化长段落的孤行与断字。balance 支持度已较广,pretty 目前主要在 Chromium/WebKit。

UI视觉

clamp() 流式排版 clamp() Fluid Typography

clamp(最小值, 理想值, 最大值) 给出一个受上下限约束的可变值,理想值常用 vw 或含 vw 的计算式,使字号/间距随视口平滑缩放而不失控。用它替代大量断点里逐档改 font-size 的媒体查询,实现真正连续的响应式排版。

UI视觉

滚动条占位槽 scrollbar-gutter

scrollbar-gutter:stable 预留出滚动条所占的沟槽宽度,使内容在滚动条出现/消失时不发生水平位移抖动。both-edges 可两侧对称留槽以保持视觉平衡,常用于弹窗、可滚动面板。

UI视觉

平滑滚动 scroll-behavior

scroll-behavior:smooth 让锚点跳转与脚本 scrollTo 以动画平滑滚动而非瞬移。配合 scroll-padding(为吸顶头留出停靠偏移)与 scroll-margin(调整目标元素的对齐边距)修正定位。应尊重 prefers-reduced-motion 关闭动画。

UI视觉

滚动溢出行为 overscroll-behavior

overscroll-behavior:contain 阻断滚动链——内层滚到底后不再把滚动传递给页面,常用于弹窗、侧栏、聊天列表。值 none 还能禁用浏览器默认的下拉刷新与橡皮筋回弹效果。

UI视觉

特性查询 Feature Queries (@supports)

@supports (property:value) 在样式表里检测浏览器是否支持某 CSS 特性,支持时才应用其中规则,实现渐进增强与优雅降级。可用 not、and、or 组合,也能检测选择器 @supports selector(:has())。

UI视觉

CSS 隔离 CSS Containment (contain)

contain 向浏览器承诺某子树的布局/绘制/尺寸互不外溢(layout、paint、size、style 或简写 content、strict),从而把重排重绘限制在局部,提升性能。paint 与 layout 还会创建独立的层叠上下文与包含块。

UI视觉

裁剪路径 clip-path

clip-path 用几何函数裁出元素的可见区域:circle()、ellipse()、inset() 或 polygon() 多边形顶点列表,还可引用 SVG <clipPath>。区域外部分被裁掉且不响应事件,常做斜切、六边形头像、异形卡片,顶点用百分比时可参与过渡动画。

UI视觉

蒙版遮罩 CSS Mask

mask-image 用一张图片或渐变的 alpha/亮度作为遮罩,决定元素各处的可见度,可做渐隐边缘、镂空图标、纹理透显。多层遮罩用 mask-composite 做交/并/差运算。为兼容 Safari 常需加 -webkit-mask 前缀。

UI视觉

文字环绕形状 shape-outside

对浮动元素设 shape-outside:circle()/polygon() 或引用图片的 alpha 轮廓,使旁边的行内文字沿该几何形状而非矩形盒子环绕流动。shape-margin 在形状外再加一圈环绕留白,实现杂志式图文环排。

UI视觉

混合模式 mix-blend-mode

mix-blend-mode 定义元素与其下层内容的像素如何按 Photoshop 式算法混合:multiply 压暗、screen 提亮、overlay/difference 等,常做文字随背景反色、彩色叠印。background-blend-mode 则混合同一元素的多层背景。混合会促使浏览器新建层叠上下文。

背景滤镜 backdrop-filter

backdrop-filter 对元素"身后"的内容应用 blur()、saturate()、brightness() 等滤镜(而非元素自身),是实现半透明面板背后实时模糊的核心技术。需元素自身有一定透明度才能透出被处理的背景,Safari 需 -webkit- 前缀。

UI视觉

滤镜 filter

filter 对元素自身像素施加图形滤镜函数,可链式书写:blur() 模糊、brightness()/contrast() 明暗、saturate()/hue-rotate() 调色、grayscale()/sepia() 去彩、drop-shadow() 贴合不透明轮廓的投影。多数函数可平滑过渡动画。

UI视觉

层叠隔离 isolation

isolation:isolate 无副作用地强制创建一个新的层叠上下文,把子元素的 z-index 与 mix-blend-mode 影响范围锁在内部,防止其穿透到外层意外混合或压过兄弟层。是控制混合模式与堆叠边界的干净手段。

UI视觉

安全区域 Safe Area Inset

用 env(safe-area-inset-top/bottom/left/right) 读取刘海、圆角、底部指示条等占用的边距,加进 padding 以避开遮挡。前提是 viewport meta 设 viewport-fit=cover 让页面延伸到屏幕边缘,常配 max() 兼顾常规留白。

UI视觉

多行文本截断 Line Clamp

经典写法为 display:-webkit-box; -webkit-box-orient:vertical; -webkit-line-clamp:3; overflow:hidden,把文本限制在指定行数并以省略号收尾。新标准 line-clamp 简写正在落地,免去 -webkit-box 组合。

UI视觉

层叠上下文 Stacking Context (z-index)

z-index 仅在同一层叠上下文内比较前后;position 非 static 且有 z-index、opacity<1、transform、filter、will-change 等都会新建层叠上下文,其内部子元素整体被封在父级的层级里。理解它才能解释"z-index 很大却压不过别人"的越级失效。
