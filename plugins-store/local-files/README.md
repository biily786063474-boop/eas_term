# 本地文件连接器（Eas-Term 自写，无第三方运行依赖）

三个真实 stdio MCP 工具：`files_list`、`files_read`、`files_write`。

安装后在软件配置入口选择目录并确认读写授权；宿主将校验后的配置只注入该插件子进程，锁定密钥柜关闭该进程。不会把目录配置或密钥复制进三种 CLI 配置。普通文本读写上限 1MB，列表上限500项；覆盖文件要求当前内容SHA256，不提供递归删除。路径必须相对授权目录，不跟随符号链接，不支持多硬链接文件。写入临时文件后晋升，失败不以空文件替代原文件。

stdio 是用户确认执行的本机代码，不是操作系统沙箱；应用级路径检查不能对抗拥有同一用户权限的恶意并发文件系统修改。不用于多租户安全隔离。连接器不联网、不执行shell、不读取全局凭证。

验收：`node scripts/verify-local-files-plugin.mjs`。实际构建应用、原安装IPC/哈希/解包、真实safeStorage、真实共享宿主和3个shim子进程、临时目录写入、越界拒绝、锁定后禁止调用。测试仅替换网络下载目的地与原生对话框返回值，不替换主进程权限/加密/宿主代码；不是原生picker手动交互、真实模型CLI或生产HTTPS上线验收。

本包为项目自写代码，沿用仓库授权，不冒充官方 filesystem MCP，也不虚构第三方许可证。
