# Jev 判断台 · 0.2.0

Eas-Term 的可选 TypeSafe 集成，并非官方客户端。Jev 对给定文本回答明确的 Choice / Score / Noul 小问题；不生成长文、不自行查文件、不构成验收或操作授权。固定模型 jev-1.13.0，中文真实效果尚未评估。

## 三页结构

- 判断台：反馈分类 / 自定义是非问题。实际材料和问题先由宿主原生对话框确认，一次确认只允许一次调用（预览上限 16KB）。
- 自动化：时间线里程碑和项目建议独立授权。只处理当前仍有时间线权限且在该配方授权集合内的新事件；新增项目须重新授权。关闭面板仍可运行，不补跑历史事件，不自动移动项目或验收成果。
- 连接与用量：请求状态、实际输入/输出 token、公开单价估算。费用未知不按零费用处理。

## 一次连接与恢复

凭证只存宿主加密凭证库，插件 HTML 不输入或回显密钥。首次验证发送固定样例，可能收费；宿主存加密配置摘要，后续进程/应用重启走可信恢复，不重复收费测试。首次升级旧选择配置默认暂停，明确启用后才持久恢复。

连接可用性与 enabledIntent 分离：之前暂停则仍暂停，已授权自动化可继续。用户主动开启“信任此设备”后免重复解锁；手动锁柜仍撤销所有运行租约，解锁后才能恢复。服务商撤销密钥或模型权限不足时停止调用，需要更新配置。断网/限流/超时不删除凭证，结果未知的请求不自动重放。

「暂停所有判断」保留凭证并取消正在进行的调用；「退出并移除凭证」经原生确认后移除本插件配置。已发送的数据和可能发生的费用不可撤回。

## 协议与安全

公开工具为 jev_show / jev_decide。旧 jev_triage/docs/eval/route/custom 名称作为过渡别名，仍必须经过宿主按次材料确认和授权 generation 校验；不得直接调用它们绕过确认。新包要求宿主 capability `jev.decisions.v2`，旧宿主拒绝安装。

固定 TypeSafe HTTPS 端点、拒绝重定向、请求/响应大小保护、15 秒传输超时和并发限制保持。持久化预算默认每日 UTC 100 次预留，失败和撤销仍计入本地预算以保护未知成本；有持久化用量时不再叠加进程累计次数上限。

费用按 2026-09-28 官方输入单价 $0.042 / M token 估算，输出免费。此值是带时点的估算，不是实际账单，也不承诺未来定价不变。来源 https://docs.typesafe.ai/models 。
