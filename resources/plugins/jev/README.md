# Jev 智能辅助插件

这是 Eas-Term 的可选插件，不是 TypeSafe 官方客户端。未安装或未开启不会调用 Jev。

## 开始使用
1. 在支持 `config.deferred` 的 Eas-Term 插件市场安装本包，打开 Jev 面板。
2. 点击“获取与使用指南”，在 TypeSafe 账户获取 API 密钥。不要把密钥发到 AI 对话。
3. 在“安全连接设置”保存密钥。密钥柜锁定时，先关闭设置，点软件顶部“密钥”解锁。
4. 重新打开 Jev，点击“验证已保存的连接”。它发送固定样例，不发送项目内容，但可能收费。
5. 另行确认开启。五项 AI 判断默认选中，时间线两个增强默认关闭。

## 能力与调用
在 AI 对话中提供材料，要求分类、筛选证据、辅助评审、推荐工具或按自定义标准判断。主 AI 只能使用已开启工具；对应使用说明按需读取，不整包注入。
时间线增强要求已安装时间线并开启其全局记录；只增强已有待确认候选，不自动认定任务完成或移动记录。并发繁忙时保留原候选而跳过可选增强。

## 暂停、断开与卸载
- 暂停全部：保留选择，拒绝新请求，尽力取消在途请求。
- 全选/全取消：只改变七项选择，不代替连接或总授权。
- 断开：连接设置中清除本地配置。修改前会确认停止插件；其他窗口/会话占用时须先关闭占用。
- 锁定密钥柜：关闭已激活的插件进程。重启保留选择和用量，不自动恢复连接或开启。
- 卸载：移除用户插件包，不退回内置版本。若不再使用服务，还应在 TypeSafe 撤销密钥。

## 数据与限额
仅必要材料发送至 `https://api.typesafe.ai/v1/systemone`，不由模型指定地址。每日 UTC 最多预留 100 次（含验证），并发最多 2 次；失败和未知结果仍占次数，防止重复收费。调用记录只保存来源、时间、状态和 token 数，不默认保存输入正文或密钥。价格/费用以服务商账单为准。
已经发送的数据或已产生的费用无法撤回。独立配置的外部直连工具不受本插件开关控制。

## 验证范围
提供离线测试及隔离宿主验收脚本。HTTP 夹具验证不等于真实模型质量、账户可用性或生产 CDN 验证。连接自己的账户后应先用少量无敏感内容测试。

时间线增强最低要求时间线 1.0.1，请在插件市场独立更新；宿主升级不覆盖已安装插件。旧版本不发起付费增强请求，面板会提示升级。发布时需同时提供该时间线更新包。

当前限制补充（0.4.106）：除持久化 UTC 每日预算外，运行时另有单进程累计 100 次限制。达到后仅等待次日或重新连接不会复位，需关闭该插件的全部引用并重启插件进程。本版保留此保护，后续再统一预算口径。
