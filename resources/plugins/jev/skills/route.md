# Jev route · 兼容说明

优先使用 `jev_decide`。这是结构化小问题判断，不是独立的资料查证、代码评审或自动工具执行工作流。

1. 只提供用户明确授权的必要文本，不读取账号、密钥或整段会话。
2. 把任务拆成 Choice（闭集含不确定选项）、Score（明确刻度）或 Noul（是/否概率）问题；算术、计数、日期比较用代码。
3. 宿主将原样预览本次材料与问题并要求用户确认。取消或授权变更后不能重放请求。
4. 不将低置信度结果作为确定事实；保留人工判断。不能据此移动文件、安装工具、合并代码或声称验收通过。
5. 旧工具名仅兼容过渡，遵守相同确认边界；首选 `jev_decide`。
