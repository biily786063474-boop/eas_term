READING GUIDE

口径与刷新方式
  • 真实输入包含缓存；“未缓存”＝输入总量－缓存，不是你本次手写字数。
  • 按 turn_id 聚合，response_id 去重；不把累计 token_count 再次相加。缺 usage 的消息无法计量，不显示成零成本。
  • 来源估算使用 。已加载文件通常只能归到工具返回；不会假装知道其中每个文件的精确计费。
  • 当前支持本项目 Codex rollout 日志；不代表 Claude、OMP 或账户全部消费。进行中的消息只统计已经返回的请求。
  • 报告纯本地、无外部依赖、无网络请求，不导出工具正文。页面刷新只能读取最新生成快照；后台分析器运行时才会产生新快照。

更新数据：在项目目录运行

python3 scripts/token-dashboard/build.py --watch

只生成一次：去掉 --watch。关闭页面不会结束后台分析器；分析器终端 Ctrl+C 停止。默认仅扫描本项目最近 30 个有效会话。
